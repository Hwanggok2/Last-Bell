마지막 종지기 · 화면과 조작

기본 2×2, 넓은 창 4열, 좁은 창 1열로 비교합니다. 화면 안에는 게임 문구를, 좌표·조건·미확정 사항은 바깥에 표시합니다.

기획 기준: 장식 조각은 일반전 +1·보스 +3·완주 +6(총24), 광고 +5·결과당 1회·일 3회, 무료 외형 80/160. 무료 수집 완료 시 광고를 숨깁니다. 패배 예시는 일반전 3회 완료 후 +3입니다. ‘표시 가격’은 스토어 가격 자리이며 기기 터치 검증 전입니다.

첫 시작 → 짧은 서사 → 로비 → 전투 ⇄ 일시정지 → 결과 → 재도전 / 로비
로비 ⇄ 수집 · 설정 · 상점　|　결과 → 선택형 보상 광고 → 결과

원점: 각 화면 좌상단. bounds = x,y,width,height. TL/TR/T는 안전 영역 상단, BL/BR/B는 안전 영역 하단, C는 안전 영역 중앙 기준입니다.

점선은 안전 영역·입력 영역입니다. 전투 하단 208 논리 단위의 음영은 손가락 가림을 검토하기 위한 가정입니다. 예고는 그 위에 둡니다. 48 논리 단위가 실제 48dp를 보장하지는 않으므로 기기에서 확인해야 합니다.

좌표와 상태는 UI 검토 문서에 설명했습니다. 기본 4화면 SVG는 정적 공유용입니다.
