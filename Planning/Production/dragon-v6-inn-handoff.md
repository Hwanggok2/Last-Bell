# Dragon v6 여관 UI 인계

상태: 소스와 부분 마이그레이션 작성 완료. Unity 실행·프리팹 적용·화면 QA는 아직 하지 않았다.

## 복원 근거와 범위

- 실제 v4 선택 화면: `Planning/Evidence/Dragon-v4/dragon-v4-candidate-02/1280x720/fresh/v4-select-rin-preview.png`.
- 업그레이드 화면은 v3에서 도입되어 v4에서도 유지한 `Planning/Evidence/Dragon-v3/dragon-v3-candidate-02/1280x720/fresh/v3-upgrade-name.png`와 640×360 대응 캡처를 직접 확인했다. 이 캡처를 새 v6 실행 증거로 표기하지 않는다.
- `ReferenceV81Migration`의 저장 `StatMenu` / `UpgradeDetail` / 하단 구매 구조를 유지한다. `DragonUiMigration`의 밝은 양피지 도트 스타일을 유지한다.
- v5의 상단 성장·동료·유물 탭줄, 행별 즉시 강화 +, 행별 10칸을 숨긴다. 저장 참조·기능은 삭제하지 않는다. 좌측 스탯을 선택하고 우측에서 +1 / 최대 견적을 고른 후 하단 강화 버튼으로 구매하는 기존 흐름이다.
- 회복력은 다섯 번째 선택 행이다. 동료 진입은 우측 상단에 단독 배치한다. 동료 화면의 뒤로가기는 강화 화면으로 돌아오고, 강화 화면의 뒤로가기는 캐릭터 선택으로 돌아간다.

## 기준 와이어와 bounds

SafeRoot 기준 좌상단 `(0,0)`, 모든 수치는 `(x,y,w,h)`이며 1280×720 / 640×360 기준이다. 기준 화면에서 hit area는 최소96×96 / 48×48이다. 외부 안전 영역 처리는 기존 SafeRoot가 담당한다. 작은 화면에서 숨겨지는 정보는 없으며 동료 목록은 스크롤한다.

```text

│ 체력   ★★★ │ 짧은 효과 설명                     │
```

## 구현/통합 인계

### 소유 파일

- `Client/Assets/Game/Runtime/Presentation/ReferenceLobbyView.cs`: `RestoreUpgradeV6` 저장 플래그, 예전 선택→강화 동선, 동료 버튼/뒤로 동작, 행별 +·pips 비표시.
- `Client/Assets/Game/Runtime/Presentation/FeedbackLayout.cs`: 위 bounds 단일 소유. `ApplyInnLayout(width,height)`는 여관 부분만 배치하므로 마이그레이션에서 전투·HP 배치를 건드리지 않는다. 동료 열기/닫기에서도 헤더 배치를 재평가한다.
- `Client/Assets/Game/Runtime/Presentation/CompanionInnView.cs`: `SkillName`, `SkillEffect`, `SkillProgress` Text3개. 기존 서비스·거절·골드 부족 교환·편성 교체 확인은 그대로 유지한다.
- 새 `Client/Assets/Game/Editor/DragonV6InnMigration.cs`와 `.meta`: 기존v5여관을 검증한 후 상세 하위Text3개만 추가한다. GameView/씬 전체 재생성·저장·빌드는 하지 않는다.

### 총괄 연결

저장 프리팹을 로드한 `MvpView`, 씬 인스턴스의 `p.View` 각각에 기존 `DragonV5InnMigration.Apply(view)` 다음 `DragonV6InnMigration.Apply(view)`를 호출한다. 적용 순서를 바꾸지 않는다. 최종 검증에도 `DragonV6InnMigration.Validate(view)`를 추가한다. 이 마이그레이션은 `RestoreUpgradeV6=true`, 기존 성장 탭/+·pips 비표시, 동료 버튼 활성화, 새Text참조를 저장 대상으로 만든다. 실제 `SaveAsPrefabAsset`/씬 저장과 빌드는 총괄이 수행한다.

Presenter의 기존 `Wire`/`Render`/`SamplePortrait` 연결은 바꾸지 않는다. 캐릭터 선택 화면에서 동료를 누르면 해당 캐릭터 선택을 Core에서 확정한 뒤 동료 화면을 열고, 동료에서 뒤로 또는 우상단 동료 버튼을 다시 누르면 강화 화면으로 돌아온다. 다시 뒤로를 누르면 캐릭터 선택이다. 파티·예약·재화 견적은 기존 Core 메서드에 맡긴다.

### Core 읽기 계약

`CompanionView.SkillName`과 카탈로그 기반 한 줄 `SkillDescription`을 사용한다. 확률은 `SkillChancePercent → NextSkillChancePercent`, 공격 주기는 `PeriodMs → NextPeriodMs`이며 밀리초를 초로만 변환한다. 피해 정보는 `ExpectedDpsMilli → NextExpectedDpsMilli`를1000으로 나눈 HP/s다. 총 동료DPS 상한 때문에 개별 기본 타격값이 작아질 수 있으므로, 기존 단타 피해의 성장 화살표 대신 실제 예상 초당 피해를 표시한다. UI에 발동률·주기·DPS 계산식을 복제하지 않는다.

잠금 상태는 실제 `JoinStage`, 최대레벨은 화살표 없이 현재 수치, 지역 레벨한도는 실제 다음 `levelCapBosses`의 보스 조건을 강화 버튼에 표시한다. 숨겨진 v5 행별+ 참조는 삭제하지 않고 비활성으로 남긴다. 실제 강화 성공 시 기존 Upgrade ParticleSystem 호출은 유지한다.

### 확인 범위와 남은 항목

기존1280/640 실제 화면을 직접 비교하고, bounds·부모 기준·형제 버튼·여관 레이아웃 소유권을 정적으로 검토했다. `git diff --check`에 수정 오류는 없었다(CRLF 안내만 표시). Unity 컴파일·저장 에셋 적용·실행 캡처·터치 QA는 총괄/전용QA에서 확인해야 한다. 기존v5 기획·캡처·QA문서는 변경하지 않았다. Core/PS/HP/숫자/Presenter/씬·프리팹·빌드 파일은 수정하지 않았다.
