# 최신 연출 Unity 통합 — 2026-10-21

대상은 `Client/Assets/Game/Scenes/Mvp.unity`, 첫1~10층과11층 경계 표본이다. 50층 전체 콘텐츠 제작과 Android 실기기 검증은 이번 적용 범위와 구분한다.

## 적용 경계

Core는 명중·회피·보상·스토리·전환 시계를 소유한다. `BattlePresentation`은 같은 시계를 읽어 저장된 모션, 카메라, VFX, 음향을 표시한다. 연출이 층을 다시 올리거나 보상을 지급하지 않는다. GameView·배경·음향·아트는 저장 프리팹과 카탈로그로 연결하며 런타임에 UI를 새로 조립하지 않는다.

## 담당과 검증 절차

- 총괄: Presenter·씬/프리팹 연결·오디오·상태 복원, 담당 결과 통합.
- Core 담당: 전투·진행·스토리·저장·카탈로그·검증 도구.
- 아트 담당: 원본273장 보존, 선택 클립·피벗·셰이더·저장 카탈로그.
- UI/VFX 담당: 예고·참격·포효·도트·Stage·등불·깊이별 배경.
- **Client 개발 채팅**: 전용 MCP 구축, 독립 코드 리뷰, 후속 Client 개발.
- **QA 채팅**: [21개 완료 기준](../QA/acceptance-20261021.md)에 따른 통합 QA1회. 실패 수정 후 영향 범위만 재검사.

전용 MCP 주소는 `http://127.0.0.1:8093/mcp`이고 `Client@65e60f79bc76ded9`만 등록한다. [설치·연결 확인](mcp-setup-20261021.md), [운영 명령](../../Tools/MCP/README.md)을 따른다.

개발 단계에서 Core67개·exporter19개·독립 계약808 assertions 및 Unity DLL 정적 컴파일을 확인했다. Unity에서 저장 마이그레이션과 콘솔 오류0을 확인하고 전용 QA에 인계했다. 이것은 전체 QA 통과 선언이 아니다. 최종 실행 결과와 빌드 식별은 `Planning/QA/result-20261021.md`에 기록한다. 이전 전투 피드백 빌드 결과를 이번 증거로 재사용하지 않는다.

## 이번 검사와 전달 상태

전용 QA는 통합 검사1회 후 수정 영향 범위만 재검사하고 종료했다. EditMode는 저장 수정 후83/84와 잔여 시간 단언의 매개변수3/3을 확인했고, PlayMode는 기존10/10과 신규 예고·피격/사망 회귀1/1을 확인했다. 전체 검사를 반복한 한 번의 합격 결과로 합치지 않는다. 최종 일반 Windows 빌드는 오류0, 별도 프로세스의 Stage11·공격Lv29·장착1 복원과 정상 종료를 확인했다.

전달물은 `Builds/Windows/LastBellMvp.exe`와 `Builds/LastBellMvp-Windows.zip`이다. QA 관측 코드는 빌드에 포함하지 않았다. 사용자 저장·설정은 보호·복구했다. 원본 Unity도 Mvp 씬과 저장 참조를 검증했으며 Play 중이 아니다.

**전체 합격은 보류**한다. QA-003 간헐적 Unity native 종료 오류가 남아 있고, 사용자가 실입력 검사를 나중으로 미뤘다. 다프레임 외형 검토·기기 Safe Area·전체 청음 등 남은 근거를 [QA 결과](../QA/result-20261021.md)에 항목별로 기록했다. 엔진 버전을 추측으로 바꾸거나 미검증 항목을 합격으로 처리하지 않았다.
