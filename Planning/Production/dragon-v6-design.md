# Dragon v6 / 0.9.5 기획 인계

Point 필터·정수 배율을 유지한다. 도해는 크기·격자 예시이며 실제 게임 렌더 확인은 남아 있다.

## 공격 중 독립 플레이어 스킬

스킬 입력을 받으면 즉시 20초 쿨타임을 시작하고 200ms 뒤 독립 접촉을 1회 처리한다. 일반 공격 준비·타격·복귀, 회피·쳐내기·반격 예약을 덮지 않는다. 별도 스킬 애니메이션으로 현재 동작을 강제로 교체하지 않고 준비 입자와 접촉 효과를 표시한다.

| 캐릭터 | 기술 | 피해 / 상태 | 시각 언어 |
|---|---|---|---|
| 루카 | 바람 베기 | 공격력 160% | 금색 이중 사선, 기존 0~5 방향 공유 |
| 다렌 | 방패 충격 | 공격력 115%, 최대 HP 8%를 1회 보호 / 접촉부터 최대 3초 | 청색 충격 고리·십자, 실제 보호막 테두리 |
| 미엘 | 별빛 벼락 | 공격력 125%, 기절 누적 50 | HUD 아래 상공에서 적 몸까지 보라·크림 벼락 |

- 일반 전투에서 양측 생존, 일시정지·가이드·도움말 연습 아님, 쿨타임 0, 예약 스킬 없음일 때 사용한다. 공격 또는 회피 중이라는 이유로 막지 않는다.
- 일시정지는 접촉과 쿨타임을 멈춘다. 사망·패배·이동·원정 종료는 예약 접촉을 취소하며 소모한 쿨타임은 환급하지 않는다.
- 동시 시각은 적 타격/사망 → 일반 플레이어 타격 → 독립 스킬 → 동료 순이다. 앞선 처치 이후 중복 피해·보상을 만들지 않는다.
- 스킬에는 치명타·기절 피해 보너스·기절 연장 추가 판정이 없다. 누적은 채울 수 있지만 100 누적을 소비해 실제 기절시키는 것은 다음 일반 플레이어 공격이다.
- 저장 복원 시 남은 접촉 예약을 한 번만 이어 간다. 이전 버전 예약 마이그레이션은 Client 계약을 따른다.
- 표시 이름을 바꿔도 안정 ID `skill_daren_iron_counter` / `skill_miel_star_seal`은 유지한다. 다렌의 보호막은 입력 순간이 아니라 실제 스킬 접촉부터 시작한다.

## 동료별 기술과 강화

전용 기술은 기존 지원 공격을 준비할 때 한 번 추첨하여 **그 차례의 기본 공격을 대체**한다. 180ms 준비 시간은 공격 주기 안에 포함한다. 별도 추가 기본 타격이나 재추첨은 없다.

| 동료 | 기술 | 동료 기본 타격 대비 | 추가 효과 | 기본 주기 |
|---|---|---:|---|---:|
| 토리 | 쌍쏘기 | 180% | 두 화살 / 실제 피해 1회 | 6초 |
| 바룬 | 쿵 내려찍기 | 170% | 기절 누적 +8 | 10초 |
| 도토 | 불꽃 망치 | 200% | 주황 불꽃 접촉 | 8초 |
| 리나 | 번개 줄기 | 180% | 기절 누적 +10 | 7초 |
| 모모 | 씨앗 폭탄 | 170% | 생존 플레이어 원정 최대 HP 2% 회복 | 6초 |

바룬·리나 누적에는 적 종류의 저항과 기존 소비 규칙이 적용된다. 모모 회복은 최대 HP를 넘지 않으며 실제 회복량만 표시한다. 스킬 선택은 저장된 전용 난수·예약으로 유지하여 다시 불러오거나 다음 적을 만날 때 같은 예약을 다시 추첨하지 않는다.

`발동률 = min(45, 12 + 레벨 - 1)%`

`주기 = 기본 주기 × max(70, 100 - (레벨 - 1)) / 100` (정수 ms)

| 강화 효과 | Lv.1 | Lv.10 | Lv.20 | Lv.30 |
|---|---:|---:|---:|---:|
| 발동률 | 12% | 21% | 31% | 41% |
| 기본 주기 비율 | 100% | 91% | 81% | 71% |
| 토리·모모 주기 | 6.00초 | 5.46초 | 4.86초 | 4.26초 |

Lv.1→2 예시는 발동률 12→13%, 토리 6.00→5.94초, 바룬 10.00→9.90초, 도토 8.00→7.92초, 리나 7.00→6.93초, 모모 6.00→5.94초다. 기술 배율 자체는 레벨마다 변하지 않는다. 기존 피해 성장과 11·21 돌파는 유지한다. 초기 Lv.10, 10보스 이후 Lv.20, 20보스 이후 Lv.30 한도이며, 최대에서는 다음 수치 화살표를 감추고 해금 조건을 보여 준다.

편성 전체 기대 DPS는 플레이어 **기본 공격력의 24%/초** 이하다. 기술 발동 기대값과 빨라진 주기를 포함한다. 고정 편성에서 강화하면 전체 및 강화한 동료의 기대 DPS는 줄지 않지만 상한에서 정체될 수 있다. 상한 재배분 때문에 개별 기본 타격이나 강화하지 않은 동료의 몫은 낮아질 수 있다. 따라서 UI는 기대 DPS·발동률·주기를 함께 비교하며 매번 한 방 피해가 증가한다고 안내하지 않는다. 임의의 플레이어 공격력을 가정한 가짜 DPS 견적은 기획 도해에 넣지 않았다.

새 계정의 현재 1~20 구간은 토리·바룬 만남을 지원한다. 도토·리나는 기존 저장 해금을 지원하며, 모모의 42스테이지 첫 만남은 후속 지역 범위다.

## 파티클과 상태 표시

루카 이중 사선, 다렌 충격·실제 보호막, 미엘 굵은 보라 벼락, 토리 쌍화살, 바룬 지면 충격, 도토 불꽃 망치, 리나 짧은 청색 벼락, 모모 씨앗 폭발을 구분한다. 미엘 벼락은 6굽이, 리나는 5굽이이며 상단 HUD 116단위를 비운다. 실제 적 몸·발에서 끝나며 조작 버튼을 덮지 않는다.

실제 기절 동안만 얼굴 주변 큰 별 3개가 돌고 종료·사망 즉시 사라진다. 면역 상태만 있을 때 별은 없다. 보호막·회복은 실제 상태/사건을 읽는다. 시각 효과에서 수치·시간·접촉 예약을 새로 만들지 않는다.

4개 ParticleSystem, 투명 Point RenderTexture, 최대 376입자 예산을 유지한다. 접촉·수명 표는 기획 페이지 및 파티클 인계에 있다. 이 수치는 성능 보장값이 아니며 동시 접촉과 실제 프레임 시간은 통합 QA에서 측정한다.

## 검증 인계

문서 담당은 링크·도해 크기·수치 계약·좌표·v5 보존을 정적으로 확인한다. 브라우저 실행이나 Unity 기능 테스트를 했다는 뜻은 아니다. 실제 완료 표기와 캡처는 총괄 통합 QA 후 별도로 연결한다.

1. 공격/회피 중 200ms 독립 접촉, 20초 쿨타임, 동시 막타·사망·정지·저장 복원의 중복 여부.
2. Lv.1~30·혼합 편성의 확률·주기·기대 DPS 단조성/24% 상한, 피해 1회와 실제 회복량.
3. 1280/640에서 강화 배치와 우상단 동료 버튼, 현재→다음 견적, 잠금·최대·부족 상태.
4. HP·큰 숫자·하늘 벼락·동료 기술·큰 기절 별이 공격 예고와 입력을 가리지 않는지.
5. 최대 동시 효과의 4개 PS·입자 예산·프레임 시간, Point·투명 알파·정수 격자 유지.

소유 범위는 `Adventure-v6/`와 이 문서다. 공용 기획 보드 연결, Unity 코드·프리팹·씬·빌드·QA 증거는 해당 담당에게 남긴다.


## 큰 피해 HP 잔상 · v0.9.6

플레이어·일반 적·중간보스·보스 모두 초록색 실제 HP(#51A441), 주황색 잔상(#EF8F35)을 같은 도트 격자에 겹친다. 실제 HP는 즉시 반영한다. 단일 실제 피해가 피격자 최대 HP의 1/3 이상일 때만 120ms 유지하고 550ms 선형 보간으로 따라온다. 연속 프레임마다 현재값을 다시 Lerp하는 지수 감쇠는 사용하지 않는다.

실제 단일 접촉 DamageMilli를 사용하므로 보호막 흡수량·과잉 피해·동료 숫자 합산은 발동량에 포함하지 않는다. 작은 후속 피해는 원래 잔상 종료시각을 유지하고 목적 HP만 바꾼다. 큰 후속 피해는 현재 보이는 잔상에서 다시 시작한다. 회복·새 대상·세션 재바인딩에서 초기화, 일시정지·가이드에서는 정지한다. 사망 시 실제 HP는 즉시0이며 소멸 중 잔상만 남는다. 잔상은 저장하거나 전투 판정에 사용하지 않는다. 1280의4px/640의2px 도트 격자는 유지한다.
