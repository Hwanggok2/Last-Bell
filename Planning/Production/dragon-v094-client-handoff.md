- `ComboPractice` read-only `ComboPracticeView`: Active, IsReplay, AwaitingInput, Step(0/1), RequiredDirection, Message, IsRealTrial. Existing ComboHint is the intro; `ConfirmComboHint()` starts guided Up→Down at1800/2550ms. `Dodge(direction)` at a hold is the fresh press-edge route; early/wrong calls do not progress. `SkipComboPractice()` stores skipped for automatic tutorial, or exits help replay. `BeginComboPractice()` starts a reward-free help sandbox from inn or paused combat; `EndComboPractice()` restores the exact live state. `CombatSuspended` includes guided input holds; attacks/skills/companions are locked during guided practice. `ComboPracticeCompleted`/`ComboPracticeChanged` events support UI feedback.

## Final behavior and integration details

- **Recovery:** five stars/levels; on/dam/rin recovery aptitude3/4/2. `recovery` includes tea in a fixed run snapshot. Same living-only, clamped, once-per-defeat heal for normal/miniboss/boss and companion last hits. Removed boss full-heal assignment. The existing `stageRewardApplied` reward transaction guards the heal as well. New departure still starts at full run maxHP.
- **Companion timing:** periods6000/10000/8000/7000/6000; initial slot offsets0/400/800; windup180 is included, not added to every period. Only ordinary live Combat advances these timers. Travel, dialogue, pause and all guided practice freeze them. New-enemy contacts have minimum350ms grace; unchanged-enemy reload preserves exact remaining time and pending windup. Completed contacts are not replayed. Last-hit reward/heal/transition is shared once; player death is processed before same-time companion contact.
- **Damage:** unmodified integer `baseAttack` snapshot × companion coefficient × level growth × shared party cap. Internal milli-HP rounding only. No crit, player skill, stagger gain/stun start, stun extension or stun multiplier. UI preview's next damage recalculates the cap for the promoted member. Live `RunCompanions` holds authoritative snapshotted values.
- **Services:** guide+3 percentage points capped together with luck; first Tori unlock affects future rewards only. Weapon uses additive relic+craft bonuses. Blessing+5 percentage points and tea+15% of base recovery are reserved per character/start stage, consumed once on departure, fully refundable before departure; obsolete start-stage reservations refund once on load/departure. No automatic gem exchange or purchase after exchange.
- **Story choice:** after the final page/skip, newly unlocked NPCs wait on `AwaitingCompanionChoice` even when full; `CanInviteCompanion=false` means show only “여관에서 만나”. First new-account Tori with an empty first slot autojoins instead. `ChooseCompanionJoin(false)` / existing next-or-skip dismisses the invitation. Existing companions use a one-page reunion per character, no repeated unlock/reward. All legacy scene definitions retained, including the Tori10 alias.
- **Tutorial:** intro remains `SessionPhase.ComboHint`; guided movement/holds/recovery use Combat plus `ComboPractice`. AwaitingInput stops exactly at1800/2550ms and only `Dodge(correctDirection)` from a fresh UI press passes. Correct calls emit normal Dodged/Parried without stagger/perfect rewards. Inputs are locked through360ms recovery, then the same Up→Down real sequence runs once with normal damage before random patterns. Saved completed recovery continues to real trial; interrupted earlier practice restarts first guided sequence. Existing active schema8 Stage5 combat migrates to the intro while keeping HP/skill cooldown. Old comboHintSeen never marks completion.
- **Help sandbox:** `BeginComboPractice()` is accepted only from inn or paused Combat. During replay `ExportSave()` returns the exact original live state and Publish never requests a save. Completion, skip or `EndComboPractice()` restores original run, threats, pending-input deadline, attack/dodge/counter timers, pause flag and dirty state. Root can refresh presentation on `ComboPracticeChanged` when IsReplay becomes false; no core time passes in the old run.
- **Events:** CompanionAttackStarted/CompanionDamaged/CompanionUnlocked/CompanionJoined carry CompanionId; PlayerRecovered carries RecoveryMilli; ServicePurchased carries ServiceId; ComboPracticeChanged/Completed expose state via ComboPractice. SkillId and SkillShieldAbsorbed remain unchanged. Companion damage is deliberately **not** EnemyDamaged; root must render its small hit effect from CompanionDamaged explicitly.
