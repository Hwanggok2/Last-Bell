# Dragon v3 · 작업 범위와 완료 기준

2026-10-24. 사용자 요청: 11층 이후 새 몬스터 적용, EXE의 Stage 1 새 시작, 두 글자 이상 이름과 전용 스킬 기획. 추가 요청: 지역별 지면 정의와 접지, 자연스러운 모션, 게임의 차별성과 재미 기획, NPC와 플레이어 화풍 정합.

## 적용 범위

- 현재 구현된 20스테이지 중 11~20을 솔바람숲의 고블린·숲송이·기블로 교체한다. 21~50은 기존 구역 계획을 유지하며 이번 실행판에서 완료됐다고 표시하지 않는다.
- 안정적인 캐릭터·적 ID, 전투·성장·보상·유물·체크포인트 수치는 유지한다. 표시 이름은 루카(on), 다렌(dam), 미엘(rin), 기블(gib)이다. 다렌·미엘은 준비 중 상태를 유지한다.
- 새 실행판의 첫 시작은 Stage 1로 이어지는 신규 진행이다. 기존 사용자 저장을 삭제하지 않고 신규 진행의 재실행 저장은 보존한다. 구체적 시작 방식은 Client 구현 인계와 배포 안내에 기록한다.
- 지역별 지면 소재와 공통 전투 기준선을 정의한다. 실제 지면, 플레이어와 적의 발 피벗, 이펙트의 기준점을 일치시킨다. 의도적인 도약·회피·타격 이동을 발 경계 강제 정규화로 지우지 않는다.
- 플레이어는 NPC 시안과 비교해 외곽선·의복 색을 보정한다. 비율 축소안도 비교했으나 원래 비율을 유지하는 A안을 채택했다. 기존 모험가의 머리·스카프·튜닉·가방·검과 승인 동작·타이밍을 보존한다.
- 새 고블린은 기존 Metal 무기 궤적, 숲송이는 기존 Wood 입자·지면 충격을 사용한다. 몸을 압축한 뒤 뿌리·포자를 방출하는 동작과 별도 공격 효과를 연결하며, 전투 방향·접촉 시각·판정은 유지한다. 새로운 VFX 원본을 제작한 것으로 표기하지 않는다.
- 캐릭터 전용 스킬과 차별화 요소는 **기획안**으로 작성한다. 새 버튼·자동 공격·해금·스킬 효과를 이번 런타임에 몰래 추가하지 않는다.

## 역할과 파일 소유

| 담당 | 범위 |
| --- | --- |
| 총괄 | 데이터·이름·스토리, 아트 임포트, 기획서 통합, Unity 저장 자산 적용·빌드·패키지 |
| Client 채팅 | 시작/저장 처리, 지면/배치 런타임과 관련 표적 검사 |
| 아트 담당 | Forest-v1 신규 10종의 Idle·Attack·Stun과 원본/라이선스 |
| 플레이어 아트 담당 | Player-v3 스타일 비교·수정 및 모션 연속성/접지 기록 |
| 기획 담당 | 캐릭터 3명 전용 스킬, 차별화 요소와 구체적인 플레이 예시 |
| QA 채팅 | 완료 후보 인계 후 변경 범위에 대한 한 차례 통합 검사, 결함 수정 시 해당 부분만 재검사 |

## 완료 기준

1. Stage 11~20 모두 신규 아트/표시명 참조. 원본과 실제 렌더에서 장비·실루엣·준비/접촉/복귀·보스 얼굴 위치와 크기를 확인한다.
2. 새 EXE 첫 진행이 Stage 1로 연결되고 재실행에서 신규 진행을 복원한다. 기존 저장은 보존한다.
3. 캐릭터 이름·프롤로그·10/20 보스 대사의 인물 이름이 일치한다. 기존 IDs/수치·해금 상태는 보존한다.
4. 지면 기준과 발 피벗이 일치한다. 일반·보스·이동·공중 동작을 구분하고, 프레임별 임의 재중심화로 모션을 훼손하지 않는다.
5. 기획서 상단에서 현재 적용, 미구현 스킬 계획, 지역별 지면, 비교 화면과 실행판을 찾을 수 있다.
6. 변경 관련 데이터 검증·컴파일·관측 실행·배포 패키지를 확인한다. OS 실입력과 모바일 실기기 검사는 이전 보류를 유지하며, 프레임 검토를 실시간 영상 체감 검증으로 부르지 않는다.
