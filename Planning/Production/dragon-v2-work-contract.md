# 모험가와 굵은 도트 수정 · 2026-10-24

사용자 요청: 플레이어와 체력바의 도트 느낌을 강화하고, 기존 캐릭터의 동작을 새 모험가 외형에 적용한다. 직전 Dragon v1 플레이어는 이번 작업의 품질 기준으로 삼지 않는다.

## 제작 기준

- 외형은 얼굴이 드러나는 갈색 머리, 붉은 짧은 스카프, 초록 튜닉, 여행 가방과 한손검이다. 작은 장신구보다 큰 색면으로 모험가 실루엣을 만든다.
- 화면 속 키는 약144~160px를 유지한다. 첫18~20px 목표에서 장비 판독성을 확인해32px 캔버스·원형 몸높이22px·7배 확대(154px)를 제작 기준으로 선택했다. 캔버스의 투명 여백과 실제 몸높이를 구분한다. 최종값은 원본 검토 후 기록한다.
- 달리기는 사용자 승인 기존 `hero-approved-dash-20261021-02`, 베기와 쳐내기는 기존 `hero-v6-slash-up` 포즈를 우선 사용한다. 실제로 재사용한 소스·선택 프레임·생성 경로를 남긴다.
- 달리기400ms 주기, 이동1920 논리px/2초, 공격 접촉200ms, 위·뒤 회피와 아래 쳐내기 조작은 그대로 둔다. 아트 재생을 판정 시계에 맞춘다.
- HP는 같은 실제 체력 값을 보여준다. 0일 때만 완전히 비우고, 양수인 최소 체력은 최소 한 칸 표시한다. 플레이어·적·보스의 기존 위치와 역할은 유지한다.

## 완료 기준

1. 이전·새 원본의 달리기와 베기를 실제 속도로 비교한다. 프레임 수나 서로 다른 해시만으로 품질을 판정하지 않는다.
2. 달리기에 접지·비행·팔다리 교차가 보이고, 상체가 기울며, 검 손잡이와 손이 떨어지지 않는다. 복장·가방·몸 비율이 프레임마다 바뀌지 않는다.
3. 베기는 찌르기처럼 보이지 않고 준비→호→후속 자세가 이어진다. 기존 접근·접촉·복귀 및 별도 사선 참격과 맞는다.
4. 위 회피·뒤 회피·아래 쳐내기가 구별된다. 유효 시간과 공격 판정은 아트를 위해 바꾸지 않는다.
5. 체력바0/작은 양수/25/50/100%를1280·640에서 확인한다. 테두리와 채움의 큰 픽셀 단위가 보이며 위치·문구·입력을 가리지 않는다.
6. 실제 Unity에서 반복 재생한 모션과 HP 화면을 검토한다. 새 원본·Unity 적용·관측 결과·일반 빌드 생성 여부를 각각 기록한다.

기존 게임 데이터·경제·성장·저장·몬스터·방향키 배치는 이번 수정 범위가 아니다. OS 마우스·키보드 실입력 보류는 유지한다.
