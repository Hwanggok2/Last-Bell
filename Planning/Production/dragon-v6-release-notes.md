# 용 잡으러 갑니다 · v0.9.6

데이터 mvp1.18.0. 현재 전투 콘텐츠는 1~20스테이지이며, 기존 저장의 진행도와 해금 상태를 유지한다.

## 이번 변경

- 여관은 좌측 스탯 선택 → 우측 상세 견적 → 하단 강화 버튼의 이전 구조로 복원했다. 동료 버튼은 우측 상단이며, 회복력은 다섯 번째 스탯으로 유지한다.
- 체력바는 초록색 실제 HP를 즉시 표시하고, 단일 실제 피해가 최대 HP의 1/3 이상이면 주황색 잔상을 120ms 유지한 뒤 550ms 선형 보간으로 감소시킨다. 회복·새 대상에서는 초기화하고 일시정지 중에는 멈춘다. 하트와 계단형 외곽, 정수 도트 잔량을 유지한다. 플레이어·일반 적은 몸 아래, 중간보스·보스는 상단의 긴 체력바를 사용한다. 보스 이름은 방향 예고 오른쪽에 둔다.
- 플레이어 스킬은 평타·회피 중에도 사용할 수 있다. 사용 즉시 20초 쿨타임이 시작되며 200ms 뒤 독립된 접촉 한 번이 발생한다. 미엘의 별빛 벼락은 굵은 보라·크림 도트 벼락, 다렌은 방패 충격, 루카는 바람 베기다.
- 동료 공격도 적의 전신 흰색 피격 반응과 도트 파편을 발생시킨다. 기존 적의 준비·공격 동작은 이 반응으로 중단하지 않는다.
- 피해 숫자는 외곽선이 있는 5×7 도트로 확대했다. 일반·스킬은 크림색, 동료는 청록색, 치명타는 더 큰 노란색이다. 0.85초 동안 우측 상단으로 이동한다. 80ms 안의 동료 연합 타격은 실제 피해를 합산한 숫자 하나로 표시하며 평타·스킬 숫자는 따로 유지한다.

## 동료 전용 스킬

매 지원 공격 준비 시 한 번 추첨하며, 발동한 스킬은 해당 차례의 기본 공격을 대체한다. 별도의 추가 기본 피해를 중복 적용하지 않는다.

| 동료 | 스킬 | 효과 |
| --- | --- | --- |
| 토리 | 쌍쏘기 | 기본 타격의 180%; 화살 두 발의 연출, 피해 판정 한 번 |
| 바룬 | 쿵 내려찍기 | 170% 피해, 기절 누적 +8 |
| 도토 | 불꽃 망치 | 200% 피해 |
| 리나 | 번개 줄기 | 180% 피해, 기절 누적 +10 |
| 모모 | 씨앗 폭탄 | 170% 피해, 생존한 플레이어 최대 HP의 2% 회복 |

레벨당 발동 확률은 1%p 증가하고, 공격 주기는 기본 주기의 1%씩 감소한다. Lv.1/10/20/30의 발동률은 12/21/31/41%, 주기는 기본의 100/91/81/71%다. 여관에 현재→다음 확률·주기·초당 지원 피해를 표시한다. 기존 보스별 레벨 해금 조건과 편성 전체의 기대 피해 상한을 유지한다. 높은 레벨에서 한 번의 기본 피해와 초당 기대 피해는 다를 수 있다.

5종의 규칙·모션·효과는 구현했다. 현재 새 계정의 1~20 구간에서는 토리·바룬을 만나며, 기존 저장의 도토·리나 해금은 유지한다. 모모의 첫 만남은 후속 지역이다.

## 저장과 검증

저장 스키마는 9를 유지하며 새 스킬 예약 규칙만 별도로 버전 관리한다. 동료의 추첨 결과·남은 시간은 저장되며 재로드로 재추첨하지 않는다. 새 스킬의 예약 접촉은 복원 후 한 번 이어지고, 이전 버전의 결합된 스킬 예약은 호환 규칙에 따라 취소한다.

Core 신규 9547 assertions, 기존 217 assertions, 데이터 30 tests, Unity EditMode 202건과 팝업 PlayMode 표적 1건이 통과했다. Windows의 기존 정산·복원·640 화면 검증은 완료했다. 추가 HP 잔상은15개 PlayMode 검사와1280/640 실제 피해 표적 검증·원본18장 시각 검토를 완료했으며, 결과는 [전용 QA 보고서](../QA/dragon-v6-result-20261025.md)에 기록한다.

관측 빌드의 합성 버튼 입력·테스트 저장·고레벨 상태를 이용한 한정 검증과 일반 배포판의 패키지 검증을 구분한다. 모바일 실기기 터치·직접 청음·정상 속도 성능 측정은 포함하지 않는다. 이전 후보의 실패와 수정 근거는 지우지 않는다.
