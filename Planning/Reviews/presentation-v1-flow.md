# 전투 전환·보스 등장 연출 검토 v1

작성일: 2026-10-21 KST. 담당: 전투 흐름 검토 세션. 상태: **현재 코드 대조를 마친 기획 권고안. Unity 적용·애니메이션 제작·플레이 검증 전.**

이 문서는 `unity-project-foundation` 스킬의 상태 소유·보상 중복 방지·저장 복구 기준을 적용한다. 이번 변경 범위는 Planning뿐이다. 아래 시간과 카메라 배율은 측정 결과가 아니라 시안 제작용 시작값이다. 통합본 `Planning/Presentation/proposal.json`·`design-spec.md`·`app.js`·`index.html`과 소스 대조해 구간을 맞췄다. 기획 수치 원본은 `proposal.json`이며 이 문서는 담당별 검토 근거다.

## 2. 공통 원칙

- **적을 처치하면 길이 이어진다.** 10층마다 로비나 확인 화면으로 돌려보내지 않는다. 유물 선택은 기존대로 5·10층에서만 멈춘다. 선택을 마치면 자동 전진한다.
- 처치·사망 판정은 마지막 타격 시점에 확정한다. 파편이 사라지는 순간이나 사운드 콜백이 보상·승패를 결정하지 않는다.
- 전환 중 공격·회피 입력은 받지 않고 버린다. 입력 예약도 하지 않는다. 다음 전투가 열린 뒤 새로 누른 입력만 사용한다. 일시정지는 항상 가능하게 한다.
- 등장·이동·분해 중에는 전투 시계를 멈추고 예고를 숨긴다. UI/연출 시계는 별도로 진행하되 일시정지와 앱 백그라운드에서는 함께 멈춘다.
- 마지막 **0.20초 정착**은 각 타임라인의 총길이에 포함된다. 카메라와 캐릭터가 기본 위치로 돌아온 뒤 전투 시계·버튼을 함께 열고, 그때 첫 예고를 처음부터 시작한다. 별도의 0.20초를 다시 더하지 않는다.
- 다음 전투 진입 시 공격·회피는 준비 상태로 시작한다. **현행 BeginStage는 공격 재사용 시각과 회피 시작 시각을 초기화하지 않으므로, 이는 기존 동작 설명이 아니라 명시적 변경 제안이다.** 연출 전투 시계 동결로 재사용 잔여가 새 적에게 넘어가는 문제를 막는다. 저장 시 현재 상태는 보존하되 새 조우의 전투 준비를 확정할 때 공격·회피 준비를 한 번 초기화한다. 이전 적에게 예약한 공격, 회피 유지, 기절 효과가 새 적에게 넘어가지 않는다. HP는 현행 규칙대로 유지하며 10층 보상 확정 시에만 기존 완전 회복을 적용한다.
- 줌은 월드에만 적용한다. 보스 HP, 조작 아이콘, 일시정지, 안전 영역은 확대하거나 흔들지 않는다.
- 전투 화면에 `승리`, `다음 층`, `보스 등장`, `사망했습니다` 같은 새 설명 문구를 추가하지 않는다. 상태는 캐릭터와 소리·빛·움직임으로 전달한다.

## 3. 일반 적 처치 → 다음 적: 기본 1.40초

| 타격 후 시각 | 화면 | 상태·입력 |
| --- | --- | --- |
| 0.00초 | 마지막 피해 숫자와 짧은 타격 정지, 적의 눈·가슴 빛이 꺼짐 | 처치·골드 확정, 남은 타격 취소, 예고 즉시 제거 |
| 0.00~0.12초 | 몸통이 1회 움찔하고 외곽 도트가 갈라짐 | 마지막 타격 정지는 이 구간 안에 포함. 별도 시간을 누적하지 않음 |
| 0.12~0.55초 | 몸체가 네모 도트로 분해. 짙은 청색 조각은 아래로, 소수 황동 조각은 짧게 튀고 사라짐 | 몸체가 먼저 비고 파편만 남는 시간 확보 |
| 0.55~1.20초 | 온이 전방으로 달리고 배경은 왼쪽으로 이동. 다음 적이 오른쪽에서 들어옴 | 공격·회피 잠금. 전진은 순간이동이 아닌 달리기 실루엣으로 읽힘 |
| 1.20~1.40초 | 양측이 정위치에 멈춤. 다음 Stage와 HP가 고정됨 | 기본 카메라·도트 격자 복귀, 아직 예고 없음 |
| 1.40초 이후 | 전투와 첫 예고 시작 | 첫 단발 피해는 빨라도 2.05초, 첫 연타 피해는 빨라도 2.30초에 발생 |

플레이어는 통합 보드 기준 발 좌표(548,590),1280×720 화면 가로의 약42.8% 지점을 기준으로 달린다. 출발 때 몸이 조금 앞으로 나가고 카메라가 따라오며 배경이 흘러야 한다. 화면 끝까지 뛰어 나갔다 다시 순간이동하는 구성은 쓰지 않는다. 다음 적의 위치가 고정된 뒤 발밑 HP를 표시한다.

일반 전환 1.40초를 매 처치마다 넣으면 전투 외 시간도 누적된다. 1~10층 구간에서 보상 선택 시간을 제외한 반복 피로를 확인하고, 최단 후보 1.10초(분해0.45 + 이동0.45 + 정착0.20)와 비교한다. **권고 기본은 1.40초**, 1.10초는 플레이테스트 비교값이다.

## 4. 중간 보스·보스 처치와 보상

순서: **처치 확정 → 몸체 분해 → 유물 3개 표시 → 하나 선택 → 보상 저장 → 전진 → 다음 적**.

- 중간 보스 분해는 0.70초, 보스 분해는 0.85초를 시작값으로 둔다. 일반 적보다 밝은 핵이 마지막까지 남지만 긴 승리 포즈는 없다.
- 골드와 종 파편(중간 보스1, 보스3), 고정된 유물 후보 3개를 처치 거래에 함께 기록한다. 분해 중 앱을 꺼도 다시 뽑지 않는다.
- 유물 선택에는 시간 제한을 두지 않는다. 카드가 들어오는 모션 중 누른 입력은 소모하고, 카드 정착 뒤 새 선택만 받는다. 보상 확인용 추가 버튼은 만들지 않는다.
- 선택 후 짧은 획득 표시 0.20초 → 전진0.65초 → 정착0.20초, 합계1.05초 후 다음 일반 전투를 연다. 다음 적이 보스라면 정착 이후 해당 등장 흐름을 진행한다.
- 기존 코드의 10층 체크포인트·HP 회복은 **유물 선택 확정과 같은 저장 거래**에서 유지한다. 보스 처치 후 선택 전 강제 종료 시에는 미결 유물 선택을 먼저 복구한다. 선택 없이 보상을 생략하고 새 런으로 이동하는 길을 열지 않는다.
- 5층은 재도전 체크포인트를 추가하지 않는다. 10층을 확정하면 사망 후 Stage11부터 재출전한다. 보상 후 계속 살아 있으면 곧바로 Stage11로 전진한다.
- 현재 MVP의 11층 완료 안내는 유지한다. 이 문서의 자연스러운 연속 흐름이 12~50층이나 50층 엔딩 구현 완료를 뜻하지 않는다.

등불은 실제 로비 아트 요소로 두며 별도의 로딩 화면처럼 보이지 않게 한다. 전체 화면을 번쩍 밝히거나 반복 점멸하지 않는다. 로비가 보이는 도중 강화·출전 버튼을 미리 눌러 오작동하지 않도록 입력은 마지막에 한 번만 연다. 사망 문구를 읽고 확인을 눌러야 하는 단계는 넣지 않는다.

## 6. 중간 보스·보스 등장

도착까지는 공통 전진을 사용하고, 보스와 플레이어가 정위치에 들어온 뒤 아래 시간을 시작한다. 기본 화면 배율을1.00×로 정의한다. 줌 중심은 보스 몸통·머리 사이이되 플레이어 실루엣과 지면 접점이 잘리지 않는 범위로 제한한다.

| 구간 | 중간 보스 총1.40초 | 보스 총1.80초 |
| --- | --- | --- |
| 시선 모으기 | 0.00~0.35초,1.00→1.12× | 0.00~0.45초,1.00→1.18× |
| 괴성 | 0.35~0.80초, 몸을 펴고 가슴빛·각진 충격링 | 0.45~1.10초, 무게를 싣는 자세·가슴빛·2단 충격링 |
| 줌아웃 | 0.80~1.20초,1.12→1.00× | 1.10~1.60초,1.18→1.00× |
| 정착 | 1.20~1.40초 | 1.60~1.80초 |

보스 HP는 줌아웃이 끝나는 마지막0.20초 정착에 **실제 전체값 그대로** 페이드인한다. 빈 막대에서 채워지는 가짜 회복 연출은 넣지 않는다. 등장 중 종 게이지와 공격 예고는 숨기고 Stage·일시정지만 고정한다. 괴성 충격링은 보스 뒤쪽으로 퍼지며 플레이어 주위의 공격 예고 궤적과 위치·형태를 다르게 한다. 무음에서도 괴성 자세와 가슴빛으로 등장 순간이 읽혀야 한다.

괴성은 단순한 큰 비명보다 **금속 마찰 + 숨 + 깨진 종의 잔향**을 조합한다. 미니보스는 짧고 가볍게, 보스는 낮은 층과 긴 잔향을 추가한다. 음량 차이로만 보스 격을 구분하지 않는다. 첫 예고가 시작될 때 잔향의 음량을 낮춰 타이밍 신호를 가리지 않는다.

최초 조우 후 같은 보스를 다시 만나면 중간 보스0.80초(0.18/0.24/0.18/0.20), 보스1.00초(0.22/0.33/0.25/0.20)로 줄인다. 짧은 줌인·괴성·줌아웃은 유지한다. 단순 배속보다 자세 유지 시간을 줄여 급격한 카메라 이동을 피한다. 조우 기억은 **캐릭터 ID + 회차 + 보스 ID** 단위의 등장 완료로 저장한다. 새로운 캐릭터·새 회차·새 보스의 첫 등장은 전체 길이를 사용한다. 첫 연출 도중 종료하면 완료로 기록하지 않지만, 해당 런 복구에서는 긴 연출을 되감지 않고 안전한 전투 대기로 이동한다. 그 보스와 나중에 새로 조우하면 전체 길이를 사용한다.

현재 5·10층의 첫 패턴은 연타 시작 예고900ms다. 중간 보스 첫 피해는 등장 시작에서 빨라도2.30초, 보스는2.70초 뒤다. 연출 중에 미리 예고를 예약하거나 줌이 끝나기 전에 입력을 열지 않는다.

## 7. 반복·감소 모션·중단

- **모션 감소**를 켜면 카메라 줌·충격 흔들림·배경의 큰 이동을 제거한다. 괴성 자세, 짧은 가슴빛, 파편, 고정 위치의 달리기 실루엣은 남긴다. 일반 전환1.40초·사망1.80초와 해당 등장 길이는 동일하게 유지한다. 빠르게 진행하는 옵션과 접근성 옵션을 묶지 않는다. 재조우 단축 정책은 별개로 동일하게 적용하며 게임 규칙·보상·첫 예고 시간도 유지한다.
- 기존 `ReducedShake`는 흔들림 감소만 담당한다. 새 카메라 이동까지 줄이려면 옵션의 범위와 표시 이름을 **모션 감소**로 확장할지 구현 단계에서 명시적으로 결정한다. 이 기획에서 기존 옵션이 이미 모든 연출을 제어한다고 주장하지 않는다.
- 무음·진동 끄기에서도 통과 가능한 시각 신호를 유지한다. 괴성은 필수 조작 정보가 아니다.
- 모든 전환에서 일시정지 버튼을 유지한다. 마지막0.20초의 정착을 포함해 일시정지 중 연출·오디오는 진행하지 않는다.
- 앱 복귀는 자동 전투로 돌입하지 않고 계속 버튼으로 재개한다. 전환을 복원하기 어렵다면 아래 안정 지점으로 이동해 계속을 기다린다. 남은 연출을 끝까지 강제로 재생하지 않는다.
- 일반 적 분해/전진 중 종료: 해당 처치 보상은 유지하고 다음 적의 전투 준비 상태로 복구. 이전 적을 다시 처치해 보상을 반복하지 않는다.
- 보스 분해 또는 유물 선택 중 종료: 처치 보상과 같은3후보를 복구해 선택으로 이동. 분해는 재생하지 않아도 된다.
- 유물 선택 확정 후 이동 중 종료: 이미 선택한 결과·체크포인트를 유지하고 다음 적 앞의 일시정지 상태로 복구. 후보 창을 다시 열지 않는다.
- 보스 등장 중 종료: 체력·전투 상태는 처음 진입 상태를 유지하고 기본 카메라의 일시정지 상태로 복구. 계속 시 온전한 첫 예고를 시작한다.
- 사망 암전 중 종료: 로비로 복구하고 짧은 등불 밝아짐만 적용한다. HP0 전투를 다시 살리지 않는다.
- 저장 실패는 현재처럼 진행을 막고 재시도를 제공한다. 암전이나 보상 카드 뒤에 저장 실패 안내가 가려지지 않도록 최상단에서 표시한다.

## 8. 향후 구현 계약과 검증 항목

표현 상태로 처치 분해·전진·등장·사망을 식별하되 전투 승패와 지갑의 소유자는 GameSession으로 유지한다. 다음 스테이지 예약과 처치 거래를 저장에 반영하고, 애니메이션의 완료 알림은 현재 거래 ID·대기 상태에 맞을 때 한 번만 전진을 승인한다. 타임라인을 다 보았는지와 골드를 받았는지는 다른 정보다. `runId:cycle:stage`를 처치·보상 거래의 안정적인 식별자로 활용할 수 있다.

추가 상태를 저장한다면 schemaVersion과 이전 저장 마이그레이션이 필요하다. 기존 enum 숫자를 중간 삽입으로 바꾸지 않는다. 미결 전환을 명시적으로 검증하고, 음수·존재하지 않는 다음 스테이지를 거부한다. 컷신에 사용하는 작은 타이머와 상태 이상을 게임 전체용 범용 연출 프레임워크로 확대하지 않는다.

필요 자산: 온 달리기4~6프레임, 온·적 공용 도트 분해 마스크/조각, 등불 점화3~4단계와 로비빛 마스크, 중간보스·보스 괴성2~3자세, 각진 충격링2종, 짧은 전진 배경 연결, 분해·발걸음·점화·괴성·잔향 오디오. 이 목록은 제작 요청 초안이며 아직 추가된 실제 자산이 아니다.

구현 후 확인할 핵심 사례:

1. 일반 적을 처치하는 동안 연타해도 다음 적에게 예약 공격이 새지 않는다.
2. 마지막 타격과 플레이어 사망 시각이 같을 때 현재의 **적 피해 우선** 규칙을 유지하고 이중 승패·이중 보상이 발생하지 않는다.
3. 4→5·9→10 진입은 전진 뒤 보스 등장,5→6·10→11은 보상 선택 뒤 전진으로 연결된다.
4. 분해·암전·줌의 매 구간에서 앱 종료/재개해도 골드·종 파편·유물 후보·체크포인트가 중복되거나 사라지지 않는다.
5. 줌아웃 종료 후 최초 공격까지650/900ms가 보장된다. 연출 속도·프레임 드롭이 그 시간을 줄이지 않는다.
6. 무음·모션 감소·640×360과 좁은 Safe Area에서도 보스 등장과 다음 전투의 시작이 구별된다.
7. 전환 1.40초와1.10초를 반복 플레이로 비교한다. 단일 연출의 멋만으로 고르지 않고 총 런 시간과 입력 대기 체감을 기록한다.

아트 담당과의 교차 검토: 황동 핵이 꺼졌다가 같은 색 등불로 이어지는 연결, 보스 가슴빛·각진 충격링, 온의 신규 달리기 프레임 필요성에 동의했다.

UI 담당 교차 검토 반영: 제안 길이와 줌1.12/1.18×에 동의. 보스HP는 마지막0.20초에 실제값으로 페이드인하고 가짜 채우기는 제외한다. 모션 감소는 기본 길이를 유지하도록 수정했다. 이동 중 입력 버퍼 폐기, 정착 후 온전한 첫 예고, 로비가 완전히 드러난 뒤 버튼 일괄 활성에 합의했다. 이는 문서·소스 기준 기획 검토이며 실제 플레이 승인으로 해석하지 않는다.

## 9. 통합본 최종 대조

사망0.55초 분해·0.70~0.85초 어둠·1.60초 공개 완료, 보스별 최초·재조우 구간을 통합 JSON과 보드 코드에 맞췄다. 등장 완료 기억은 캐릭터·회차·보스ID 단위로 확정하며 공격·회피 준비 초기화가 현행 코드에서 달라지는 점을 명시했다.

브라우저 file 정책으로 보드를 직접 열 수 없어 브라우저 접근을 우회하지 않았다. 검토 범위는 HTML·JS·JSON·문서의 소스 정합성이며 실제 렌더·소리·손맛 검증은 포함하지 않는다.

최종 재대조에서 Stage4 표본을 `gate_00`(성문 파수병)·첫예고 `outer_arc`로 고친 것과,1층 시작→10층 도착의 전환 비용을 **12.95초**(일반8×1.40 + 5층 분해0.70 + 선택후1.05, 선택 대기·보스 등장 제외)로 수정한 것을 확인했다. 통합 상세 명세에도 공격·회피 준비 초기화를 명시적 변경으로 기록했다. 전투 전환 담당 범위의 기획·소스 정합성 검토에 동의하며 남은 필수 수정 의견은 없다.
