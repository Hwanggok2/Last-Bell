## 2. 강화 부족분 계산과 사용자 확인

골드가 충분하면 원래 `+` 강화 구매를 수행한다. 부족하고 다음 레벨이 유효할 때만 확인 창을 연다. MAX 스탯이나 로비 밖에서는 부족분 교환을 유도하지 않는다. 아래의 `강화 후`는 사용자가 교환 완료 뒤 다시 `+`를 눌렀을 때다.

| 보유 골드B | 강화 비용C | 부족분 | N파편 | 획득G | 교환 직후 골드 | 별도 강화 후 골드 |
|---:|---:|---:|---:|---:|---:|---:|
|0 |150 |150 |2 |200 |200 |50 |
|49 |150 |101 |2 |200 |249 |99 |
|50 |150 |100 |1 |100 |150 |0 |
|149 |150 |1 |1 |100 |249 |99 |
|150 |150 |0 |0 |0 |150 |0 |
|0 |60 |60 |1 |100 |100 |40 |

**[산술]** 부족분이 양수면 마지막 강화 후 남는 골드는0~99 G다. 현재 최대 단일 강화 비용150 G에서 필요한 파편은 최대2개다. 충분한 골드를 가진150/150 사례는 교환 창 없이 바로 강화한다. 보유 파편이1개인데0/150 사례를 누르면2개가 필요하므로 교환을 실행하지 않는다. 가진1개만 부분 교환하거나 남은1개를 자동 결제하지 않는다.

예시 문구: `종 파편 2개를 소모해 200골드를 획득하시겠습니까?` / 보조 설명 `교환 후 강화하려면 +를 다시 누르세요.` 확인 성공 후 레벨·강화 비용 차감은 그대로 두고, 새 잔액을 표시한다. 교환으로 슬롯 예산이 줄어드는 기존 규칙은 유지하며 슬롯용 강제 예약은 추가하지 않는다.

### 확인 중 값 변경과 중복 처리

**[제안]** 견적에는 계정·캐릭터·스탯·현재/목표 레벨·강화 가격 버전·교환비율 버전·골드/파편 잔액 버전·N/G를 연결한다. 확인 시 최신 상태를 한 거래에서 다시 검사한다.

- 가격·현재 레벨·잔액·비율이 바뀌면 기존 견적은 실행하지 않고 새 계산을 보여 준다. N이 줄거나 늘어도 바뀐 양을 묵시적으로 차감하지 않는다. 골드가 충분해졌다면 교환 창을 닫고 원래 강화 `+`로 돌아간다.
- 캐릭터/스탯 변경·MAX 도달·출전 시작으로 대상이 유효하지 않으면 견적을 닫는다. 교환을 원래와 다른 강화 대상에 넘기지 않는다.
- 견적에 연결된 요청ID는 일회용이다. 같은 확인의 연속 터치·응답 유실 후 재시도는 같은 거래 결과를 돌려주며 재차감하지 않는다. 두 기기가 서로 다른 요청으로 같은 잔액을 쓰려 해도 잔액 버전 검사와 원자적 차감으로 하나만 확정한다.
- N파편 차감과100N골드 지급을 함께 저장한다. 성공 응답 전 종료돼도 원장 조회로 결과를 복구한다. 무료/유료 파편의 출처 추적·무료분 우선 사용은 v3 계약을 유지한다.
- 다음 `+` 강화는 별도 요청ID·최신 가격/잔액 검사로 처리한다. 확인 창을 연 `+` 입력이나 누르고 있던 입력을 강화로 재사용하지 않는다.

위 규칙은 기존 확정형 골드 교환의 진입 편의를 바꾸며, 교환 비율·현금 패키지 가격·슬롯 비용을 바꾸지 않는다.

## 3. 후보3개·Lv.5·MAX 처리

**[제안]** Lv.0은 미보유를 뜻하고 선택 시1,1~4는 선택 시+1,5는 MAX 전환이다. 카드는 이름·현재 레벨·결과를 보여 준다: `미보유 → Lv.1`, `Lv.3 → Lv.4`, `MAX · 골드 60`. 장착 슬롯이 꽉 차 있어도 선택·보유 레벨 증가를 막지 않으며 보상을 받았다고 자동 장착하지 않는다.

전환 골드는 **선택된 유물의 예전 고정 드랍층이 아니라 방금 처치한 적의 구역**으로 정한다. 예를 들어25층에서 어떤 MAX 유물을 골라도60 G다. 같은 구역의 중간보스와 보스는 같은 전환액이고, 기본 골드의 중간×3/보스×5를 다시 곱하지 않는다. 행운·별점·NG+ 배율도 전환액에 적용하지 않는다.

전체10종을 매번 같은 확률로 추첨한다. 옛 `relic_50` 같은 ID를 보존해도50층 해금 조건으로 해석하지 않는다. 초기5층에서도 모든 유물에 후보로 나올 기회가 생긴다. 후보 선택은 유료 뽑기나 파편 소모가 아니며 현금 재추첨도 없다.

**[산술]** 서로 다른3개 조합은 `C(10,3)=120`개이며 각 조합 확률은1/120이다. 각 유물의 후보 등장 확률은36/120=30%다. 플레이어가 선택하는 최종 획득 확률까지 각10%로 동일하다는 뜻은 아니다.

| 미완성 유물 종류 수 |3후보 모두 MAX일 확률 | 처리 |
|---:|---:|---|
|3 |35/120≈29.17% | MAX 카드3개 중1개 선택 시 고지된 골드1회 |
|2 |56/120≈46.67% | 남은2종을 강제로 넣거나 후보를 복제하지 않음 |
|1 |84/120=70% | 남은1종 등장 확률30%; 미등장 시 MAX 골드 선택 가능 |
|0 |100% | 계속 서로 다른3유물의 MAX 카드를 표시하고1개만 골드로 전환 |

미완성1종이 남았을 때 평균 후보 등장 대기 횟수는1/0.3≈3.33회다. 이는 **한 번의 레벨 증가 기회**에 대한 평균이며 남은 모든 레벨 완성 보장이 아니다. 특정 유물 또는 미완성 후보 보장은 추가하지 않는다. 균등 추첨·항상3후보·MAX 포함이라는 선택의 결과를 UI와 기획서에 숨기지 않는다.

전체10종을 미보유에서Lv.5까지 올리는 데 최소50번의 유물 증가가 필요하다. 50층 경로당 선택 기회는10회여서 산술상 최소5회차 분량이지만, 현재 체크포인트 중간보스 반복·다른 캐릭터 보상도 합산되므로 완주5회를 필수로 요구하는 것은 아니다. MAX 골드를 선택하거나 원하는 후보가 안 나오면 실제 처치 수는 더 늘어난다. 한 번50층 완주로10종을 모두 획득한다는 v3 보장은 폐기한다.

모든 유물·캐릭터 강화·슬롯이 끝나도 정상 처치 보상과 MAX 골드는 지급·보존한다. 기존 정책대로 골드 소비처가 없으면 교환을, 모든 파편 소비처가 없으면 직판을 숨긴다. 유물 레벨은 무료 선택으로만 증가하므로 미완성 유물이 있다는 이유만으로 파편 직판을 다시 켜지 않는다.

## 4. 연속 진행·선택 결과의 저장 경계

유물 선택은 처치 결과에 매달린 **미처리 선택권1개**다. 골드·파편 지급 여부와 선택 완료 여부를 같은 플래그 하나로 처리하지 않는다.

1. **처치 확정·선지급:** 해당 적의 안정적인 처치 결과ID로 기본 골드·고정 파편 지급과 후보3ID·선택권ID·선지급 완료 상태를 함께 저장한다. 후보는 이때 한 번만 추첨·저장한다. 이 단계에서는 보스 체크포인트·전회복·50완주·다음 회차 준비를 확정하지 않는다.50층도 처치 후 선택 대기이며 아직 완주 확정 전이다. 같은 처치ID 재처리는 이미 저장한 결과만 반환한다.
2. **선택 대기:** 전투 시계·공격 입력·자동 다음 층 진입을 멈춘다. 종료/재실행 시 선지급 완료 상태와 같은 후보·선택권을 복구하고, 기본 골드·파편을 다시 주지 않는다. 체크포인트가 아직 이전 값이어도 보스를 다시 싸우거나 선택을 건너뛰지 못한다. 미처리 선택권 복구를 우선하며 로비 출전·캐릭터 교체·NG+ 시작을 막는다. 강제 자동 선택·타이머·취소 후 재추첨은 없다.
3. **선택 확정:** 선택권ID·선택ID·제시 버전을 검사한다. 유물Lv.1/+1 또는 MAX 골드 지급 중 정확히 하나, 선택권 소모, 현재 출전의 해당 장착 유물 효과/HP 갱신, 필요한 체크포인트·회복·다음 상태를 한 결과로 원자적으로 저장한다.10·20·30·40층은 여기서 체크포인트와 전회복을 확정한다.50층은 여기서 완주·다음 회차 준비를 확정한다. 기본 골드·파편은 선지급됐으므로 이 단계에서 추가 지급하지 않는다. 두 카드 동시 입력은 먼저 확정한1개만 유효하다.
4. **후속 진행:** 선택 저장 성공 뒤 다음 층으로 자동 진행한다.50층은 저장 성공 뒤 엔딩/로비로 가며 다음 출전에서NG+1층 시작을 한 번만 적용한다. 선택 커밋 후 응답이 유실되면 기존 결과의 유물·HP·진행 상태를 복구한다. 레벨 증가·MAX 골드·HP 증가분·체크포인트·회차를 다시 적용하지 않는다. 선택 저장 실패 시 같은 선택 대기에 머문다.

계정 공유 유물 레벨이 다른 기기에서 바뀌었다면 후보ID는 유지하고 결과 라벨만 최신 상태로 다시 보여 준다. `Lv.4→5`로 보인 선택을 확인 없이 `MAX 골드`로 바꾸지 않는다. 후보 생성 버전과 표시 결과 버전을 구분하며, 재확인 중에도 새 후보를 뽑지 않는다.

**출전 중 능력치 — 교차 합의 반영:** 현재 출전 캐릭터가 장착한 유물을 선택해 레벨이 오르면, 선택 커밋 뒤 **다음 적부터 그 유물 효과만** 반영한다. 스탯 강화 레벨·장착 조합은 출전 중 고정한다. 미장착 신규/중복 유물은 계정 보유함에만 반영하며 자동 장착하지 않는다. 카드 미리보기와 MAX 골드 선택은 유물 능력을 올리지 않는다. 기존의 ‘모든 유물 효과는 다음 새 출전까지 보류’ 권고는 폐기한다.

장착 HP 유물의 유효 레벨 증가로 최대HP가 늘면, 선택 커밋에서 다음 전투에 쓸 상태를 아래 순서로 한 번 계산·저장한다. 합산 상한을 적용한 실제 최대HP 차이를 사용한다.

```text
delta = max(0, newMaxHP - oldMaxHP)
nextHP = min(newMaxHP, oldHP + delta)
10/20/30/40층이면 그 뒤 nextHP = newMaxHP
```

예를 들어 최대100/현재40에서 새 최대110이 되면 다음HP는50이다. 같은 선택 요청을 다시 보내도60으로 회복되지 않는다.10단위 보스라면 증가분 적용 후110까지 전회복한다. 상한 때문에 최대HP가 늘지 않거나, 미장착 유물·MAX 전환·미리보기라면 증가분 회복은0이다.50층은 선택 후 출전을 종료하므로 다음 전투를 열거나 회복을 이용한 추가 행동을 만들지 않는다.

다른 캐릭터의 중단 출전은 해당 캐릭터의 저장된 적용 유물 레벨·최대HP·현재HP를 유지한다. 계정 보유 레벨이 올랐다는 이유만으로 중단된 출전을 덮어쓰지 않으며, 그 캐릭터의 새 출전 시작 때 최신 보유 레벨을 읽는다. 선택ID와 현재 출전ID를 묶어 다른 캐릭터에게 HP 증가분이 적용되지 않게 한다.

## 5. 기존 골드·수익 가정에 미치는 영향

**유지되는 기본값:** 행운0·추가 처치0·교환0에서50층 기본 골드8,000 G/파편20개다. 4스탯 최대7,120 G와의 차액880 G도 같다. 무교환 슬롯4+8파편의 예산은30층 완료 시 충족된다. 부족분 교환을 사용하면 그만큼 슬롯 예산이 늦어지며 별도 무료 파편을 추가하지 않는다.

**폐기되는 가정:** ‘보유한 유물이면 곧바로 구역별 골드로 전환’과 ‘두 번째 완주부터 중복 골드600 G가 항상 추가’는 더 이상 성립하지 않는다. 보유Lv.1~4 선택은 레벨만 오르고, MAX를 고른 횟수에 대해서만 골드가 추가된다.

`MAX 전환 골드 = Σ(각 선택권에서 MAX를 골랐으면 해당 처치 구역 금액, 아니면0)`이다. 50층 정상 경로의 추가 전환 골드는0~600 G이고, 전부 MAX인 계정에서10개 선택을 모두 끝내면600 G다. 기존 `duplicateGoldPerZone` 필드는 일반 중복에 쓰지 말고 `maxRelicGoldPerZone` 같은 전용 의미로 교체할 것을 권고한다. 전투 기본 골드와 별도로 더한다.

중간보스 반복1회의 기본 골드280/490/700/910/1,120 G와 파편1개는 유지한다. 종전 반복 유물 골드20/40/60/80/100 G는 이제 MAX를 고를 때만 받는다. 유물 성장이 완료되기 전에는 같은 반복의 골드 수입이 v3보다 줄 수 있지만 레벨 증가를 대신 받는다. 기본 성장 예산은 원래 중복 골드 없이 계산했으므로 비용표를 올리거나 파편 지급을 줄일 근거는 없다.

직판4/12/20개=1,100/3,300/5,500원과 v3 민감도 입력을 유지한다. MAU2,000, 결제율0/0.5/1.5/3%, 월ARPPU0/1,100/2,200/3,300원, 환불2%·수수료20%·광고0일 때 수취액0/7,840/47,040/141,120원이라는 **가정 산술**은 변하지 않는다. 교환 진입이 쉬워졌거나 중복 골드가 줄었다는 이유만으로 구매율을 상향하지 않는다. 유물 선택 시간·레벨 성장·후반 후보 편차가 실제 반복 시간과 구매 수요에 미치는 영향은 미측정이다.
