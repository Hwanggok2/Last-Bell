## 2. 추천 성장 공식

`S=1..5`는 **캐릭터별·스탯별 고정 성장 적성**이다. 별 획득·승급은 없다. 온은공격/HP/행운/공명3/3/3/3, 담은2/5/2/3, 린은4/2/4/2다. 각 식은 해당 스탯의 독립 레벨과 별점을 사용한다. 출전할 때 능력·장착을 고정하며 전투 중 강화는 없다.

```text
L = 0..50
q(S) = 1 + 0.05×(S-1)       # 1.00 / 1.05 / 1.10 / 1.15 / 1.20
b(L) = floor(max(0,L-1)/10) # Lv11,21,31,41에서 증가
E(L,S) = q(S) × [L+10×b(L)]

공격 A = (10 + 3q×L공격) × [2 + 0.15×(S공격-1)]^b(L공격)
HP H = round[(100 + 20q×L체력) × [1.6 + 0.1×(S체력-1)]^b(L체력)]
치명 확률 p = min(0.30, 0.05 + 0.0015×E(L행운,S))
전투 드랍 골드 배율 M = 1 + min(0.20, 0.0018×E(L행운,S))
기절 적 피해 배율 R = min(1.75, 1.40 + 0.002×E(L공명,S))
치명 피해 배율 = 1.50 고정
```

q도 각 스탯의S를 사용한다. 양수HP 반올림은 `floor(x+0.5)`로 통일한다. 공격은 계산 중 소수를 유지하고 최종1회 피해에서 한 번 반올림한다. Lv0은 별점과 무관하게A10/H100/p5%/M1/R1.4다. 공명은 기절량·시간을 바꾸지 않고 기절 중 공격 피해만 더한다.

**교차 조정 제안:** 행운 골드 상한은 시장안의20%를 채택한다. 시장 초안의 `0.002×E`는 높은 별에서Lv50 전에 상한에 닿아 마지막 구매의 골드 증가가0이 된다. **계수0.0018**이면★5 Lv50도+19.44%로 모든 구매와 돌파가 유효하다. 상한20%는 향후 합산 효과까지 적용한다. `floor(층 기본 골드×M)`으로 처치별 한 번 내림하며 종파편1/3·현금 구매량·교환100G·유물 중복 전환에는 적용하지 않는다. 정수 지급액은 내림 때문에 인접 레벨에서 같을 수 있다.

## 3. 50층·NG+의 고정 적 표

**제안:** 적은 플레이어 레벨·별점·재화에 자동 대응하지 않는다. 아래 구역별 상수를 데이터로 저장한다. 큰 돌파가 필요한 구역 경계는 강하지만 입장 제한·강제 사망은 없다. 첫 구역은Lv0의 기본10/100에 맞추고 이후 구역은 별도의 출전 스냅샷으로 검산한다.

```text
s = 1..50, n = 캐릭터의NG+회차(첫 회차0)
z = floor((s-1)/10), j = (s-1)%10
종류 = s%10==0이면보스, 아니고s%10==5이면중간, 나머지일반
HP종류배율 = 일반1 / 중간1.8 / 보스3.2
피해종류배율 = 일반1 / 중간1.15 / 보스1.3

n==0: HP기초=[120,1050,4200,13500,40000][z]
      피해기초=[8,40,110,280,650][z], NG배율=각1
n>=1: HP기초=[22000,26000,31000,37000,44000][z]
      피해기초=[500,600,700,800,900][z]
      NG_HP=1.35^(n-1), NG_피해=1.20^(n-1)

적HP = round(HP기초×1.07^j×HP종류배율×NG_HP)
적1회피해 = ceil(피해기초×1.045^j×피해종류배율×NG_피해)
일반 공격 간격P=[1.80,1.65,1.50,1.40,1.30][z]초
중간 공격 간격P=[1.60,1.50,1.40,1.30,1.20][z]초
보스 공격 간격P=[1.50,1.40,1.30,1.20,1.10][z]초
```

P는 아래 평균 검산의 실효 타격 간격이다. 연타 데이터도 **회피 가능한 타격 간격450ms 이상**을 지키고, 연타 뒤 대기로 구역 평균P에 맞춘다. NG+는 HP/피해를 올리며 예고·회피창·연타 하한을 몰래 줄이지 않는다. NG+1부터 별도 고정 기초표를 쓰는 이유는 최종 강화 캐릭터가 첫 구역을 모두1타격으로 건너뛰는 폭을 줄이기 위해서다. 적이 캐릭터 스탯을 읽는 공식은 아니다.

## 4. 출전 능력을 고정한 10전 생존 검산

**가정:** 유물 없음, 시작 최대HP, 같은 캐릭터의 네 스탯을 표의L에 고정, 해당10층 동안 성장 없음. 기준 입력은공격 가동률u=.90, 방향·시간을 모두 맞춘 회피q=.92, 전체 타격 중 완벽p=.35다. 학습은u=.85/q=.85/p=.15다. 4방향에서 이 성공률이 실제로 나오는지 확인하지 않았다.

```text
E[g] = 20(q-p)+40p-20(1-q)  # 기준23.8
F = 100/E[g]×P
일반DPS = A/0.5×u×(1-0.12/P)×(1+0.5×치명확률)
기절DPS = A/0.5×u×R×(1+0.5×치명확률)
진행 = 일반F초 → 기절T초 → 일반/축적불가2초 → 반복
T = 일반1.5 / 중간1.2 / 보스1.0
마지막 구간은 남은HP/DPS만 사용
예상 피해 = 기절 외 시간/P × (1-q) × 적1회피해
```

`100/E[g]`는 실제 확률적 기절 도달시간의 기댓값과 같지 않다. 게이지 경계·연속 실수·개별 공격 취소·첫/마지막 타격 반올림은 이산 시제품에서 확인해야 한다. 아래 초는 **해당 고정 능력으로 생존한다고 가정한 순수 전투량**이다. 층 전환·강화·귀환·사망 재도전 시간을 포함하지 않으며 서로 다른L 행을 합쳐1회 완주시간으로 쓰지 않는다.
