# 마지막 종지기 v2 — 전투·성장·유물·제작 검토

작성일: 2026-10-21 KST  
상태: **수정 계약·산식 검산·통합 파일 교차 검토 완료 / 구현·실기기 검증 미실시**

## 1. 이번 변경의 우선순위

사용자의 새 요청에 따라 가로 화면·낮은 지면, 위/아래/뒤 방향회피, 일반/완벽회피의 차등 기절 축적, 재화 능력치 강화와10레벨 돌파, 5·15·25 중간보스와10·20·30 보스, 유물 드랍·장착 확장을 검토한다. 기존의 성장 없음·울림1회·12전·700ms 회피 쿨타임은 v2의 전제가 아니다. **이전187초 전투·216초 런·옛 보스 TTK는 v2에서 무효다.**

3방향 회피를 주 후보로, 1버튼 회피를 동일 패턴·동일 시간값의 비교시험으로 둔다. 원작에서 차용할 구조와 신작 초기 수치를 구별한다. 아래 ms·배율은 원작을 측정하거나 복원한 값이 아니다.

이미 읽은 `unity-project-foundation`과 `game-ui-wireframe-copy`의 데이터/런타임/저장 프리팹·입력 가독성 원칙을 적용한다. 이번에는 `combat-v2.md`만 작성하며 소스 구현과 다른 담당 파일 편집은 하지 않는다.

회피의260ms는 **160ms 판정+100ms 동작 회복**을 합친 재입력 최소 간격이다. 사용자에게 별도700ms 쿨다운 원형 게이지를 제시하지 않는다. 100ms의 취약 구간이 실제로 존재하며 유물·강화로 없애지 않는다. 가로 화면의 최종 bounds/anchor는 UI 담당 소유다.

## 3. 성장과30단계 검산 출발식

```text
공격력 레벨 LA = 1..30, 체력 레벨 LH = 1..30
공격 돌파 횟수 bA = floor(LA/10), 체력 돌파 횟수 bH = floor(LH/10)
공격력 A(LA) = 10 × 1.045^(LA-1) × 1.25^bA
최대HP H(LH) = round(100 × 1.035^(LH-1) × 1.20^bH)

적 단계 s = 1..30
적HP = round(180 × 1.065^(s-1) × 종류HP배율)
적피해 = ceil(12 × 1.055^(s-1) × 종류피해배율)
종류HP배율 = 일반1 / 중간보스2.1 / 보스3.5
종류피해배율 = 일반1 / 중간보스1.15 / 보스1.30
```

적의 수치는 플레이어 실제 레벨에 맞춰 자동 상승하지 않는다. 돌파 직후 같은 적을 더 빨리 잡는 효과가 남는다. 구매 비용·보상 수급은 시장 담당의 후속 조정 대상이며, **단계s에서 두 능력치가 모두 레벨s라는 검산 가정은 실제 수급 보장이 아니다.** 구매·장착은 전투 밖에서만 가능하고 다음 전투 시작 때 능력치를 고정한다.

현재 계산 출발점은 공격 효율90%, 올바른 회피92%, 전체 타격 중 완벽회피35%, 적 타격1회당 공격 기회 손실0.12초, 유물 없음이다. 기절 이전/중/재축적 대기의 서로 다른 DPS를 나누는 유한 전투 근사로 계산했다. 기준 결과는 전투 약420.4초 + 5전 구간별 전환9초×6 = **474.4초(약7분54초)**다. 이는 성장·메뉴·재도전·유물 선택을 제외한 가상 완주 경로이며 실제 캠페인 완료 시간은 아니다.

**최종 조정:** 총괄이 일반전의 기절 체감 문제를 검토하고 **일반+20/완벽+40을 수용했다.** 초기15/30 및425.3초 전투·479.3초 합계는 폐기한다. 15/30은 첫 일반 적의 기절이 처치 약0.27초 전에 생겼지만,20/40 기준에서는 첫 기절 약7.56초·처치약9.96초로 보상 시간이 확보된다. 이것은 계산상의 개선이며 실제 체감 확인은 남아 있다.

## 4. 빠른 방향회피·기절의 경계 계약

### 4.1 방향, 입력과 실패 이유

| 적 공격 | 올바른 회피 | 시각 단서 |
|---|---|---|
| 발목을 쓸어오는 낮은 궤적 | 위 | 낮은 가로 궤적+발을 올릴 공간 |
| 머리 높이를 가로지르는 궤적 | 아래 | 높은 가로 궤적+몸을 낮출 공간 |
| 몸통을 향한 찌르기 | 뒤 | 전방으로 뻗는 직선+후방 잔상 방향 |

방향 표시는 **적이 움직이는 방향**과 **플레이어가 피할 방향**을 혼용하지 않는다. 초기 학습에서는 안전 방향 아이콘을 함께 보여주고, 숙련 구간도 궤적·자세가 유지되게 한다. 뒤로 빠지기를 모든 공격의 정답으로 만들지 않는다. 회피는 자리에서 이루어지는 동작이며 매번 동일 전투 위치로 복귀한다.

- Pointer Down 시각에 명령을 수집한다. 수락 시 방향을 고정하며 동작 도중 바꾸지 않는다.
- 여러 방향 명령은 타임스탬프 순서상 첫 수락1개만 사용한다. 완전히 같은 시각이면 고정된 처리 순서를 사용하고 **현재 적 공격의 정답을 보고 선택하지 않는다.**
- 160ms 판정은 전방위 무적이 아니다. 올바른 방향일 때 해당 타격을 피할 수 있는 태그다. 다른 방향이면 창 안이어도 피해를 받는다.
- 회복100ms 안의 입력을 저장해 다음 회피로 자동 발동시키지 않는다. 홀드·새 손가락·버튼을 바꿔 누르기로 기존 회피 시각을 갱신하지 않는다.
- 같은 시각에 유효한 회피와 공격 명령이 오면 회피를 먼저 처리한다. 공격 준비100ms 중 회피되면 적중 취소, 공격500ms 간격은 그대로 남긴다.
- 맞은 뒤 조작을 장시간 잠그거나 다음 타격까지 무적을 주지 않는다. 피격 표시와 조작 가능 상태를 분리한다. 동일 `hitId`만 한 번 피해를 준다.
- `정답 방향+Δ≤60ms`는 완벽, `정답 방향+60<Δ≤160ms`는 일반 회피다. 그 외 실제 피격은 피해와 게이지-20. 게이지 감소는 입력 실패 횟수가 아니라 **실제 맞은 타격당1회**다.
- 기록 가능한 원인만 안내한다. 창 안의 다른 방향은 `방향이 달랐어요`, 너무 이른 입력은 `조금 빨랐어요`. 입력 자체가 없을 때 임의로 기기 지연 탓을 하거나 늦은 입력이라고 단정하지 않는다.

**450ms 연타의 여유:** 첫 타격 직전에 늦게 피하고 다음 타격에는160ms 일찍 피하는 경우에도 입력 간격은450-160=290ms다. 재입력 최소260ms보다30ms 길다. 같은 전투 시계로 비교해야 하며 낮은 프레임에서290ms를 몇 프레임으로 반올림해 판정하지 않는다.

### 4.2 기절의 단일 상태기계

`Accumulating → Stunned → Recovering → Accumulating`을 적 상태로 관리한다. 기존 `Echo Charged/Ready`와800ms 소비창은 삭제한다.

| 상태/사건 | 규칙 |
|---|---|
| 축적 중 일반/완벽 회피 | 각각+20/+40. 완벽은20+40을 모두 받는 것이 아님 |
| 축적 중 실제 피격 | 게이지-20, 최소0. 전량 초기화하지 않음 |
| 100 이상 도달 | 해당 타격 회피 성공을 먼저 확정하고 즉시 기절. 남은 연속 타격·예고 이벤트의 세대를 폐기 |
| 초과치 | 예:80+40=120이면 기절1회, 남는20은 폐기. 기절 종료 뒤 미리 충전하지 않음 |
| 기절 중 | 적 타격·이동 없음. 플레이어 일반 공격 피해×1.40. 공격 횟수는500ms 간격으로 제한 |
| 피해로 조기 해제 | 없음. 적HP가0이면 처치가 우선 |
| 기절 끝 | 정상 패턴의 첫 단계부터 온전한 예고. 취소된2·3번째 타격으로 돌아가지 않음 |
| 종료 후2,000ms | 공격은 할 수 있으나 기절 게이지 축적0. 회피 성공·실패는 정상 판정. UI는 게이지에 잠깐 회복 표시 |
| 재축적 시작 | 게이지0부터. 회복 동안 놓친 축적을 나중에 몰아서 지급하지 않음 |
| 적 교체·재시도·이탈 | 게이지/기절/회복 타이머 초기화 |

기절 중 피해 배율은 `stunStart≤적중시각<stunEnd`에서 적용한다. 공격 준비를 기절 중 시작했어도 적중이 종료 뒤면 일반 피해다. 같은 시각의 회피 성공으로 기절이 발생한 뒤 이미 예약된 플레이어 공격이 적중하면 기절 배율을 받을 수 있다. 플레이어HP0이면 그 시각 이후의 공격을 취소한다.

기절 종료 후2초 동안도 회피가 필요하다. 그 시간에 기절량을 얻지 못하는 것을 숨기지 않으며, 별도 플레이어 필살기 게이지를 더하지 않는다. 공격은 적HP만 줄이고 기절량은 회피에서만 얻는다.

### 4.3 예고와 빠른 연타를 함께 유지하는 방법

연타450ms에 단타 예고650ms를 각각 순서대로 붙일 수는 없다. 따라서 **연속 묶음의 전체 방향 순서를 첫 타격900ms 전에 공개**하고, 현재 타격만 직전250ms 동안 강조한다. 다음 방향을 처음 공개하는 시간이250ms라는 뜻이 아니다. 이미 공개된2~3개 방향 아이콘은 해당 묶음이 끝날 때까지 남긴다.

| 구간/종류 | 평균 타격 간격P | 실제 간격 예시 | 최초 예고/후속 강조 |
|---|---:|---|---|
| 일반1~10 | 1.80초 | 단타1,650/1,950ms 반복 | 단타650~950ms |
| 일반11~20 | 1.60초 | 단타1,450/1,750ms 반복 | 같은 창, 자세·방향 순서 변화 |
| 일반21~30 | 1.45초 | 단타1,300/1,600ms 반복 | 같은 창, 이미 배운 지연 조합 |
| 중간보스5 | 1.60초 | 2연타700/2,500ms | 전체900ms / 후속250ms |
| 보스10 | 1.50초 | 2연타600/2,400ms | 전체900ms / 후속250ms |
| 중간보스15 | 1.45초 | 2연타600/2,300ms | 전체900ms / 후속250ms |
| 보스20 | 1.30초 | 3연타500/500/2,900ms | 전체900ms / 후속250ms |
| 중간보스25 | 1.30초 | 3연타450/550/2,900ms | 전체900ms / 후속250ms |
| 보스30 | 1.20초 | 3연타450/650/2,500ms | 전체900ms / 후속250ms |

간격은 현재 타격에서 다음 타격까지다. 긴 마지막 간격에는 다음 묶음의 전체 예고가 들어간다. 1단계 위, 2단계 아래, 3단계 뒤, 4단계 혼합, 5단계2연타 순서로 가르친다. 20단계 이후에도 방향을 사후 변경하거나 무음 상태에서 구별 불가능한 공격을 넣지 않는다.

### 4.4 연타 악용 검산과 한계

방향이 균등하고 입력 위상이 독립이라는 거친 가정에서 무작정 회피의 시간 점유율은160/260=61.5%, 올바른 방향까지 맞을 비율은 약20.5%다. 이것만으로 모든 스팸이 실패한다고 증명하지는 않는다.

### 5.3 기절을 포함한 계산 방식과 시간 한계

```text
q = 올바른 회피 비율 = 0.92
p = 전체 타격 중 완벽회피 비율 = 0.35 (p≤q)
u = 공격 입력 효율 = 0.90
w = 적 타격당 공격 기회 손실 = 0.12초

평균 순기절량 g = 20(q-p)+40p-20(1-q) = 23.8/타격
기절까지 활성시간 F = 100/g × 평균 타격간격P
활성 DPS = 공격력/0.5 × u × (1-w/P)
기절 DPS = 공격력/0.5 × u ×1.40

첫 활성F → 기절T → 축적불가 활성2초 → 다음 활성F → ...
각 구간에서 남은HP/DPS가 구간 길이보다 작으면 그 시각에 종료한다.
기절하기 전에 처치되는 적에게 기절 DPS를 미리 나눠 주지 않는다.
```

이 계산은 **평균 기절량으로 실제 확률적 게이지를 치환한 유한 구간 근사**다. 게이지0/100 경계, 연속 실수 상관관계, 개별 패턴 취소 시점, 첫 타격 대기, 마지막 공격 초과 피해는 정확히 재현하지 않는다. `100/E[g]`는 실제 기절 도달시간의 기댓값과 일반적으로 같지 않다. 소수점 표시는 산식 재현을 위한 것이며 정확한 플레이 시간을 뜻하지 않는다.

전환 예산9초/묶음은 진입 준비1초+중간4전환 각1.25초+묶음 결과3초다. 이는 다섯 전투의 편의상 시간 집계이며 패배하면 묶음 시작으로 돌아간다는 뜻이 아니다. 강화·유물 장착·재화 확인·서사·플레이어가 머문 시간은 제외했다. 같은 가정에서 숙련 프로필은449.1초다.

### 6.2 드랍·재시도·슬롯 계약

- 5/10/15/20/25/30 처치마다 지정 유물을1개 확정 드랍하는 시장안에 동의한다. 신규면 보유 추가, 이미 소유했다면 시장표의 골드로 전환한다. 새 유물과 중복 전환을 동시에 주지 않는다.
- 기본 슬롯1개는 무료. 첫5단계 유물을 바로 장착할 수 있다.
- 최신 시장·총괄 기준은2칸을20새벽석,3칸을40새벽석으로 **직접 구매**한다. 구매 가능 조건도각각10/20단계 보스 클리어다. 무반복 첫 처치 수급을 따르면 그 시점에 비용이 모인다.
- 따라서 “10/20보스가 슬롯을 준다”가 아니라 **“10/20보스까지의 새벽석으로 플레이어가 슬롯을 산다”**가 정확하다. 슬롯 가격·보스 새벽석·교환 비율의 최종 결정은 시장 담당 소유다.
- 슬롯은 구매한 순간 영구 저장한다. 유물 장착 교체는 전투 밖에서 무료이며, 전투 시작 때 슬롯 수·유물ID·강화 레벨 스냅샷을 고정한다.
- 사망한 스테이지의 적HP·기절량은 다음 시도에 이월하지 않는다. 이미 확정된 이전 전리품·강화·슬롯 구매는 잃지 않는다.
- 전투마다 새 `attemptId`를 부여한다. 재도전 실패에 처치 보상은 없고, 성공한 재플레이에는 시장표의 반복 보상을 준다. 무한 실패로 보상을 생산하지 않는다.

총괄의 최신안은 미구매 슬롯 비용을 **강제로 예약하지 않고 일반 교환을 허용**하는 방향이다. 교환 후 새벽석 잔액과 슬롯 비용을 보여 주고 부족분의 무료 획득 경로를 안내한다. 기본 골드만으로 두 강화 트랙을 진행하는 산술은5.1절에서 따로 확인했다. 현금 판매나 유료 능력치 상품을 이 문서가 새로 승인하는 것은 아니다.
