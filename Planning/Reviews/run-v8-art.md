이전 v7 검토는 후드와 팔다리 위상에 집중해 크림색 의상·짧은 체형이 바뀐 문제를 놓쳤다. 이번 기준은 예전 입력 그림이 아니라 실제 대기 프레임 01이다.

최신 12장 비교에서는 크림 후드, 어깨 의상과 옷자락, 짧은 몸통, 금색 허리 종, 장갑·부츠, 두꺼운 검이 유지된다. 후드와 몸통 사이의 명확한 절단, 손에서 떨어진 검, 셀 밖으로 잘린 부위는 발견하지 못했다. PNG 12장 모두 128×128 셀의 가장자리 불투명 픽셀은 0개이며, 전체 프레임을 합친 불투명 범위는 x28~102, y31~113이다. 이는 셀 잘림 확인이며 모든 내부 접합부의 픽셀 단위 인증은 아니다.

검 선택 영역은 `[80,68,102,99]`와 `[74,82,80,95]`로 이전 x79 누락이 해소됐다. 손과 검을 한 패치로 이동·회전하여 둘 사이 연결이 유지된다. 몸통과 후드·옷·종은 공통 원본 패치를 사용하며, 뒤쪽 팔과 가려진 짧은 다리의 연결에는 원본의 어두운 색을 쓴다. 전신을 새로 그린 애니메이션이 아니라 원본 픽셀 부위를 복사·변형한 12개 자세다.

수치상 12장 × 40ms = 480ms 한 주기다. 접지 후보 구간 p0→p1→p2 및 p6→p7→p8의 부츠 이동량은 프레임당 13px다. 표시 배율 1.52075 적용 시 494.24px/s로, 배경 이동 480px/s와 약 2.97% 차이가 난다. 이는 recipe 계산 검증이며, 화면 합성에서 발이 미끄러지지 않는다는 시각 검증을 대신하지 않는다.

실시간으로 GIF나 게임 합성 루프를 관찰하지 않았다. 11→0 연결의 인상, 지면 접지, 양팔 펌핑의 명료함과 전력질주의 속도감은 실제 재생에서 추가 확인해야 한다. 12° 공통 몸통 기울기와 부위 변형을 사용한 제한적인 모션이므로 이번 판정을 출시 품질 승인이나 Unity 적용 완료로 표현하지 않는다.
