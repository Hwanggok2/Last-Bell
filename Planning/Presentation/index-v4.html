01 / SCALE

일반 적도 크게, 보스는 압도적으로

온은 유지하고 일반 몬스터는 높이2.0, 중간 보스3.2, 보스4.0으로 확대합니다. 같은 구도로 현재 실행본과 제안을 비교하세요. 기본 체급 확대와 등장 카메라 줌은 별개입니다.

현재 실행본의 크기

v4 제안 크기

캐릭터현재 → 제안온 대비1280×720 높이

온 발(500,590), 적 발(900,590). 모자·후광·무기를 포함한 대기 그림의 전체높이 기준입니다. 포즈마다 높이를 다시 맞추지 않고 대기 그림 기준 배율을 고정해 몸이 늘어나는 현상을 막습니다. 체급 변경만으로 피해량·공격 판정 범위를 바꾸지 않습니다.

02 / BOSS ENTRANCE

크게 들어가고, 멈춰 포효한 뒤, 돌아온다

보스 등장의 제작 목표는 고정된 큰 줌 → 얼굴 원형 파동과 공격 동작1회 → 줌아웃입니다. 공격 동작은 피해·투사체·공격 예고를 만들지 않는 표시용 클립으로 제작합니다. 비전투 상체 클로즈업에서는 보스 다리와 온 일부가 화면 밖으로 나갈 수 있습니다. 전투 구도로 완전히 돌아온 뒤에만 첫 공격 예고를 시작합니다.

0.85s

중간 보스 · 1.80초

줌인0.40 → 1.45배 유지·포효0.75 → 줌아웃0.45 → 정착0.20초.

재조우1.00초에도 최대 줌은 같습니다. 준비·정점 포효 포즈와 낮은 문·종·호흡 계열 음원을 제작합니다.

보스 · 2.20초

줌인0.50 → 1.60배 유지·포효1.00 → 줌아웃0.50 → 정착0.20초.

재조우1.20초에도 큰 줌 유지. 포효 후반부터 잔향을 줄여 첫 공격 신호가 묻히지 않게 합니다.

현재 장면은 카메라·얼굴 파동·전투 복귀 시점을 확인하는 기획 시안입니다. 보스별 연결 프레임은 별도 제작·검토가 필요하며, 아직 생성되지 않은 동작에는 대기 참고 프레임만 표시합니다. 보스 HP는 마지막 정착0.20초에 실제값으로 나타나며, HUD는 카메라와 함께 확대하지 않습니다.
03 / ENEMY ATTACK

준비 자세가 원인, 가시와 무기비가 결과

몬스터의 준비 동작에 지면 균열·착탄점·무기 끝의 빛을 맞추는 기획입니다. 큰 화살은 오른쪽 위 화면 밖에서 마지막180ms에 사선으로 내려옵니다. 아래 시안에서 공격 공간과 시간 관계를 확인하고, 각 방향의 준비→발동→회수 연결은 생성 프레임으로 별도 검토합니다.

0.69s

방향몬스터 준비예고 → 타격대응
여러 가시·무기는기본적으로 한 묶음, 한 번의 타격입니다. 큰 화살3발은 사선 몸체로 날아와 같은 시각에 꽂히며 장식 개수만큼 피해가 중첩되지 않습니다. 실제 연타는 기존 패턴의 각 타격마다 독립 예고를 냅니다.

큰 가시와 점프가 어긋나지 않게

가시는 좌상향으로 최대120px 솟고, 성공 점프의 발은144px까지 올리는 기획입니다. 타격 시점 이후 성공 포즈를 짧게 보정하고 잔해는140ms 안에 사라집니다. 무적160ms·완벽60ms 판정은 그대로이며, 정확한 경계 프레임은 실제 모션 연결 후 검증합니다.

공격 방향마다 연결 프레임 제작

낮은 공격은 바닥에 힘을 주고, 후방 공격은 하늘을 부르는 준비 동작이 필요합니다. 미생성 방향은 대기 참고 프레임으로만 표시합니다. 생성된 공격 후보도 무기 형태·몸의 연결·명중 자세를 검토한 뒤 각 패턴에 연결합니다.

04 / PLAYER STRIKE

플레이어에서 몬스터까지, 긴 사선 금빛 참격

0.13s

75ms부터 펼쳐지는 긴 사선 참격을100ms 명중 사건에 맞춥니다. 플레이어부터 몬스터 몸통까지 한 번 길게 벱니다. 밝은 중심·금빛 테두리가250ms 동안 나타났다 사라지며, 접점 불꽃·도트 파편·피해 숫자를 함께 표시합니다. 참격 프레임 수만큼 피해가 추가되지 않습니다. 치명타에는 더 큰 피해 숫자와 기존80ms 흔들림을 사용하며, 적의 현재 공격 예고가 가려지지 않게 조절합니다.

참격 합성 프레임 · 참격 GIF · 달리기 GIF

참격 VFX와 캐릭터의 베기 동작은 별도 클립입니다. 생성 후보의 형태·타이밍을 검토 중이며, Unity의 명중 판정·공격 취소와 연결하는 작업은 남아 있습니다.
05 / GENERATED FRAMES

원본 프레임으로 동작과 반복을 검토합니다

온의 달리기·베기와 몬스터 공격을 실제 생성 시트에서 재생합니다. 반려한 첫 결과와 재작업 결과를 함께 보존하며, 목록에 있는 후보도 채택을 확정하지 않았습니다. 생성되지 않은 동작은 대기 참고 프레임만 유지하고 별도 제작합니다.

생성16장 + 입력 원본1장

달리기 후보는 생성16프레임과 입력 참고1프레임을 구분합니다. 시트의 총17칸을 생성17장으로 세지 않습니다.

생성24장 + 입력 원본1장

첫 베기·몬스터 공격 후보는 생성24프레임, 재작업본은 생성16프레임이며 입력 참고1프레임은 별도입니다. 준비·타격·회수 연결과 무기 형태를 검토합니다.

시트별 실제 프레임 수·생성 작업·검토 상태는 아래 검토기에 표시합니다. FPS는 시각 재생 기준이며 게임 판정 검증값이 아닙니다. 검토기 넓게 열기 ↗

전체 상태 제작 목록·전투 배치 참고

캐릭터별 필수 상태와 예정 시간을 확인하는 보조 화면입니다. 생성 클립이 없는 상태는 대기 참고 프레임으로 표시하며, 실제 연결 프레임 제작이 필요합니다. 채택 여부와 원본 품질은 위 검토기에서 확인합니다.

0.20s

상태목표 프레임표현 시간현재 자산·다음 제작

담·린과 전체50종의 상태 매핑은 제작 목록에 포함합니다. 목록의 목표 프레임 수는 제작 완료 수량이 아닙니다.

06 / DEPTH

먼 성벽은 느리게, 발밑 돌은 빠르게

현재 직교2D를 유지한 채 하늘·원경·중경·가까운 기둥·바닥을 분리합니다. 이동하는1.20초 동안 바닥480px와 층별 배경을 왼쪽으로 흐르게 합니다. 온의 화면 x=500은 고정하고 발과 망토만 움직입니다. 다음 적도 바닥과 같은480px를 이동해 x1380→900에 도착합니다. 전투 중에는 멈춥니다.

0px
레이어바닥 대비 속도480px 이동 시역할

위 시안은 분리 레이어의 이동량과 다음 적의 도착 위치를 검토합니다. 달리기는 실제 생성 클립의 접지·반복 경계를 별도로 검토하며, 유효한 클립이 없는 상태는 대기 참고 프레임만 표시합니다. 배경은 가려진 부분까지 복원한 레이어와 이음매 없는 바닥의 별도 제작이 필요합니다.

깊이값만 바꾸는 방식은 원근 카메라에서 자동 원근차를 만들 수 있습니다. 현재 직교 카메라에서는 z를 배치·겹침에 쓰고 이동량은 별도로 계산합니다. 이번 MVP 권고는 직교+레이어 속도차입니다. 2.5D 전환은 향후 회전·전후 이동이 필요할 때 다시 비교합니다.

07 / AUDIO

전투는 또렷하게, 종소리는 여운만 남게

상업적 사용 조건이 명시된 원 제작자 자료로 후보를 골랐습니다. 효과음은 CC0 팩, 음악은 출처 표기가 필요한 CC BY4.0 곡을 검토합니다. 아직 청음·편집·다운로드·게임 삽입을 완료한 상태는 아닙니다.

포효는 별도 제작

두 보스의 호흡·깨진 종·금속 마찰을 직접 녹음/합성하고 검증된 CC0 금속 소리를 보조로 사용합니다. 팩 안에 적절한 포효가 있다고 가정하지 않습니다.

신호가 음악보다 먼저

예고·명중·완벽 회피를 음악보다 선명하게. 포효와 치명타 때 음악을 짧게 낮추고, 같은 순간의 무기3발은 착지 소리를 하나의 묶음으로 믹스합니다.
