쏘아지는 달리기 — 새 버전

유일한 시각 참고: ../character-base.png
생성: 내장 image_gen. 전체 프롬프트는 source/generation-prompt.txt.

변경한 동작
머리와 어깨를 골반보다 앞으로 두고 상체를 낮춤.
뒷다리를 길게 밀어내며 앞 무릎을 빠르게 회수.
머리 위치를 맞춰 상하 움직임을 약 2픽셀로 제한.
짧은 접지와 강한 밀기를 강조한 8프레임, 0.4초 무한 반복.
프레임별 시간: 40, 40, 60, 60, 40, 40, 60, 60 ms.

결과
frames/run-01.png ~ run-08.png: 128×128 투명 PNG.
run-preview.gif: 512×512 확대 애니메이션 미리보기.
preview.html: 자체 포함 로컬 재생기. 일시정지, 프레임 선택, 속도 변경 지원.
run-sheet.png: 가로 8프레임 투명 스프라이트 시트.
contact-sheet.png: 프레임 및 재생 시간 목록.
animation.json: 프레임 순서와 시간.

이전 결과와 기존 게임 파일에 적용하지 않고 이 폴더에 별도로 저장.
PNG 크기와 투명 여백, GIF 프레임 수/시간/무한 반복 및 재생기 로직을 검사.
