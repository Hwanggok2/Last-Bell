# 마지막 종지기 · 720ms 박자와 방향키 쳐내기 v5.9.1

2026-10-22 KST. **0·240·480ms 점멸 → 720ms 중앙 접촉·타격**. 기본/기존 빠른 패턴 모두 이 박자로 통일한다. 네 방향 회피 체계를 유지하며, 상단에 대응하는 아래 회피의 표현을 제자리 검 쳐내기로 변경한다.

[수정 보드](feedback-plan-v591.html) · [미리보기](hitbox-preview-v59.html) · [실제 Windows 검증](../Evidence/Combat-v591/index.html)

## 박자와 판정

|구간|시간|
|---|---|
|첫 점멸 밝음 / 흐림|0~120 / 120~240ms|
|둘째 점멸 밝음 / 흐림|240~360 / 360~480ms|
|셋째 점멸 밝음 / 흐림|480~600 / 600~720ms|
|무기 출발 / 타격|600 / 720ms|
|일반 회피 입력|560~720ms|
|완벽 회피 입력|660~720ms|

파동은 타격 T−600ms에 화면 밖 두 고정 원점에서 발생하고 T−480ms부터 화면에 보인다. 원의 앞끝이 T에 화면 정중앙에서 맞닿는다. 첫 공격과 후속 공격의 이동 속도는 같다. 정확한 T 프레임을 보여준 뒤 그 입력을 수집해 판정하며 별도의 늦은 입력 유예는 없다.

연속 공격은 모든 방향을 먼저 세 번씩 예고한다. 2연타: 앞 0/240/480, 뒤 720/960/1200 → 타격 1440/1920ms. 3연타: 세 방향 각720ms 예고 → 타격 2160/2640/3120ms. 타격 간격은480ms(두 박자)이며 사이에 재점멸하지 않는다. 종은 처음1~3개를 표시한 뒤 해결된 공격의 종만 제거하고 재중앙정렬하지 않는다.

## 네 방향 회피

|적 공격|입력|플레이어 표현|
|---|---|---|
|하단 휩쓸기|위 회피·W·↑|점프|
|앞 창 찌르기|왼쪽 회피·A·←|후퇴|
|상단 베기|아래 회피·S·↓|제자리에서 올려 베며 쳐내기|
|후방 내려치기|오른쪽 회피·D·→|전진|

아래 방향은 다른 방향과 같은 회피 입력이며, 공격 버튼에 연결하지 않는다. 네 삼각형을 모두 표시하고 정답 버튼을 미리 강조하지 않는다. 공격 버튼·Space는 일반 공격과 완벽 회피 후 반격을 수행한다.

- 일반160ms·완벽60ms 판정과260ms 방어 재사용을 모든 방향이 공유한다. 아래 회피도 너무 일찍 누르거나 다른 공격에 사용하면 실패하며 재사용 시간을 소비한다.
- 아래 회피는 숙이거나 전진하지 않고 제자리에서 기존 올려 베기 프레임을 사용한다. 성공 시 해당 상단 공격1회만 막고 적HP를 자동으로 깎지 않는다.
- 일반/완벽 회피는 기존20/40 공명과 기절·면역 규칙을 사용한다. 완벽 쳐내기도 화면 정중앙에서 청록 원형 파동을 화면 밖까지 확산하고500ms 반격 기회를 준다.
- 공격 재사용500ms와 회피 재사용260ms는 독립이다. 회피로 아직 명중하지 않은 공격을 끊으면 예약 피해만 취소하고 소비한 공격 쿨타임은 유지한다. 이미 준 피해는 보존한다.
- 반격 입력 수락 시 원점으로 즉시 복귀한 뒤 기존 접근 공격을 한 번 수행한다. 다음 연타는 적 기절·사망 등 기존 취소 조건이 없으면 계속된다.

## 유지되는 연출

회피 진입은50ms 이내 ease-out, 성공 시 타격 후100ms 유지,130ms 복귀. 공격은165px 접근120ms → 명중200ms →230~500ms 귀환. 전장 이동 달리기는 승인된8자세·400ms 주기·1,920px/2초를 유지한다.

금빛 히트박스는 밝음alpha.20/흐림.04, 먼저 끝난 예고는 윤곽alpha.14. 각 점멸 시작에70ms 금속음을 재생한다. 파동·종·위험 영역·96개 제한 파티클은 전투 시계로 진행하고 일시정지 때 함께 멈춘다. 연출 줄이기에서도 필수 타이밍 원은 남긴다.
