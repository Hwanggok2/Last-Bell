## 1. 완벽 회피에만 울리는 종

- 완벽 회피와 아래 방향의 완벽 쳐내기를 같은 완벽 방어 성공으로 취급한다. 성공 판정1회당 낮은 종 타격음1회. 예측 재생하지 않는다.
- 일반 회피, 일반 쳐내기, 적 예고, 플레이어 공격·치명타·피격, 기절 발동, 적 처치, 보스 처치, 스테이지·서사 전환에서는 종을 울리지 않는다. 자동으로 문을 여는 장면도 종 음향을 재생하지 않는다.
- 적의 남은 공격 횟수를 나타내는 **종 아이콘은 유지**한다. 점멸·파동은 종 음향 없이 읽을 수 있어야 한다. 예고는 시각 신호만 사용한다.
- 현재 낮고 긴 종 원본을 완벽 성공 신호로 사용한다. 완벽 성공이480ms 간격으로 이어지면 이전 잔향을40ms 동안 감쇠하고 새 타격을 재생한다. 완전한 잔향은 마지막 성공 뒤 이어진다. 지속 음성1개, 교체 중 교차 감쇠만 허용한다. 피치 상승·중첩 증폭은 하지 않는다.
- 검 ‘챙’은 실제 검 명중에 유지한다. 일반 성공 효과는 무음 또는 비음정 바람으로 두며 종 같은 금속 울림과 구별한다. BGM도 완벽 성공으로 오인할 독립적인 종 타격이 없는지 적용 전 확인한다.
- 기절 후 면역 때문에 게이지 증가가0이어도 완벽 판정이면 종은 울린다. 일시정지 중에는 종과 잔향도 멈추고, 복귀 때 성공음을 재발화하지 않는다.

## 2. 적 공격을 무작위로 선택

현재는 스테이지의 고정 `patternSteps`를 순환한다. v6에서는 **공격 묶음 시작 시 연타 수를 뽑고, 각 타격 방향을 해당 몬스터의 허용 목록에서 뽑는다.** 예고가 시작된 묶음의 횟수·방향·순서는 끝날 때까지 바뀌지 않는다.

### 저장·취소

- 패턴 추첨은 전투 로직이 소유한다. 시각 효과·치명타 추첨과 독립된 난수 상태를 저장한다. 같은 시드와 같은 입력은 같은 패턴을 만든다.
- 선택한 묶음 전체, 이미 해결한 타격 위치, 직전2방향, 난수 상태를 저장한다. 재접속 시 선택한 방향은 유지하고 **미해결 타격만** 전체 예고부터 다시 보여준다. 해결된 타격을 재판정하거나 재접속 때 추첨을 다시 하지 않는다.
- 기절·적 사망으로 취소된 남은 타격은 피해·완벽 성공·콤보를 발생시키지 않는다. 기절 종료 후 새 묶음을 뽑는다.

## 3. 20스테이지까지 진행

새10종에 보존된 기존 원본5종을 더해 **총15종을1~20층에서 사용**한다. 새10종은 성문 구역5종 + 사슬 주거구5종이다. 전체50층용 몬스터가 모두 완성된 상태는 아니며 이번 범위는20층이다. 기존5종 재배치와 새10종 배치를 게임 데이터에 반영했다.

|층|몬스터|구분|동선|
|---|---|---|---|
|1|빗장 초병|일반|등불의 길|
|2|종추 사냥개|일반|바깥 돌길|
|3|금 간 검기사|일반|무너진 초소|
|4|성문 파수병|일반|경비 순찰로|
|5|성문 수문장|중간 보스|중간 검문소|
|6|재의 불씨|일반|성벽 바깥길|
|7|종추 사냥개|일반|성문 대교 앞|
|8|금 간 검기사|일반|성문 광장 접근|
|9|검문쇠 거인|일반|마지막 검문선|
|10|종의 기사|보스|보스가 남아 있는 대사 → 소멸·골드 → 성문 개방 → 보상 →11층|
|11|문패 꼭두각시|일반|통과한 성문은 왼쪽에 남음|

|13|사슬 무희|일반|열쇠 골목|
|14|사슬 망령|일반|문패 거리|
|15|수문 추지기|중간 보스|잠긴 수문|

- 10층은 끝이 아니라 중간 보상 지점으로 바꾼다. 새10층 대사를 보스가 남아 있는 상태에서 보여주고, 대사 종료 후 소멸·골드 이동과 성문 개방, 유물3택1·회복을 거쳐11층으로 이동한다. 15층은 중간 보상만, 20층은 보스 대사·유물3택1 뒤 종료한다. 21층과 NG+는 이번 범위에 추가하지 않는다.
- 11~20의 주거구 배경은 기존 동선·색상 기획을 사용한다. 새 구역 BGM은 등록된 `bgm-quarter`를 쓰고,15/20 보스전은 보스 BGM으로 전환한다. 현재 배경 아트를 재사용하고 구역 BGM·보상·10/20층 스토리·20층 종료를 실제 진행에 연결했다. 별도 주거구 배경 아트는 후속 제작 대상이다.
- 20층 대사 초안: 집행관 “그들은 사라진 게 아니다.” → “종이 가져간 것은 그들의 내일이다.” → 온 “사슬을 끊으면, 돌려줄 수 있어.” 문패의 빛·등불·물속 시계로 구역 회복을 표현하며 자동 종소리는 사용하지 않는다.
- 재도전·로비 출전은1층부터 시작한다. 영구 재화·강화·유물은 유지한다. 진행 중 저장은 해당 층에서 재개한다.
- 이전10층 클리어 저장은 보상 기록과 성장 상태를 보존한 로비로 옮기고 다음 출전은1층으로 시작한다. 10층 보상 재지급이나 완료 저장의 임의11층 전환은 하지 않는다. 이전11층 경계용 HP1050/공격40은 폐기 대상이다.

### 10층 보스는 대사 후 사라진다

기존 “문은… 안에서 잠갔다”, “묶인 건 우리가 아니다”는 누가 왜 갇혔는지와 다음 목적지가 불분명했다. 새 대사는 **성문이 주민의 탈출을 막았다는 사실 → 문 너머 주민과 사슬 → 주민을 찾으러 간다는 목표**를 전달한다.20층에서 드러날 시간 징수의 전모까지 여기서 설명하지 않는다. 이 문안을 실행 카탈로그의 `story_boss_10`에 적용했다.

|순서|화자|새 대사|
|---|---|---|
|1|종의 기사|이 문은 적을 막는 문이 아니었다.<br>주민들이 밖으로 나가지 못하게 잠근 거다.|
|2|종의 기사|주민들은 저 문 너머에 있다.<br>집집마다 이어진 사슬을 따라가라.|
|3|온|문 너머로 가겠어.<br>사람들이 왜 갇혔는지 알아봐야 해.|

플레이어별 마지막 응답: 온은 위 문안, 담은 “문을 열어라. / 안에 남은 사람들을 찾겠다.”, 린은 “사람들은 아직 안에 있어. / 사슬을 따라가 볼게.”로 둔다. `/`는 화면의 두 줄 구분이며 실제 문장에 표시하지 않는다.

1. 보스 HP가0이 되는 순간 승리·보상을 한 번 확정하고 적 공격 예약·판정·플레이어 전투 입력을 중지한다. 보스는 처치 직전 화면에 표시한 전투 프레임 그대로 남는다. 기절 포즈나 다른 외형으로 바꾸지 않는다. 소멸·비활성화·삭제·도트 변환은 아직 시작하지 않는다.
2. 보스가 보이는 상태에서 위3개 대사를 순서대로 보여준다. 캐릭터별 응답으로 마지막 줄을 바꾼다. 대화 중 전투용 이름·기절·HP·종 아이콘은 숨기고 화자 이름은 대사 패널에 표시한다. 골드 HUD는 유지하되 이번 보상 표시 증가는 대사 종료까지 기다린다.
3. 마지막 대사 완료 또는 건너뛰기에서 한 번만 다음 단계로 넘어간다. **보스550ms 소멸과 몸통 위치의 골드 도트 생성을 같은 프레임에 시작**한다. 도트는 곧바로 골드 숫자로 직선 비행한다.10층은 대사를 위해 골드의 시각적 출발만 늦추며, 처치 보상 저장은 이미 끝나 있다.
4. 보스가 사라진 뒤 성문이 열리고 등불이 켜진다. 자동 종소리는 없다. 유물 선택·회복 후11층으로 이어진다. 골드의 최종 도착은전체1200ms 이내로 독립 진행하며 보상 창을 불필요하게 지연시키지 않는다.

- 기존 첫 처치/다시 보기 정책은 유지한다. 대사가 재생되는 모든 경우 ‘대사 먼저, 소멸 나중’을 지킨다. 이미 읽은 대사의 자동 생략도 대사 완료로 처리한다.

## 4. 기절 공략과 두 종류의 연속 기록

### 기절 중 공격 속도·연장

|시점|평소|기절 중 시작한 공격|
|---|---:|---:|
|접근 종료|120ms|100ms|
|명중|200ms|약166.67ms|
|귀환 시작|230ms|약191.67ms|
|귀환 종료·다음 공격 가능|500ms|약416.67ms|

공격 수락 순간 적이 기절 중인지 확인해 **그 공격 전체의 속도를 고정**한다. 모션·접근·명중 예약·귀환·재사용 모두 같은1.2배를 적용한다. 중간에 기절이 풀려도 이미 시작한 공격 속도를 바꾸지 않는다. 이미 시작한 평소 공격은 적이 기절해도 도중에 빨라지지 않는다. 회피 시간과 완벽 반격 가능 시간500ms는 유지한다.

- 기절 중인 살아 있는 적에게 실제 피해가 들어갈 때 종료 시각을50ms 뒤로 미룬다. 같은 기절1회에서 총300ms까지 연장한다. 치명타·이펙트·여러 도트가 연장 횟수를 늘리지 않는다.
- 기본 기절은 일반1500 / 중간1200 / 보스1000ms. 연장 포함 최대1800 /1500 /1300ms다. 연장 상한은 새 기절이 시작될 때만 초기화한다.
- 명중 시각이 기절 종료 시각보다 **엄격하게 이른 경우만** 연장한다. 같은 시각이면 기절 종료를 먼저 처리한다. 취소된 공격·빗나감·처치한 막타는 연장하지 않는다.
- 기절 후 면역2000ms는 **최종 연장된 기절 종료**부터 계산한다. 기절 중 공격으로 새 기절 게이지를 쌓지는 않는다. 기존 기절 피해 배율은 별도로 유지한다.

### 적 등급과 연속 완벽 회피 보너스

기절 기준100은 유지한다. 플레이어 성장·유물로 계산된 일반/완벽 기절 증가량에 적 등급 배율을 곱하고, 완벽 성공에만 연속 보너스를 곱한다.

`완벽 증가 = 플레이어 완벽 기본량 × 적 배율 × (1 + 0.2 × min(연속 완벽 횟수−1, 4))`

|적|일반 회피|완벽1회째|2회째|3회째|4회째|5회 이상|
|---|---:|---:|---:|---:|---:|---:|
|일반 ×1.0|20|40|48|56|64|72|
|중간 ×0.6|12|24|28.8|33.6|38.4|43.2|
|보스 ×0.4|8|16|19.2|22.4|25.6|28.8|

표는 성장·유물 보정이 없는 예다. 0게이지·0연속에서 완벽만 성공하면 일반3회, 중간4회, 보스5회에 첫 기절이 온다. 내부 소수는 유지하고100에서 잘라 남는 양을 다음 기절로 넘기지 않는다. 플레이어 피격 시 기존 게이지−20도 유지한다.

- 연속 완벽 횟수는 **같은 적의 실제 타격 결과**로 계산한다. 완벽 회피/완벽 쳐내기는+1. 일반 성공·비완벽 위치 회피·피격이면0. 불필요한 버튼 입력 자체나 취소된 위협은 결과로 세지 않는다.
- 기절, 면역, 대기, 일시정지는 연속 기록을 끊지 않는다. 면역 중 완벽 성공은 기록·종소리는 인정하되 게이지 증가는0이다. 적 교체·새 출전·사망·귀환 때 초기화한다. 저장·재개는 유지한다.
- 보너스는5회째에+80% 상한에 도달한다. 그 이후에도 성공 기록은 증가하지만 배율은 더 높아지지 않는다.

### 우측 상단의 명중 콤보

HUD의 `12 COMBO`는 위의 완벽 회피 기록과 **별도 값**이다. 플레이어가 맞지 않고 적에게 명중시킨 공격 횟수를 보여준다.

- 실제 적 HP를 줄인 공격1회당+1. 일반 공격·반격·치명타·기절 중 공격·막타를 모두1회로 센다. 공격 버튼만 누르기, 빗나감, 취소, 방어 성공은 증가시키지 않는다.
- 플레이어 HP가 실제로 감소하면 즉시0. 일반/완벽 회피·쳐내기·공격 사이 대기는 유지한다. 적 처치·층 이동·10층 보상·유물 선택을 거쳐도 이어진다.
- 새 출전·사망·귀환·20층 완료에서 끝난다. 일시정지·저장 복원에서는 유지한다. 피해 배율·골드 보너스는 이번 콤보에 추가하지 않는다.
- 0은 숨기고 첫 명중부터 `1 COMBO`. 증가 시 숫자만100ms 강조한다. 피격 시 이전 숫자는 즉시 사라지고 작은 선이120ms 흐려진다. 9999 초과는 `9999+ COMBO`로 표시하되 내부 횟수는 보존한다.
