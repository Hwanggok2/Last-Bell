02 / WARNING

금 간 종의 잔향

위험이 닿을 자리에 낡은 황동의 균열이 생기고, 타격이 가까워질수록 밝은 접점이 차오릅니다. 입력 버튼과 닮은 꺾쇠 대신 열린 띠·세로 균열·C형 잔향으로 방향을 읽습니다.

72%
암청 외곽낡은 황동활성 잔향밝은 접점

지금 피할 공격을 먼저

현재 공격은 굵게 이어진 황동 균열과 사각 접점. 다음 공격은 바깥16px의 성긴 점선만 표시합니다. 같은 방향 연타도 겹치지 않습니다. 게임 안에는 방향 설명문을 추가하지 않습니다.

판정은 그대로, 표현만 교체

단발650ms · 연타 첫900ms · 후속250ms. 후속 예고에 장식용 등장 시간을 추가하지 않습니다. B안은 형태가 무겁고 장식 비중이 커서 비교 후보로만 남깁니다.

배치·레이어·작은 화면 기준
위험 위치1280×720 bounds (x,y,w,h)대응형태

좌상단 원점 · Safe Area 인셋0 기준. 플레이어 기본 발 (548,590), 바닥 y600. 예고는 회피 포즈를 따라 흔들리지 않습니다. 실제 Canvas 960×540 기준 수치는 위 값×0.75. 밝은 핵12×12px, 암청 외곽16×16px는12px 형태슬롯보다 양쪽2px 돌출합니다. 다음예고는4px점·16px간격, 하단 다음예고와HP 사이 약15px(640에서7.5px)을 확보합니다. 640×360에서 접점6px·활성 띠5px 유지, 이 그림의 단순 축소만으로 터치 크기를 검증하지 않습니다.

레이어: 배경 → 캐릭터 → 위험 궤적 → HP/기절 기호 → 피해 숫자 → 입력 → 모달. 일반/치명 피해 숫자는 각 피격자의 상단 전용 레인에 두고, 경고 영역 위쪽(y438 미만)에서 올라가게 합니다. 숫자보다 공격 예고의 핵심 접점을 우선 보존합니다.

03 / SEQUENCE

끝나고, 달리고, 다시 마주한다

재생하거나 시간을 직접 움직여 보세요. 전투 화면과 실제 로비 배치를 사용하는 연출 모형입니다. 사망 시안은11층 사망→Stage11 로비 복귀 예시입니다. 달리기 프레임·사망 마스크·괴성 음원은 아직 제작 전이며, 이 보드의 자세 이동과 잔향은 타이밍 확인용입니다.

0.00s

승리 · 끊기지 않는 진행

적 도트가 아래로 떨어져 사라짐 → 온이 앞으로 달림 → 다음 적과 대치. 일반 적은 화면 전환이나 확인 버튼 없이 이어집니다.

배경은 왼쪽으로 흐르고 온은 화면 안에 남습니다. 기존 배경은 반복용 이음매가 없어, 실제 제작에서는 원경·중경·바닥 분리와 경계 숨김이 필요합니다.

패배 · 등불 아래에서 재정비

온이 금빛 도트로 흩어짐 → 화면이 서서히 어두워짐 → 등불이 켜지며 캐릭터와 강화 화면이 드러납니다.

로비 UI를 어둠 아래 먼저 준비합니다. 마지막0.2초에 조명이 안정되고 화면 전체가 읽힌 뒤 강화·출전 입력을 엽니다. 사망 문구나 설명 팝업은 추가하지 않습니다.

보스 처치 순서: 분해 → 유물 3개 중 1개 선택 → 달리기 → 다음 적. 10층마다 출전 버튼이나 로비로 끊지 않습니다. 보상 선택에 쓴 시간은 연출 길이에 포함하지 않습니다.

5층 · 성문 수문장

최대1.12배 줌인, 무거운 문과 낮은 종 울림을 섞은 짧은 괴성, 각진 가슴 잔향. 1.4초 후 카메라가 원래 위치로 돌아옵니다.

재조우0.8초. 짧은 줌·괴성은 유지. 같은 종의 첫 등장은 현재 캐릭터·회차 단위로 기록합니다.

10층 · 종의 기사

최대1.18배 줌인, 깨진 종과 금속 호흡을 섞은 긴 괴성, 후광에서 퍼지는 잔향. 1.8초 후 정착합니다.

재조우1.0초. 상단 HP와 UI는 줌 대상에서 제외. 소리를 꺼도 가슴빛과 잔향으로 단계가 읽힙니다.

04 / HANDOFF

재미를 가리지 않는 연출 규칙

항목초안 규칙
입력·첫 공격연출 중 공격/회피 잠금, 전투시계 정지. 마지막 정착0.20초는 총 길이에 포함. 정착 종료에 입력을 열고 온전한650/900ms 첫 예고를 시작. 연출 중 눌러 둔 버튼은 공격으로 이어지지 않도록 새 입력을 요구.
일시정지·앱 중단연출시계도 멈춤. 로컬 복귀는 멈춘 시점에서 재개하고, 프로세스 재시작은 저장된 안전한 목적 상태에서 재개. 보상 선택 중 종료하면 같은3후보 복원. 괴성은 재개 시 중복 시작하지 않음.
저장·보상처치 확정 시 보상·진행을 한 번 기록. 연출 종료 콜백은 골드/파편/유물을 지급하지 않음. 보스 미선택 보상은 회수 전까지 다음 전투로 넘어가지 않음. 5층은 기존 파편1개,10층은3개.
체크포인트정규 보스(10·20·30·40층) 기준 유지. 중간 보스는 체크포인트가 아님. 9층 사망→Stage1,10층 처치 후11층 사망→Stage11. 미래50층의 엔딩·NG+는 별도 경로이며51층을 생성하지 않음.
모션 줄이기줌·흔들림·배경 스크롤 제거, 분해 입자 절반. 전투 재개 시점은 동일. 무음에서도 실루엣·가슴빛·각진 잔향으로 보스 등장 전달. 전체 화면 흰색 점멸은 사용하지 않음.
반복의 속도1층 시작→10층 도착의 전환 비용약12.95초(일반8회×1.40 + 5층분해0.70 + 선택후1.05, 유물 선택 대기·보스 등장 제외). 실제 연속 전투에서 지루함을 측정한 뒤 전진구간0.65초를 우선 조정. 현재 수치는 실측이 아닌 기획 목표.
