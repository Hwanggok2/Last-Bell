01 / SCALE

일반 적도 크게, 보스는 압도적으로

온은 유지하고 일반 몬스터는 높이2.0, 중간 보스3.2, 보스4.0으로 확대합니다. 같은 구도로 현재 실행본과 제안을 비교하세요. 기본 체급 확대와 등장 카메라 줌은 별개입니다.

현재 실행본의 크기

v5 제안 크기

대기 기준 온 발(500,590), 적 발(900,590). 공격 접근 중 온의 표시 발은x780까지 이동합니다. 모자·후광·무기를 포함한 대기 그림의 전체높이 기준이며, 포즈마다 크기를 다시 맞추지 않습니다. 체급·표시 위치 변경만으로 피해량·회피 판정·무적을 추가하지 않습니다.

02 / BOSS ENTRANCE

크게 들어가고, 멈춰 포효한 뒤, 돌아온다

보스 등장의 제작 목표는 고정된 큰 줌 → 얼굴 원형 파동과 공격 동작1회 → 줌아웃입니다. 공격 동작은 피해·투사체·공격 예고를 만들지 않는 표시용 클립으로 제작합니다. 비전투 상체 클로즈업에서는 보스 다리와 온 일부가 화면 밖으로 나갈 수 있습니다. 전투 구도로 완전히 돌아온 뒤에만 첫 공격 예고를 시작합니다.

0.85s

중간 보스 · 1.80초

줌인0.40 → 1.45배 유지·포효0.75 → 줌아웃0.45 → 정착0.20초.

재조우1.00초에도 최대 줌은 같습니다. 준비·정점 포효 포즈와 낮은 문·종·호흡 계열 음원을 제작합니다.

보스 · 2.20초

줌인0.50 → 1.60배 유지·포효1.00 → 줌아웃0.50 → 정착0.20초.

재조우1.20초에도 큰 줌 유지. 포효 후반부터 잔향을 줄여 첫 공격 신호가 묻히지 않게 합니다.

현재 장면은 카메라·얼굴 파동·전투 복귀 시점을 확인하는 기획 시안입니다. 보스별 연결 프레임은 별도 제작·검토가 필요하며, 아직 생성되지 않은 동작에는 대기 참고 프레임만 표시합니다. 보스 HP는 마지막 정착0.20초에 실제값으로 나타나며, HUD는 카메라와 함께 확대하지 않습니다.
03 / ENEMY ATTACK

준비 자세가 원인, 가시와 무기비가 결과

몬스터의 준비 동작에 지면 균열·착탄점·무기 끝의 빛을 맞추는 기획입니다. 큰 화살은 오른쪽 위 화면 밖에서 마지막180ms에 사선으로 내려옵니다. 아래 시안에서 공격 공간과 시간 관계를 확인하고, 각 방향의 준비→발동→회수 연결은 생성 프레임으로 별도 검토합니다.

0.69s

방향몬스터 준비예고 → 타격대응
여러 가시·무기는기본적으로 한 묶음, 한 번의 타격입니다. 큰 화살3발은 사선 몸체로 날아와 같은 시각에 꽂히며 장식 개수만큼 피해가 중첩되지 않습니다. 실제 연타는 기존 패턴의 각 타격마다 독립 예고를 냅니다.

큰 가시와 점프가 어긋나지 않게

가시는 좌상향으로 최대120px 솟고, 성공 점프의 발은144px까지 올리는 기획입니다. 타격 시점 이후 성공 포즈를 짧게 보정하고 잔해는140ms 안에 사라집니다. 무적160ms·완벽60ms 판정은 그대로이며, 정확한 경계 프레임은 실제 모션 연결 후 검증합니다.

공격 방향마다 연결 프레임 제작

낮은 공격은 바닥에 힘을 주고, 후방 공격은 하늘을 부르는 준비 동작이 필요합니다. 미생성 방향은 대기 참고 프레임으로만 표시합니다. 생성된 공격 후보도 무기 형태·몸의 연결·명중 자세를 검토한 뒤 각 패턴에 연결합니다.

04 / PLAYER STRIKE

달려들어 한 번 베고, 빠르게 원자리로

x500에서 적 앞x780까지 접근해 긴 사선 금빛 참격을 한 번 내고 돌아옵니다. 접근·준비·휘두름·복귀는 새 실제 프레임으로 연결하는 기획이며, 명중은200ms에 한 번입니다.

0.23s
120ms · 접근 완료200ms · 명중1회300ms · 복귀 시작460ms · x500 복귀500ms · 재공격 가능

0~120ms에 앞으로 숙여 접근하고,120~200ms에 발을 디뎌 베기를 준비합니다.200ms 명중 뒤300ms까지 검을 회수한 다음460ms에 원위치로 돌아옵니다. 긴 사선 참격은175~425ms의250ms 동안 한 번 재생하고,200ms에 접촉합니다. 접촉 전25ms는 검의 궤적이며 피해가 없고,200ms의 실제 명중 사건에만 접점 파편·피해 숫자가 나타납니다. 치명타에는 큰 숫자와80ms 흔들림을 사용합니다.

공격 중에도 유효한 회피 입력은 즉시 받습니다. 타격 전 회피는 예약 공격을 취소하며, 타격 후 회피는 이미 발생한 피해를 되돌리지 않습니다. 이동 자체로 무적이나 회피 성공을 얻지 않고, 참격 프레임 수만큼 피해가 추가되지 않습니다. 적 예고와 피격 접점도 현재 표시 위치에 맞춰 연결해야 합니다.

신규 베기의 접점·회수 연결과 실제 입력 경계는 검토 중입니다. 접근·명중·회피 취소 계약 · 이전 v4 제자리 베기

05 / GENERATED FRAMES

생성된 플레이어10종과 달리기 대안을 검토합니다

대기·질주·베기·빠른 복귀·네 방향 회피·피격·사망10종과 달리기 대안의 PNG 생성이 완료되었습니다. 반려본과 재작업본을 보존하며, 무기 형태·접지·반복·연결 자세를 확인한 기획 후보를 비교합니다. 생성 완료는 출시 최종 품질 승인이나 Unity 적용 완료를 의미하지 않습니다.

대기·피격 · 각각 생성8장

대기는 반복 연결, 피격은 짧고 분명한 반응을 검토합니다. 입력 참고 프레임은 생성8장에 포함하지 않습니다.

나머지8종 · 각각 생성16장

질주·베기·복귀·네 방향 회피·사망의 생성 후보입니다. 생성16장과 입력 참고 프레임을 구분하며, 장수만으로 동작 완성을 판정하지 않습니다.

시트별 실제 프레임 수·생성 작업·검토 상태는 아래 검토기에 표시합니다. FPS는 시각 재생 기준이며 게임 판정 검증값이 아닙니다. v5 신규 프레임 아트 검토 · 검토기 넓게 열기 ↗

전체 상태 제작 목록·전투 배치 참고

캐릭터별 필수 상태와 예정 시간을 확인하는 보조 화면입니다. 생성 클립이 없는 상태는 대기 참고 프레임으로 표시하며, 실제 연결 프레임 제작이 필요합니다. 채택 여부와 원본 품질은 위 검토기에서 확인합니다.

0.20s

상태목표 프레임표현 시간현재 자산·다음 제작

담·린과 전체50종의 상태 매핑은 제작 목록에 포함합니다. 목록의 목표 프레임 수는 제작 완료 수량이 아닙니다.

06 / DEPTH

앞으로 숙인 빠른 질주, 천천히 흐르는 먼 성벽

전경의 온은400ms 주기로 발을 교차하며 달리고, 먼 배경은 느리게 흐릅니다. 처치 후 전진하는1.20초 동안 플레이어x500을 고정하고 바닥·다음 적을480px 왼쪽으로 이동시킵니다. 다음 적은x1380→900에 도착합니다. 공격할 때의500→780→500 위치 이동과 처치 후 전진은 별개의 연출입니다.

0px
레이어바닥 대비 속도480px 이동 시역할

처치 후 전진 한 번에400ms 달리기3주기를 사용합니다. 새 생성 클립의 발 접촉과 바닥 이동·반복 경계를 함께 검토하며, 유효한 클립이 없으면 대기 참고 프레임만 표시합니다. 현재 직교2D를 유지하고 하늘·원경·중경·가까운 기둥·바닥을 분리합니다. 배경의 가려진 부분 복원과 이음매 없는 바닥은 별도 제작이 필요합니다.

깊이값만 바꾸는 방식은 원근 카메라에서 자동 원근차를 만들 수 있습니다. 현재 직교 카메라에서는 z를 배치·겹침에 쓰고 이동량은 별도로 계산합니다. 이번 MVP 권고는 직교+레이어 속도차입니다. 2.5D 전환은 향후 회전·전후 이동이 필요할 때 다시 비교합니다.

신호가 음악보다 먼저

08 / REVIEW

새 동작을 검토하고 실제 전투로 연결합니다
