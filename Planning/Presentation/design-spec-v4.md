# 마지막 종지기 · 실제 프레임 기획 v4

2026-10-21. Unity·GameData 변경 없이 기획 미리보기와 아트 후보를 교체한다.

## 이번 변경

- 절차적으로 그린 다리와 두 포즈 스위치를 주 모션 검토에서 내렸다. PixelLab 실제 PNG 프레임과 공통 셀·피벗을 사용한다.
- 플레이어 달리기/단발 공격/앞·뒤·위·아래 회피, MVP 몬스터 5종의 공격 후보를 생성한다. 입력 원본1장은 생성16/24장과 별도로 센다.
- `PixelLab/review.html`에서 원본 프레임, 재생·스크럽·배속, 처음/끝, 격자·피벗을 확인한다. `assets.json`의 status·note와 `edits.json`의 채택 순서를 함께 본다. 반려본은 메인 전투 미리보기에서 제외한다.
- 생성 프레임의 반복 대기는 프레임 선택/표시 시간으로 줄인다. 각 원본 프레임의 크기·비율은 바꾸지 않고 투명128×128 셀과 공통 피벗을 보존한다. 원본은 `frames/`에 남긴다.
- 모든 방향의 적 공격이 제작된 것은 아니다. 현재 공통 공격 후보를 방향별 상태에 참고 표시할 수 있지만, 19개 방향 동작 완성으로 세지 않는다. 피격·기절·별도 대기는 제작 목록에 남아 있다.

## 긴 사선 참격

크림색 칼날 중심, 황동 테두리, 암청1px 외곽. 플레이어 앞에서 시작해 적 몸통을 지나 좌하→우상으로 약17도 뻗는다. 기존 초승 검흔과 꺾인 연결선은 제거한다. PixelLab VFX Workbench 256×128, 10장,40fps,250ms 단발이다.

1280×720 기준 도화 영역(487,383,475,184). 100ms 프레임의 불투명 시작은 손 주변(535,532), 날 끝은 약(930,409)이다. 몬스터 상체 접점은(885,424). VFX만 두 앵커 사이로 늘리며 캐릭터 프레임 비율은 고정한다. 캐릭터/몬스터별 앵커로 후속 조정한다. 화면 전체광/장시간 빔으로 만들지 않는다. 밝은 갑옷 위 가독성을 위해 어두운 외곽을 보존한다.

입력75ms부터 참격 펼침, 기존100ms 명중 사건에 칼날 본체·접점 불꽃·도트 파편·숫자를 묶는다. 325ms에 참격 소멸,500ms 다음 공격 준비를 유지한다. 단일 타격 원본 프레임을100ms로 재배치하며, 생성 FPS가 실제 피해 시각을 바꾸지 않는다. VFX 추가 피해 없음. 치명타는 더 큰 숫자·접점과80ms 흔들림, 적 공격 예고를 가리지 않는 범위다.

## 검수와 남은 범위

프레임이 많다는 이유만으로 통과하지 않는다. 달리기 좌우 지지발·발 미끄러짐·반복 경계, 손과 검 연결, 무기 길이, 한 번의 타격, 회수 동작을 확인한다. 미완성 상태를 두 그림 반복으로 대체해 완성으로 표기하지 않는다.

아트 담당 기록: `../Reviews/pixellab-motion-v4-art.md`. 실제 원본 셀과 오프라인 합성 이미지를 확인하며 브라우저 연속재생·기기·Unity 검증과 구분한다. 모든 생성물을 출시용 최종 채택했다고 주장하지 않는다.

기존 체급, 큰 줌 유지→얼굴 포효→줌아웃, 처치후 x500 고정·배경/바닥480px 이동, 사망 등불로비, 보상/체크포인트 계약은 유지한다. 이전 자세 모형·상세 수치는 `design-spec-v3.md`와 `index-v3.html`에 보존한다. 오디오 청음·배경 레이어 원화 제작·Unity 적용은 미수행이다.
