# Dragon-v6 / v0.9.5 · 변경 범위 합격 기준

2026-10-25 KST · **DESIGN_READY / CORE_UI_CONTRACT_RECEIVED / EFFECTS_SOURCE_RECEIVED / PROBE_PREPARED / QA_NOT_RUN**

요청된 UI·전투·동료 변경에 한정한44개 기준이다. 기준 승인 뒤 개발용 프로브와 러너를 준비했다. [구현 인계](dragon-v6-probe-preparation-20261025.md)가 현재 준비 범위이며 [프로브 계획](dragon-v6-probe-plan-20261025.md)은 최초 설계다. 네이티브 실행, Core 테스트, Unity 연결/Apply/빌드, 저장 프리팹 및 제품 코드 수정은 하지 않았다. 구현 완료와 총괄의 source freeze·실행 인계 뒤 한 차례 통합 캠페인을 수행하고, 확인된 실제 결함만 표적 재검한다. 준비 완료는 실행 PASS가 아니다.

기존 [v5 최종 결과](dragon-v5-result-20261024.md)와 원본 증거는 변경하지 않는다. v5의 전체60기준 미인증, 실입력·모바일 보류, 청음·성능 미검증은 유지한다. v6가 바꾸는 동작에 v5 PASS를 그대로 적용하지 않는다. 이44개 설계 항목도 실행과 담당별 근거가 연결되기 전에는 완료로 표시하지 않는다.

수신한 Core 계약 기준: 발동률=`min(45,12+L−1)%`, 주기=`basePeriod×max(70,100−(L−1))/100`의 정수ms. L1/10/20/30 확률은12/21/31/41%, 주기는100/91/81/71%이다. 현재 레벨한도30에서는45%/70% 안전 상한·하한에 도달하지 않는다. 이 값에 도달한 것처럼 L30 UI나 테스트를 쓰지 않는다.180ms windup은 주기에 포함된다. 최종 handoff가 바뀌면 실행 전 기대값을 갱신한다.

`rin`은 플레이어 미엘, `rina`는 동료 리나다. 이름/ID/스킬/효과/저장 연결에서 둘을 분리한다. 동료의 특별 공격은 기본 공격과 별개 추가 타격으로 계산하지 않는다. 여러 화살 등 시각 요소 수와 권위 피해 횟수도 구분한다.

독립 스킬은 승인 때CD20000ms, 고정200ms 뒤 접촉한다. 새 `PlayerSkillStarted/PlayerSkillContact`만 발생하며 스킬 때문에 `AttackStarted/EnemyDamaged`를 중복 발생시키지 않는다. 피해160/115/125%, 다렌 방패최대HP8%/3000ms, 미엘기세50을 유지한다. 스킬 접촉은 치명·기절 피해보너스·기절연장을 발동하지 않고, 가득 찬 기세를 소비하는 것은 다음 일반 공격이다. 같은 마감 순서는 적 impact/death→일반타격→독립스킬→동료이며 사망한 대상의 잔여 피해/보상은 중복되지 않아야 한다.

동료 proc는 독립된 저장 per-companion RNG로 최초 windup 예약 때 확정한다. 저장/복원 및 적 전환으로 재추첨하지 않고, 시각 windup이 취소돼도 새 적 grace 뒤 같은 선택을 이어 실제 접촉한 뒤에만 예약을 비운다. 총 지원 예상DPS는 원래 플레이어 baseAttack의초당24% 이하이다. 고정 편성 강화 시 총 예상DPS와 강화한 동료 예상DPS는 감소하지 않아야 하며, cap에서 다른 동료 몫 또는 기본1타 수치는 줄 수 있다.

수신 당시 문서 SHA: Core `AFFC2AD763EDA5643EAF5F93C8656D21A58463F1EA22F276DF03F32EC0718945`, 여관 `77B76AB8BAB2A213DAAFFBFB332C598E3088FD69C5E433F0934787094F5C5409`. 이는 **설계 입력 스냅샷 식별자**이며 최종 제품 동결 SHA가 아니다.

## 판정 방법과 남길 제한

각 ID는 `NOT_RUN`, `PASS_BOUNDED`, `FAIL`, `BLOCKED_CONTRACT`, `DEFERRED` 중 실제 근거에 맞춰 기록한다. 자동 result의 PASS는 시각 PASS가 아니다. 수동 PNG 판정은 실제 검토 파일/원본 크기 또는 crop/샘플 한계를 별도 JSON에 적고 원본 campaign/result를 수정하지 않는다. 담당 Core 결과는 담당자·동결 해시와 함께 재사용한 것으로 표시한다.

전체 수치 조합, 장시간 성능/메모리 누수, OS 실입력·모바일·청음은 이번 대표 관측만으로 인증하지 않는다. v5에서 작고 옅었던 기절 입자의 문제가 새 효과에도 나타나는지640 후기 프레임을 포함해 확인한다. 만약 미검증 계약이나 효과가 남으면 그 부분을 구체적으로 남기고 포괄적인 완료/배포 PASS로 바꾸지 않는다.

최종 효과 예산은4PS/376입자(256+32+24+64), 실제 기절별21입자다. 기존216/15입자 기대값은v6에 적용하지 않는다. 큰 적의 상공 여유가48UI단위 미만이면 벼락 구현이 접촉만 표시하므로, 자동 contact PASS와 무관하게 실제 상공 벼락이 보이는지 검토하여 미충족이면 시각 결함으로 보고한다. 보스 HP는상단16–60,이름64–104이며108부터의리듬바와4px간격이 최종 기준이다. 이전y48/92제안은폐기했다.
