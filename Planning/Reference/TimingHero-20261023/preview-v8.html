직접 확인할 수 있는 것

강화 버튼으로 골드와 정수 능력치가 바뀝니다. 별·레벨 변경은 비교용 조건이며 실제 캐릭터의 별을 바꾸는 기능이 아닙니다. 유물은 선택 → 설명 → 확정을 거칩니다. 프롤로그는 자동 재생, 일시정지, 다음 문단, 건너뛰기를 지원합니다.

전투 미리보기의 범위

동작·파동은 자동 연출입니다. 방향 버튼 또는 방향키를 누르면 다음 타격에 대한 타이밍 표본을 계산합니다. 전투 결과나 HP를 시뮬레이션하지 않습니다. 아래 버튼은 상단 공격을 쳐내는 입력입니다. 일시정지 중에는 입력 표본을 받지 않습니다.

실제 판정 검증과 모바일 터치 검수는 Unity 적용 단계에서 진행해야 합니다. 이 페이지의 비교 대상은 Audio-v7.2 저장 캡처입니다.
