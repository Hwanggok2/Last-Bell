# 밝은 서사 초안 검토

2026-10-24. 소유 범위는 이 문서와 `story.json`이다. 기존 기획 원본, Unity, GameData, 아트 자산, 커밋은 변경하지 않았다. 사용자가 먼저 검토할 기획·시안이며 제작 완료 보고가 아니다.

## 추천 방향

**축제 아침의 돌풍 뒤, 온이 마을의 다섯 종을 울리는 작은 모험**을 권고한다. 할 일은 처음부터 끝까지 같다. 길의 소동을 정리하고 종을 울리면 다음 구역으로 간다. 마지막 종이 울리면 축제가 시작된다. 늦게 밝혀지는 원인이나 반전은 없다.

원인은 돌풍 한 번이다. 장식 끈이 종과 준비 장치에 엉키고, 동물들이 놀라 길로 나온다. 구역마다 새 고장·악역·규칙을 만들지 않는다. 축제 시작 전이라는 동기를 카운트다운이나 실패 패널티로 바꾸지 않는다.

처음의 자동인형 전용 제안은 수정했다. 현재 `GameData/mvp-catalog.json`에는 들개·늑대·불곰·여우·멧돼지·오소리·스라소니·산양·사슴 등 실제 동물이 있고,5층 중간 보스도 `wild_boar`다. 모두 기계라고 설명하면 실제 외형과 어긋난다. 기계는 동작을 멈추고, 동물은 진정해 옆길로 물러나는 두 표현이 필요하다. 두 표현 모두 기존 승리 판정이며 새 포획 시스템은 아니다.

## 다섯 구역

| 구간 | 이름 | 목표 | 중간 보스 / 보스 |
|---|---|---|---|
| 1–10 | 축제 성문길 | 첫 종을 울려 마을로 들어간다. | 놀란 멧돼지 / 성문 종지기 |
| 11–20 | 물길 골목 | 엉킨 줄과 장치를 정리하고 두 번째 종을 울린다. | 줄 정리인형 / 물길 관리인형 |
| 21–30 | 종시계 공방 | 작업 장치를 멈추고 세 번째 종을 울린다. | 태엽 조립장 / 공방 지휘기 |
| 31–40 | 바람종 정원 | 정원길을 정리하고 네 번째 종을 울린다. | 회전 물뿌리개 / 정원 관리장 |
| 41–50 | 하늘 종탑 | 마지막 소동을 정리하고 축제를 시작한다. | 종탑 조율기 / 축제 지휘인형 |

아트 담당과 구역 구조를 맞췄다. 성문·수로·시계와 톱니·아치·큰 종이라는 기존 큰 형태를 남기고 재료와 주변 생활을 바꾼다. 물길 골목은 침수된 주거지가 아니라 보행로와 분리된 맑은 수로다. 옛 성당형 아치는 유리온실과 정원 종틀로, 마지막 종루는 마을이 내려다보이는 열린 종탑으로 읽히게 한다. 전투 바닥 높이와 위험 예고는 배경 때문에 달라지지 않는다.

## 짧게 읽히는 내용

시작은 세 문장이다. “오늘은 마을의 종 축제다.”로 장소와 목적을 열고, 돌풍의 소동을 한 문장으로 말한 뒤, 온이 다섯 종을 울리러 출발한다. 기존 프롤로그 자리를 사용하고 새 설명창을 추가하지 않는다. 오래된28초 프롤로그를 그대로 유지해야 한다는 뜻은 아니며, 새 길이는 UI 시안에서 결정한다.

10단위 보스 뒤 대사는 각2줄이다. 보스는 눈앞의 문제가 풀렸음을 말하고, 주인공은 종과 다음 목적지를 말한다. 긴 사연이나 전투 규칙 해설은 없다. 온·담·린은 마지막 응답만 바꾼다. 기존 최신 계약대로 보스가 보이는 상태에서 대사를 읽고, 완료/건너뛰기 뒤 퇴장과 유물 선택으로 이어진다.50층의 마지막 종은 완주·유물 저장 뒤 엔딩에서 울린다.

엔딩도 세 문장이다. 다섯 종의 합주, 마을 행렬, 주인공의 합류로 마무리한다. 구출해야 할 사람이나 감춰진 대가를 마지막에 추가하지 않는다. 재도전은 같은 모험을 더 어려운 조건으로 다시 즐기는 것으로 설명하며 축제를 매번 취소하지 않는다.

`game-ui-wireframe-copy`의 문구 기준을 적용했다. `story.json`의 대사·시작·엔딩만 게임용 문구이고, 원인 설명·제작 주석·검토 결과는 화면에 붙이지 않는다. 대사는 하단 한 줄씩 표시하며 실제640×360/모바일 렌더에서 최대2행을 확인해야 한다. 현재 문서 검토는 한글 줄바꿈·터치 검증을 대신하지 않는다.

## 현재 파일과 충돌을 피한 부분

- `story-world-v2.json`에는 현재 프로토타입10층이라는 오래된 설명이 남아 있다. 더 최신인 `route-onboarding-v5.json`과 실행 원본 `mvp1.13.0`은20층 범위다. 이번50층 서사는 정식 목표이며50층 구현 완료가 아니다.
- `route-onboarding-v5.json`의 일부 배치와 현재 실행 원본도 다르다.5층은 현재 멧돼지,15층은 사슬 망령이다. 초안은 현재 형태를 우선해 각각 동물과 줄 정리인형으로 제안한다. 실제 enemyId/artId는 이 작업에서 바꾸지 않았다.
- 새 도전은 현재 실행본의 Stage1 규칙을 유지한다. 오래된10층 체크포인트 기획을 이번 이야기 교체와 함께 되살리지 않는다. 캐릭터별 진행·정식50층 회차의 별도 계약은 이 문서에서 수정하지 않는다.
- 가로 타이밍 전투, 세 방향 회피와 공격 쳐내기, 50스테이지 목표, 5단위 중간 보스/10단위 보스, 10단위 보스만 유물 3택1은 유지한다. 보유 유물 자동 적용·보관함 확장이라는 최신 규칙을 따르며, 오래된 장착 슬롯 규칙을 되살리지 않는다. 전투 시계·피해·보상·강화·유물 레벨 수치는 변경하지 않는다.
- 골드·종 파편·유물의 이름을 유지한다. 종은 부품을 모아 만드는 물건이 아니라 기존 보스 뒤 울리는 목표물이다. 새 종추·부품·열쇠 수집은 없다.

## 외형과 연출의 후속 작업

아트 담당이 실제12·13·15층 이미지를 검토했다.12층의 짧은 비옷 실루엣은 관절·청소도구를 더해 우비 청소인형으로 읽히게 할 여지가 있다.13층의 부유·연기꼬리와15층의 긴팔·후드·갈라진 옷은 이름만 바꾸면 여전히 유령이다. 안내풍선에는 고정끈·송풍기, 줄 정리인형에는 기계손·태엽·이어진 겉옷 같은 근거가 필요하다. 원형을 살리는 소품 보완안이며 최종 자산 승인이 아니다.

실제 동물은 몸이 분해되는 패배 연출을 쓰지 않는다. 주인공도 패배 후 몸이 부서지는 인상보다 넘어짐·숨 고르기·쉼터로의 화면 전환이 맞다. 현재 공통 사망 연출을 유지한 채 문구만 가볍게 바꿨다고 완료 처리하지 않는다. 해당 모션과 연출은 `followupAssetChanges`에 미완료로 분리했다.

## 적합성 판단

기획 초안으로 적합하다. 목적을 처음 세 문장으로 이해할 수 있고, 다섯 구역의 사건이 한 원인에서 이어지며, 현재 전투와 보상 구조를 바꿀 필요가 없다. 밝은 톤은 반복되는 과장된 농담보다 낮의 풍경·정리된 길·정상으로 돌아온 장치에서 만든다. 전투의 빠른 반응과 도전성은 그대로 남는다.

확정 전 남은 확인은 배경/UI 시안에서 적·예고가 충분히 구분되는지, 동물과 기계의 패배가 실제 그림으로 구별되는지, 짧은 대사가 작은 화면에 잘 들어가는지다. 이 문서만으로 새 아트·모션·Unity 적용을 승인하거나 완료한 것으로 표시하지 않는다.

정적 검토에서 JSON 파싱, 1–50의 연속된 다섯 구역, 5/10단위 보스 위치, 시작·엔딩 각 3문장, 보스 대사 10개의 고유 ID, 온·담·린 응답과 출처 파일 경로를 확인했다. 대사 본문은 최대 25자, 인물별 응답은 최대 26자다. 글자 수는 화면 줄바꿈 검증이 아니며, 실제 UI 렌더 검수는 후속 작업이다.
