# 밝은 축제 콘셉트 UI 검토

2026-10-24 · 담당: UI/가독성 · 상태: 기획 제안. Unity·게임데이터·경제 수치는 수정하지 않았다.

밝은 낮하늘과 크림 패널로 바꾸되, **현재의 전투 배치와 선택 → 개별 스탯 강화 흐름을 유지하는 안**이 적합하다. 온의 기존 외형과 금색 검은 그대로 둔다. 위험은 산호, 선택·성공은 청록으로 정리하되, 전장에서는 색보다 짙은 외곽선과 형태 차이가 먼저 보여야 한다. 상세 좌표는 같은 폴더의 `ui-spec.json`에 있다.

## 검토 근거와 최신 기준

- 직접 본 최신 자료: `Planning/Evidence/Feedback-v86/desktop/`의 선택·강화·전투·보스 발밑 HP·유물 목록·유물 선택·보스 대사 캡처, `mobile/08-combat.png`, `mobile/03-upgrade.png`.
- `Prototype10-Web/fullflow/09-lobby.png`, `03-stage-1.png`는 초기 미술/배치의 비교 자료로만 사용했다. 이 화면의 4방향 회피, 옛 강화 UI, 높은 지면을 새 시안으로 가져오지 않는다.
- 현재 작업 지시의 **540ms 박자, 상단 쳐내기 = 공격 버튼, 점프/후퇴/전진 3방향 회피**를 기준으로 삼았다. 진행 중인 Client 소스와 이전 캡처에는 아래 방향/S의 잔여 표현이 있으므로 이번 문서에서는 이를 복원하지 않는다.
- 최신 960×540 캡처의 지면은 대략 y360, 발은 y350, HP는 y398이다. 1280×720 제안에서는 각각 y480, y468, y524~540으로 맞췄다. 이는 캡처에서 읽은 근사 위치와 제안값이며, Unity RectTransform 실측이라고 주장하지 않는다.
- 최신 유물은 **모두 자동 적용 + 보관함 확장**이다. 초기 요청의 장착 슬롯/장착 버튼을 다시 그리지 않는다. 최신 보스 HP 역시 발밑에 있으므로 상단으로 이동시키지 않는다.

## 배치 결정

| 화면 | 1280×720 제안 | 이유 |
|---|---|---|
| 전투 | 지면 y480, 크림 조작 영역 y500~720 | 현재 월드 높이와 조작 분리 유지 |
| 회피 | 점프 [96,476,104,104], 후퇴 [12,600,104,104], 전진 [216,600,104,104] | 배경판 없는 ▲/◀/▶, 640에서 각 52px 터치 영역 |
| 공격/쳐내기 | [1120,564,144,144] | 동일 검 아이콘과 기능, 640에서 72px 터치 영역 |
| 로비 선택 | 좌측 [24,116,300,488], 우측 [348,116,908,488] | 캐릭터 목록 약 1/4, 본문과 Idle 충분한 폭 |
| 강화 | 상단 4탭 [28+i×310,104,294,96], 본문 [28,212,1224,378] | 모든 스탯에 바로 접근, +1/최대 견적과 실행 분리 |
| 유물 | 좌측 [24,116,384,500], 우측 [432,116,824,500] | 약 1/3에 2열 목록·수용량, 우측 효과·다음 레벨 |
| 보스 대사 | 하단 [24,518,1232,178], 본문 최대 2줄 | 전투 입력이 멈춘 동안 조작 영역을 대사로 교체 |

좌표는 전부 왼쪽 위 기준 `[x,y,w,h]`다. 가로 Safe Area에 16:9를 맞추고, 더 넓은 화면의 여백은 배경만 확장한다. 작은 화면에서 버튼/글자를 추가 축소하지 않는다. 640×360 이미지에서 48px 이상으로 설계했으나 이것이 실기기 48dp 검증을 뜻하지는 않는다.

현재 640×360 강화 캡처에서는 본문과 `↑ Lv`/`↑ Max`가 작다. 새 시안은 주요 본문 32px(축소 시 16px), 보조 28px(14px), 버튼 높이 최소 96px(48px)로 제안한다. 별점은 유지하되 강화의 핵심 정보는 `50 → 130` 같은 실제 변화량이다. `더 강력한 공격을 할 수 있습니다.` 같은 자명한 설명은 지운다. 행운의 `치명 확률 · 획득 골드`, 공명의 `기절 중 피해`는 의미 확인에 필요하다.

## 밝은 전장에서 놓치기 쉬운 것

통합 시안 `render-preview.cjs`의 실제 C 토큰으로 정합성을 맞췄다. sRGB 상대 휘도 대비 계산: 잉크 `#283F42`/크림 `#FFF4DD` **10.23:1**, 산호 `#B84232`/크림 **4.98:1**, 청록 `#24766D`/크림 **4.95:1**. 본문은 잉크/크림을 기본으로 한다.

목업 민트 토큰 `#B8D4BE` 위에서는 산호 **3.42:1**, 청록 **3.40:1**, 금색 `#C7832F` **1.97:1**이다. 다만 생성 배경 전체가 이 민트 단색은 아니고 하늘·구름·나무·석재의 명도가 다르다. 따라서 금색 위험선을 산호로 칠하는 것만으로는 충분하지 않다. 위험선·접점에는 논리 4px의 잉크 외곽을 붙이고, 성공/웨이브에는 크림 받침과 잉크 경계를 둔다. 640 축소에서도 경계가 2px 남아야 한다. 이 값은 단색 조합 계산이며 실제 애니메이션의 가독성 인증은 아니다.

위험은 공격 접점과 끊긴 사각 모서리, 박자는 연속된 원호, 성공은 밖으로 퍼지는 네 갈래 도트로 구별한다. 조작 화살표를 공격 예고 안에 반복하지 않는다. 중앙 전장 `[320,192,760,288]`에는 산호 깃발·금색 가로 울타리·눈에 띄는 장식 입자를 두지 않는다. 기존 흰색/금색 피해 숫자에는 어두운 외곽이 필요하다. 무음에서도 파형·준비 자세·접점이 읽혀야 하며, 모션 감소가 박자나 판정 시간을 바꾸면 안 된다.

## 로비·유물·대사

현재 선택 화면과 개별 스탯 강화 화면을 분리한 흐름, +1/최대 견적, 별점, 단계별 성장, 재도전/진행도는 그대로 둔다. 상단 오른쪽 지갑은 골드와 종 파편을 두 줄로 표시한다. 과금·교환·보관함 확장 비용은 현재 데이터값을 바인딩하며, 이번 테마 변경으로 지급량/가격/유물 획득 조건을 바꾸지 않는다. 부족 시 `종 파편 {n}개로 골드 {g}개를 받을까요?` 확인을 유지한다.

유물 목록은 장착창이 아니다. 약 1/3 폭의 목록에서 2열 × 2행을 보이고 추가 보유분은 세로 스크롤한다. 수용량은 목록 위에 고정한다. 우측은 이름·레벨·자동 적용·현재 효과·다음 효과만 표시한다. 선택 보상은 3장 중 선택 → 효과 확인 → 받기 흐름과, 가득 찼을 때의 확장 비용/대신 골드 선택을 유지한다.

보스 대사는 전투 정지 중 하단 조작 영역을 덮으며, 이름과 두 줄 본문, `다음`/`건너뛰기`만 둔다. 최신 `v84-story-10.png`에는 보스가 흰색 피격 플래시와 피해 숫자를 띤 채 대사가 열려 있다. 새 시안에서는 순간 피격 표시를 끝낸 Idle 프레임을 사용해야 대화가 읽히고 밝은 분위기와도 맞는다. 전투 데이터나 보상 결과를 바꾸라는 제안은 아니다.

이야기 문구는 스토리 담당과 합칠 때 확정한다. 동물·기계가 모두 같은 존재라는 설정, 죽음의 비극, 주민 시간 징수 같은 옛 무거운 설정은 UI에서 덧붙이지 않는다. `종 하나 울렸다! / 다음 종은 어디에 있을까?` 정도의 짧은 말은 예시이며 확정 대사가 아니다.

## 배경 5층

하늘의 작은 네모 구름 → 낮은 언덕/종탑 윤곽 → 나무 지붕/시장 차양 → 가장자리 울타리/표지판 → 밝은 돌길 순서다. 중앙은 단순한 중명도 민트 면으로 비워 온의 크림 후드와 남색 얼굴이 유지되게 한다. 목재는 패널 테두리와 소량의 환경 요소에 쓰고, 화면 전체를 갈색으로 덮지 않는다. 패럴랙스 요인은 현재 5층 의도를 유지하는 제안값이며 이번 작업에서 런타임/배경 자산을 수정하지 않았다.

## 확정 전 남은 확인

가장 큰 구현 단계 우려는 **움직이는 밝은 배경 위 금색 캐릭터·금색 숫자·위험선의 동시 겹침**과 **구버전 4방향/장착 UI의 재등장**이다. 정적 통합 시안에서 최신 3방향·공격 쳐내기·자동 적용 유물을 확인했고, 보스 얼굴과 건너뛰기 버튼도 겹치지 않는다. 실제 애니메이션/다른 보스 크기의 검증은 구현 단계에 남는다.

통합 목업 6장(`images/combat`, `lobby`, `upgrade`, `relic`, `story`, `wireframe.png`)도 직접 확인했다. 밝은 색감, 온의 실루엣, 발과 길의 접점, 3방향/검 조작, 하단 대사 가독성은 적합하다. 총괄에게 전달한 아래 사항은 재출력본에서 해결을 확인했다.

- 강화 상단의 공격력·체력·행운·공명 4탭이 복원됐다.
- 강화 표본은 현행 Lv.10→11의 `50→130 / 225 골드`로 바로잡았다.
- 유물 다음 효과(+8%), 서로 다른 아이콘, 수용량 5→6의 현재 비용 12파편이 추가됐다. 지갑 16파편으로 확장 가능한 표본이며 실제 값을 변경한 것이 아니다.
- 일시정지 영역은 96×96으로 커졌다.
- Stage/획득 골드 뒤에 크림 받침이 추가됐다.

최종 합성안에 맞춰 JSON의 로비 패널, 강화 상단 탭, 유물 2열 그리드 좌표도 동기화했다. 긴 실제 재화값은 한 줄 표본 지갑에 억지로 넣지 않고 두 줄로 바뀌는 규칙을 남겼다. 파형은 전장 y112~500에만 보이고 조작부를 통과하지 않는다. 배경의 실제 보행선은 y468이며 발끝과 일치하고, y480은 돌길 띠의 배치 기준값이다.

최종 재출력에서 보관함 증가 화살표는 직접 그린 도형으로 바뀌어 글꼴 깨짐이 사라졌고, +1/최대 견적 선택과 별도 하단 `강화 · 225 골드` 실행 버튼도 분리됐다. 마지막 수정본을 직접 확인했으며, 정적 시안에 대한 미해결 수정 요청은 없다. HTML 소스의 기획 설명도 읽어 화면·명세와의 충돌이 없음을 확인했다. 브라우저를 실행해 탭/반응형 동작을 검증한 것은 아니다.

이 검토는 기존 캡처/표시 코드/문구 읽기, 단색 대비 계산, 새 PNG 6장과 수정본 확인까지 완료했다. HTML 상호작용·작은 화면 반응, Unity 적용, 실기기 터치·DPI·노치 및 움직이는 밝은 배경 위 대비는 아직 검증하지 않았다. 현재 정적 시안과 문서는 사용자 기획 검토에 넘길 수 있다. 방향 확정 뒤 구현 대상으로 넘긴다.
