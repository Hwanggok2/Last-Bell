# UI 전체 도트 디자인 v4 · 검토

2026-10-24 · 담당: UI/가독성 · 정적 기획 시안 검토. **Unity·브라우저·실기기 실행 검증은 하지 않았다.**

## 판정

**UI v4를 도트 디자인 기획안으로 채택할 수 있다.** 요청된 6장과 렌더러·명세를 한 번의 묶음으로 확인했다. 방향이 뒤집힌 아이콘, HP 1과 0의 혼동, 글자 깨짐·잘림, 조작 영역의 중대한 겹침은 발견하지 못했다. 추가 반복 생성이나 전체 재검토를 요구할 문제는 없다.

UI가 배경·캐릭터보다 매끈한 벡터처럼 보이던 v3와 달리, 화살표·검·방패·일시정지·재화·체력바·패널·예고가 사각 셀과 계단 외곽으로 이어진다. 실제 플레이 기능과 상태 전환까지 구현됐다는 판정은 아니다.

## 명세와 구현 방식 확인

아이콘은 컴포넌트 로컬 **4px 정사각 셀**로 그린다. 좌우 회전은 픽셀 행/열 변환이고, 타이밍 원호도4px 셀로 래스터화한다. 상태 비교표의 일부 아이콘은2px/3px로 표시하므로 상태표 전체가 한 가지4px 표시 단위라는 뜻은 아니다. 실제 전투 아이콘의4px 기준과 모순되지 않는다.

문자는16px 원본 글리프와 baseline16, 이진 알파 처리 후 정수 배율 확대를 사용한다. 전투는2배, 상태표는1/2/3배다. 글자가 또렷하다는 이번 판단은 제공된 PNG 기준이며, 브라우저의 임의 CSS 축소나 휴대전화 해상도에서 같은 선명도가 유지되는지까지 확인한 것은 아니다.

HP 채움은 `ceil`로4px 셀에 올림하고 양수일 때 최소1셀,0일 때만 빈 바로 표시한다. 최대 셀 수로 제한하므로 바깥으로 채움이 넘치지 않는다. **1HP 표본은 작은 양수 비율의 시각 예시**이며, 실제 최대 HP가1000이라는 게임 수치를 새로 정한 것이 아니다. 셀 단위 반올림으로 보이는 길이가 정확한 실수 비율과 조금 달라질 수 있으나 실제 HP 값을 바꾸는 기능은 없다.

최종 HP 좌표는 플레이어 `[390,520,160,24]`, 일반 적 `[718,520,184,24]`, 보스 `[710,520,280,24]`다. 가로 중심470/810/850과 기존 터치 영역은 유지했다. 프레임 그림자나 아이콘 외곽이 새 입력 영역을 만드는 것은 아니다.

## 남는 범위

원호와 캐릭터가 움직일 때의 가림, 실제 공격 예고·쳐내기 동기화, 성공 효과, 피해 숫자의 전장 배경 대비·이동·중첩은 이번 정적 시안으로 검증하지 않았다. 특히 피해/치명타 숫자는 양피지 상태표에서만 보았으므로 구름·후드·적 몸 위에서도 읽힌다고 확대 해석하지 않는다.

눌림·비활성 PNG는 디자인 상태다. 입력 수락·잠금·쿨다운·강화 결제 같은 런타임 동작을 추가하거나 바꾸지 않았다. 로비·유물·대사의 공통 패널/아이콘 스타일은 제시됐지만, 모든 화면과 상태를 실제 게임에서 연결한 것은 아니다.

기존 후퇴 터치 영역 x12와 문서 Safe Area x16의4px 차이는 명세에 이미 기록돼 있다. 이번 도트 개정에서 새로 생긴 문제는 아니며 실제 Safe Area 연결 단계에 남는다. 640×360 환산은 회피52px·공격72px·일시정지48px지만, 물리 기기의 dp/터치 검증은 수행하지 않았다.

**완료 범위는 최종 PNG6장의 묶음 시각 검토와 소스·명세 대조다.** 별도 이미지 재생성, 브라우저 실행, Unity 임포트/실행, 모바일 QA는 하지 않았다.
