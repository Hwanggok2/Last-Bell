# 모험가 이름과 전용 스킬

2026-10-24 · **이름은 이번 표시 변경 대상 / 전용 스킬은 기획안이며 미구현**

현재 게임 데이터에 있는 플레이어 3명을 기준으로 정리했다. 별도 스킬 버튼이나 자동 공격을 추가하지 않고, 방어 타이밍을 맞춘 보상을 기존 공격으로 직접 사용하는 방식이다. 수치는 초기 제안이며 플레이 검증을 마친 밸런스가 아니다.

## 이름과 역할

| 저장 ID | 이전 이름 | 새 표시 | 현재 상태 | 전용 스킬 |
|---|---|---|---|---|
| `on` | 온 | **루카 · 검사** | 선택 가능 | 바람 베기 |
| `dam` | 담 | **다렌 · 수호기사** | 준비 중·선택 불가 유지 | 철벽 반격 |
| `rin` | 린 | **미엘 · 마법사** | 준비 중·선택 불가 유지 | 별빛 봉인 |
| `gib` | 깁 | **기블** | Stage 20 적 보스 | 플레이어 스킬 대상 아님 |

이름은 모두 2글자 이상이다. 저장 ID, artId, 성장 별점, 해금 여부는 이름 변경으로 바꾸지 않는다. 기존 플레이어 진행도도 이름을 키로 다시 만들지 않는다.

토리·리나·바룬·도토는 현재 이야기 NPC이며 기존 이름을 유지한다. 토리·리나·바룬의 플레이어화는 후속 후보일 뿐이다. **마법사 미엘(`rin`)과 이야기 NPC 리나(`rina`)는 다른 인물**이다. 이 문서에서 NPC를 자동 합류 동료나 새 선택 캐릭터로 추가하지 않는다.

## 세 캐릭터가 함께 쓰는 발동 규칙

**완벽 대응 3회 → 공격 버튼에 준비 표시 → 다음 유효한 수동 공격에 전용 스킬 1회.**

1. 현재 판정으로 확정된 완벽 회피·완벽 쳐내기가 충전 1칸을 준다. 일반 성공은 0칸이다. 현재 조작인 위·뒤 회피와 아래 쳐내기를 그대로 쓴다.
2. 동일한 적 공격 판정은 한 번만 적립한다. 연속 공격의 별도 타격은 각각 인정한다. 3칸을 넘는 충전이나 다음 사용분 예약은 없다.
3. 실제 HP 피해를 받으면 1칸 감소한다. 0 밑으로 내려가지 않는다. 보호막으로 전부 흡수하면 HP 피해가 아니므로 감소하지 않는다.
4. 준비 상태에서 기존 공격 입력을 전투 세션이 접수하는 순간 3칸을 소모하고 해당 공격 ID에 사용을 기록한다. 입력 거절이면 소모하지 않는다.
5. 피해와 부가 효과는 기존 공격 접촉 시점에 한 번 처리한다. 현재 일반 속도는 시작 후 200ms이며 기존 공격 속도 보정을 그대로 따른다. 준비 순간이나 버튼을 누르기 전에는 적에게 아무 피해도 주지 않는다.
6. 접수 후 공격이 취소되거나 대상이 사라져 헛치면 피해·부가 효과는 없고 충전은 돌려주지 않는다. 성공한 스킬을 다시 환급하거나 대상마다 여러 번 처리하지 않는다.

현재 1,200ms 완벽 반격 입력 가능 시간, 공격 간격, 회피 무적·회복 시간은 바꾸지 않는다. 스킬 준비가 언제든 반격할 수 있는 권한이나 추가 무적을 주지 않는다.

### 충전 이월과 반복 발동 방지

- 같은 도전의 다음 적·보스까지 0~3칸을 이월한다. 보스를 만나기 전에 준비해 두는 선택은 허용한다.
- 사망, 도전 종료, 새 출전, 캐릭터 변경, 새 회차 시작은 0칸이다. 체크포인트에 충전 보너스를 저장하지 않는다.
- 이어하기를 실제 구현할 때만 기존 도전 저장에 충전과 사용한 공격 ID를 함께 보존한다. 구버전 저장은 0으로 시작한다. 영구 성장 데이터에는 넣지 않는다.
- 공격 적중, 스킬 피해, 치명타, 기절, 유물, 보호막 흡수는 충전을 주지 않는다. 튜토리얼 강제 성공도 제외한다.
- 일시정지·달리기 전환·보스 등장·대사 장면은 충전 판정을 만들지 않는다. 같은 이벤트나 같은 공격 ID를 재처리해 충전·피해를 복제할 수 없다.
- 충전용 별도 쿨타임·자동 회복은 없다. 다음 스킬은 다시 실제 적 공격 3회를 완벽히 대응해야 한다.

## 루카 · 바람 베기

작은 등짐과 한손검을 든 첫 의뢰의 모험가. 세 캐릭터 중 가장 직관적으로 **큰 한 방**을 만든다.

| 항목 | 기획값 |
|---|---|
| 발동 | 공통 3칸을 소모한 기존 수동 공격 |
| 피해 | 기존 공격의 **160%**, 1회 |
| 부가 효과 | 없음 |
| 사용처 | 지금 큰 피해를 넣을지, 적 누적 100까지 기다려 같은 타격으로 기절도 열지 선택 |
| 화면 문구 | `다음 공격 피해 160%.` |

현재 달려가서 베고 돌아오는 모션을 유지한다. 랜덤 사선 참격 폭을 1.25배로 하고 크림색 도트 잔상을 80ms 남긴다. 잔상은 추가 타격이 아니다. 이동 거리·공격 회복·무적을 늘리지 않는다.

공격력 유물과 행운에 따른 치명타는 기존 공식대로 한 번 적용한다. 여러 참격이 겹쳐 보이더라도 피해 팝업·치명 판정·적중 이벤트는 하나다. **3칸이면 다음 공격이 스킬을 소모하므로 기절 진입 타격을 평타로 넘기고 스킬만 보관할 수 없다.** 기절을 여는 첫 타격은 기세 피해 배율을 받지 않고 이후 평타가 그 보상을 받는다.

## 다렌 · 철벽 반격

길을 먼저 살피는 믿음직한 기사. 타이밍을 잘 맞춘 뒤 **다음 실수 한 번을 일부 완충**한다.

| 항목 | 기획값 |
|---|---|
| 피해 | 기존 공격의 **115%**, 1회 |
| 부가 효과 | 실제 적중 후 **최대 HP의 8% 보호막**, 최대 **3초**, 적 피해 **1회**에 소모 |
| 보스 적용 | 같은 8%. 보스 피해를 추가로 줄이는 보정 없음 |
| 화면 문구 | `피해 115%. 적중하면 3초간 체력 8%를 1회 보호.` |

보호막은 기존 피해 감소를 적용한 뒤 남은 적 피해에서 차감한다. 흡수량보다 큰 피해는 HP에 들어온다. 작은 피해를 받아 보호막이 남더라도 그 한 번으로 종료한다. 회피·쳐내기에 성공하면 보호막을 소모하지 않는다.

3초는 기존 전투 시계를 따른다. 적 처치·전투 이탈 시 남은 보호막은 사라진다. 재발동하면 기존 보호막을 교체하고 합산하지 않는다. HP 회복·부활·경직 면역·3초 무적은 아니다. 여러 발짜리 보스 공격 전체를 무대응으로 넘길 수 없다.

생명의 목걸이와 튼튼한 팔찌가 반영된 최대 HP를 사용한다. 수호 망토의 기존 피해 감소 상한도 그대로 적용한다. 흡수 성공은 완벽 대응이 아니므로 충전이나 기절 누적을 만들지 않는다. HP 피해를 전부 흡수해도 방어 실패에 따른 기존 완벽 연속 횟수 초기화와 기절 누적 손실은 유지한다.

시각적으로 작은 사각 방패 테두리와 HP 아래 16px 상태 아이콘을 쓴다. 파괴 시 사각 조각 4개로 끝낸다. HP가 실제 감소한 타격의 흰 피격 플래시는 유지한다.

## 미엘 · 별빛 봉인

긴 주문보다 적의 균형을 보는 여행 마법사. **다음 기절을 조금 앞당기는 선택**을 담당한다.

| 항목 | 기획값 |
|---|---|
| 피해 | 기존 공격의 **125%**, 1회 |
| 부가 효과 | 기본 기절 누적 **+50** |
| 일반 / 중간 보스 / 보스 | **50 / 30 / 20**. 기존 저항 1 / 0.6 / 0.4 적용 |
| 면역 | 이미 기절했거나 기절 후 2초 면역이면 추가 누적 **0** |
| 화면 문구 | `피해 125%. 기절 누적 +50. 보스 저항 적용.` |

공격 피해→살아 있는 적에게 추가 누적→100 도달 확인→기절 순서다. 이 타격으로 기절에 들어갔다고 같은 타격의 피해를 소급 증폭하지 않는다. 기절 중 추가 누적을 저장하거나, 종료 후 면역을 건너뛰거나, 스킬 자체로 기절 시간을 연장하지 않는다.

바위 부적·바람 깃털 및 완벽 대응 연속 보너스는 실제 방어 성공에만 쓰므로 고정 누적 50에 다시 곱하지 않는다. 기절 적 피해 유물은 기존처럼 **이미 기절한 적**을 공격할 때만 반영한다.

제안값 50의 이유: 기절 누적 유물 없는 보스의 완벽 대응 4회는 `16 + 19.2 + 22.4 + 25.6 = 83.2`다. 보스에게 적용되는 추가 20이면 100에 도달해, 일반적으로 다음 완벽 대응까지 기다릴 상황에서 미엘이 수동 공격으로 기절을 앞당길 수 있다. 예전 초안의 기본 30(보스 +12)은 95.2라 이 차이를 만들지 못해 조정했다. 실측 밸런스 확정값은 아니다.

접촉 순간 적의 몸 안쪽에 작은 사각 별 하나를 120ms 표시한다. 큰 문양·지속 피해·자동 추적 투사체는 추가하지 않는다. 기절 여부는 기존 게이지와 기절 모션이 알려 준다.

## 성장과 기존 시스템 관계

별도 스킬 레벨과 재화를 만들지 않는다. 해당 캐릭터를 향후 해금할 때 전용 스킬도 함께 사용한다. 스킬 자체의 배율과 요구 충전 3칸은 고정하고, 기존 스탯과 별점의 의미를 유지한다.

| 기존 요소 | 스킬에 미치는 영향 |
|---|---|
| 공격력·공격 별점 | 세 스킬의 피해 원본 증가 |
| 체력·체력 별점 | 다렌의 8% 보호막도 함께 성장 |
| 행운 | 현행 치명 확률로 스킬 1회당 1번 판정. 재화 수급은 기존 처리 |
| 기세 | 기존 기절 적 피해 공식과 해당 배율 상한 6 유지. 충전 증가 없음 |
| 11·21·31·41레벨 돌파 | 기존 스탯 증가를 통해 자연스럽게 반영 |
| 유물 | 원래의 공격·HP·치명·기절 피해 효과만 한 번 적용. 별도 스킬 충전 루프 없음 |

피해 공식은 `기존 공격력 × 스킬 배율 × 기존 치명 배율 × 기존 기절 적 피해 배율`이며 기존 정수 피해 처리를 마지막에 한 번 한다. 막타의 보상·다음 스테이지·흔들림도 기존 1회 처리다.

## HUD와 안내 초안

전투에는 새 스킬 버튼이나 긴 설명을 추가하지 않는다. 기준 1280×720에서 **기존 공격 버튼 상단 중앙에 32×8px 표시**를 붙인다. 버튼 위 기준 상대 bounds는 `x -16 / y -16 / width 32 / height 8`이며, 8px 칸 3개와 사이 4px 여백으로 구성한다. 표시만 추가하고 기존 터치 영역은 바꾸지 않는다. 실제 프리팹과 최소 화면 확인은 후속 구현 때 한다.

빈칸 → 한 칸 → 두 칸 → 세 칸과 공격 아이콘 외곽선 한 겹으로 읽는다. 색뿐 아니라 채움과 테두리로 구분하고, 음향·진동 없이도 준비를 알 수 있게 한다. 전투 중 상시 `바람 베기 준비 완료` 같은 텍스트는 넣지 않는다.

로비의 기존 캐릭터 상세에 스킬명과 위 짧은 설명을 붙인다. 공통 규칙은 `완벽 대응 3회 후 다음 공격 강화.` 한 줄이다. 초반 회피→공격 튜토리얼을 늘리지 않고, 후속 스킬 구현 때 최초 준비 순간 안전한 구간에서 공격 버튼만 한 번 강조한다.

## 후속 구현 완료 기준

다음은 이번에 수행한 테스트가 아니라 구현 담당이 확인할 기준이다.

- 같은 적 공격을 중복 통지해도 1칸만 얻는다. 같은 스킬 공격 ID에서 피해·보상도 한 번이다.
- 충전 3칸 상태에서 공격을 누르기 전에는 아무 피해도 생기지 않는다. 잘못된 입력은 충전을 잃지 않고, 접수 후 헛친 공격은 환급되지 않는다.
- 같은 도전의 다음 적에는 충전이 이월되지만, 사망·새 도전·캐릭터 변경에는 초기화된다.
- 다렌의 보호막은 실패 대응 1회만 완충하며 보스 연속타 전체를 막지 않는다.
- 미엘은 저항과 기절 후 면역을 우회하지 않고 스킬로 스스로 충전을 얻지 않는다.
- 루카의 공격 연출이 여러 겹이어도 1회 적중이며 현재 조작과 공격 시계를 유지한다.
- 같은 성장·같은 입력 기록으로 피해·피해 완충·기절 도달 시점을 비교한다. 적을 일부러 오래 살려 충전하는 것이 최적 공략이 되지 않는지 확인한다.

담당: 캐릭터·스킬 기획 세션. 총괄이 새 이름과 공통 수동 발동 구조를 확인했다. 전용 스킬 런타임 구현, 해금 변경, 실제 게임 플레이 검증은 이 기획 작업에서 수행하지 않았다.
