# Dragon 대사 초상화

48×48 네이티브 픽셀 초상화. 게임의1280×720 기준에서는144×144(3배)로 사용한다. 파일 이름은 안정적인 화자 ID다.

| ID | 화자 | 식별 요소 |
|---|---|---|
| on | 루카 | 갈색 머리, 붉은 스카프, 청록 튜닉 |
| dam | 다렌 | 강철 머리띠와 어깨, 크림·청색 갑옷 |
| rin | 미엘 | 청록 모자, 금발, 짧은 크림 칼라 |
| tori | 토리 | 주황 여우 얼굴과 큰 두 귀, 청록 망토 |
| rina | 리나 | 자주색 큰 모자, 갈색 머리, 크림 로브 |
| barun | 바룬 | 검은 머리, 넓은 어깨, 붉은 목도리 |
| doto | 도토 | 금빛 큰 수염, 크림 소매와 청색 앞치마 |
| gib | 기블 | 녹색 고블린 얼굴·긴 귀, 작은 투구와 주황 깃털 |
| unknown | ??? | 첫 호출에서만 사용하는 토리의 단색 실루엣 |

Point / Single Sprite / No Compression / No Mipmaps. `manifest.json`에 Unity 복사 경로와 PNG해시를 기록한다. 원본은 `raw/`, 최종 선택은 루트 `{id}.png`. 실패한 도토·기블 첫 후보는 원본 기록으로 보존하되 게임용 경로에는 선택한 최종본만 연결한다.

사용자에게 보이는 화자명은 이 파일명이 아니라 게임 데이터에서 가져온다. 미엘(`rin`)과 리나(`rina`)는 서로 다른 인물이다. 초상화를 동료 전투 AI나 플레이어 해금으로 해석하지 않는다.
