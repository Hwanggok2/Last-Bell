HP 도트 강화 · UI v2

체력바 중심과 너비는 유지하고 높이를 24 → 36px로 조정합니다. 9칸 높이의 계단형 외곽선, 회색 끝부분, 4칸 채움 + 1칸 구분으로 도트 덩어리를 분명하게 만듭니다. 인게임 숫자나 별도 장식은 추가하지 않습니다.

1280×720: 플레이어 160×36, 적 184×36, 보스 280×36, 1칸 4px. 640×360: 각각 80×18 / 92×18 / 140×18, 1칸 2px. 막대당 5색, 그라데이션 없음.

실제 HP 값은 그대로 표시합니다. 0은 빈 칸, 0보다 크면 최소 한 열, 100%는 모든 채움 칸을 표시합니다. 회색 끝부분과 검은 구분선은 체력에 포함하지 않습니다.
