# 다렌·미엘 모션 소스 검수

2026-10-24 · 제작/소스 검수: `/root/dragon_playable_art_v4`

PixelLab으로 새 기준 외형을 만들고, 기존 Player-v3 루카의 승인된 동작을 `transfer_outfit`로 재생성했다. 루카 프레임의 색만 바꾸는 방식은 사용하지 않았다. 다렌은 강철 어깨와 작은 청색 방패·한손검, 미엘은 금발과 짧은 청록 모자·수정봉으로 구분된다. 리나의 자주색 큰 모자·긴 크림 로브와도 구분된다.

## 확인한 산출물

- 두 캐릭터 각각 Idle8 / Run8 / Attack14 / DodgeUp8 / DodgeBack8 / Hit6. 물리 원본52개, 총104개.
- DodgeDown은 기존 쳐내기 계약에 따라 Attack14를 재사용한다. 런타임 클립 참조는 총132개다.
- `reviews/`의 12개 전체 프레임 시트를 직접 확인했다. 각 프레임의 얼굴·의상·장비가 같은 캐릭터로 이어지고, 달리기 시 몸 기울기와 팔·다리의 교차가 보인다.
- 검과 수정봉은 준비 자세에서 뒤로 빼고 위로 휘두르는 궤적을 유지한다. 런타임의 랜덤 사선 참격·피해 판정은 별도이며 PNG에 이펙트를 굽지 않았다.
- 미엘의 무기는 큰 지팡이가 아니라 짧은 수정봉이다. 작은 캔버스에서도 준비/회피/공격 전체에서 손에 붙고 끝이 보이도록 길이를 제한했다.
- 다렌의 방패는 몸이 돌아갈 때 옆면이 좁아지며, 정면에 가까운 자세에서 청색 면이 크게 보인다. 공격 동작에 맞춰 몸 양쪽으로 위치가 바뀌는 것은 몸 회전에 따른 것이다.

## 수치 검사

`validation.json`은 실제 PNG를 검사한 결과다. 모든 프레임32×32, 이진 알파, 프레임당8색 이하. 각 클립은 최소3개 이상의 실제로 다른 픽셀 프레임이다. 모든 프레임의 불투명 영역 최하단이 대응하는 루카 소스 프레임과 정확히 같다.

| 동작 | 고정 피벗(좌상단 기준) | 발 접지 / 의도한 상승 |
|---|---|---|
| Idle |16,29| 모든 프레임 최하단29(exclusive) |
| Run |18,29| 2·6번 프레임만 최하단27, 나머지29 |
| Attack / DodgeDown |17,30| 모든 프레임 최하단30 |
| DodgeUp |16,29| 최하단29,28,27,26,27,28,29,29 |
| DodgeBack / Hit |16,29| 모든 프레임 최하단29 |

공격500ms·접촉200ms, 달리기400ms는 기존 승인값 그대로다. 이미지별 발 위치를 다시 가운데 정렬하거나 애니메이션 전체를 수직 이동시키지 않았다. 다렌 기준 신장22px, 미엘은 모자 포함24px, 둘 모두720p 권장7배이며 소스 픽셀의 실제 확대율이 같다.

## 범위

소스 프레임·명세·색 수·접지·타이밍 검사 완료. `review.html`은 실제 프레임을 순서대로 재생하도록 제공한 검수 뷰어다. 이 담당은 Unity 씬/프리팹/런타임/카탈로그를 편집하지 않았으며 실기기 재생·돌진/복귀·타격감 QA는 통합 후 별도다. 브라우저 뷰어의 실제 화면 재생 검증을 했다고 주장하지 않는다.
