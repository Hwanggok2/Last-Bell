# 온 · 밝은 판타지 제작 자산

기준 이미지는 `canonical.png`이다. 48×48 투명 캔버스에 몸 높이26px, 불투명7색이다. 원화의 크림 후드·남색 얼굴과 몸·황토 스카프·짧은 한손검을 유지한다. Unity 파일은 이 폴더에서 수정하지 않는다.

`manifest.json`에 프레임 경로, fps, 발 피벗, 기준 몸높이, 시각용 접촉 프레임과 생성 job을 기록한다. `clips/`가 팔레트를 고정한 등록 대상이고, `requests/`는 원본 프롬프트와 영수증이다. 입력 프레임을 제외한 실제 생성 프레임만 사용한다.

원본 키가48이므로 화면표시 키를48×배율로 계산하면 안 된다. 기준 몸높이26을 사용하며 정수6배에서156px 높이다. 발 피벗은 원본 좌상단 기준(21,38), Unity 정규화로(0.4375,0.2083333)이다.

회피와 달리기는 포즈다. 실제 이동, 회피 판정, 공격 데미지, 기절 시간은 기존 런타임 시계가 소유한다. `contactFrame`은 베기 및 방어 자세의 시각 정렬을 위한 정보이며 판정 시간을 변경하는 근거가 아니다.

완료 묶음은 Idle·Run·Attack·DodgeUp·DodgeBack·DodgeForward·DodgeDown·Hit·Stun의 9종, 총70프레임이다. Hit은6프레임, 나머지는8프레임이다. 모든 클립에서 서로 다른 실제 픽셀 프레임을 확인했다. `manifest.json`의 `actors[0].clips`를 통합 입력으로 사용한다. 시각 검토와 미완료 런타임 검증은 `visual-review.md`에 구분했다.

Run만 클립 공통 피벗(21,40)을 사용한다. 지면 접지 프레임6장과 발이2px 뜨는 비행 프레임2장을 그대로 보존한다. 프레임별 발높이를 보정하지 않는다. Run 재생20fps는 기존400ms 주기를 유지하는 값이며, 추가1.5배를 다시 곱하지 않는다. 기본 캐릭터 월드높이는720px 기준 카메라6.2에서156px를 표시하도록1.343333333이다.

Attack의 시각 접촉 프레임은0부터 세어5이다. 기존 런타임 공격 접촉0.2초에 맞춰 재생구간을 배분한다. DodgeDown은 검을 세워 막는 쳐내기이며, DodgeForward는 자산만 준비한 상태로 조작 변경을 뜻하지 않는다.

서비스 약관 기록은 `license.json`을 참조한다. 기존 시안 파일 업로드는 자동 승인 검토가 거절해 실행하지 않았고, 텍스트로 생성한 원본을 로컬 시안과 대조했다. 이후 모션은 PixelLab 자체 생성 원본 URL만 참조한다.
