## 실제 차이와 추천

NPC들은 머리·몸·장비·신발의 노출된 경계를 짙은 남색으로 잡는다. Player-v2는 머리/가방의 외곽을 갈색 면 그대로 끝내고, 무기/신발에는 남색 외곽이 남아 있어 같은 인물 안에서도 경계 처리 강도가 다르다. 실제 밝은 전투 배경에서 머리와 가방이 NPC보다 부드럽게 퍼져 보이는 원인이 된다. NPC 토리의 청록 옷과 바룬의 따뜻한 붉은색에 비해 기존 루카의 상의는 녹색, 목도리는 어두운 자주색 성분이 강했다.

원형은32px 캔버스이고 실제 불투명 높이는 y7~28의22px다. 머리/얼굴은 y7~15의9px, 약41%다. 초기 전달한11px/약절반은 목도리까지 포함한 시각 추정이었으므로 정확한 native 측정으로 정정한다. NPC 원본은 고해상도 분위기 컨셉이며 엄밀한32px/8색 게임 시트가 아니다. 토리의 귀·리나의 모자·도토의 수염까지 머리 크기로 일괄 비교해서 모든 NPC의 머리 비율이 작다고 단정할 수 없다. 비율보다 외곽과 색 면의 일관성을 우선하는 근거다.

두 원형을 실제 PixelLab 정밀 편집으로 만들었다.

| 안 | 실제 수정 | 판단 |
|---|---|---|
| A | 노출된 머리/가방 갈색28px를 원래 남색으로 정리. 튜닉/목도리2색 매핑. alpha·얼굴·눈·손·검·발·몸 비율 불변. | **채택.** 원래 젊은 모험가의 형태를 유지하면서 NPC의 외곽 처리와 연결된다. |
| B | A에 머리 캡1행 축소를 추가. 머리 위쪽만 낮춰 전체 높이22→21px. | 미채택. 비율 차이는 작고 머리가 납작해 보이는 손해가 있어 불필요하다. |

후드나 종, 무거운 갑옷을 다시 넣지 않았다. 루카의 짧은 갈색 머리·목도리·짧은 튜닉·작은 여행 가방·단일 검이라는 모험가 정체성을 유지한다.

## 52프레임에 적용한 원칙

PixelLab `pixelart_workbench`의 guarded `patch_pixels`와 정확한 `map_colors`만 사용했다. AI로 프레임별 자세를 다시 생성하지 않았다. 머리 갈색 연결 영역과 크림 두루마리 옆 가방에서 외부로 드러난 갈색 테두리를 골랐고, 검에 인접한 손잡이 부분을 제외했다. 프레임별 좌표·원래 예상색은 `requests/*-style.json`에 남아 있다. 이 방식은 일괄 외곽 팽창이 아니며 모든 alpha 바이트가 원본과 같다.

공유8색 중 튜닉만 `#287780`, 목도리만 `#A23B2D`로 바꾸고 나머지 색을 유지했다. 피부 `#F3BD83`, 손/가방 밝은 갈색 `#AB6C37`, 강철 `#B7D3D0`, 크림 `#E8D9AD` 픽셀은 정확히 동일하다. 기존 갈색/남색 장화 픽셀도 유지된다. 옷자락의 청록은 아래 행에서도 같은 팔레트 매핑을 받으므로 하단8행의 모든 RGB가 동일하다고 주장하지 않는다. 기존 Back05 발끝의 초록1px도 위치·alpha를 그대로 두고 같은 팔레트 매핑만 받았다. 새로 발 모양을 고치거나 새 장비를 만들지 않았다.

`validation.json`의52개 프레임에서 원본 PNG 해시 불변, alpha 차이0, 명세 외 변경0, 보호색 변경0, 기존 장화 재질 변경0을 확인했다. 팔레트는 공유8색이며 몸 회전으로 크림 두루마리가 가려진 일부 원본 공격 프레임은7색이다. 사용 색 수는 각 원본과 동일하다. Idle8은7개 고유 프레임이며 아래 쳐내기는 Attack14 재사용이다.

## 접지와 모션 기준

| 클립 | 공통 pivot, 좌상단 source px | 보존 사항 |
|---|---|---|
| Idle / Up / Back / Hit | `[16,29]` | 기본 발바닥 기준. Up03은 다리를 접어 올린 자세로 유지. |
| Run | `[18,29]` | 원본 전체 여백+2를 반영한 공통 피벗. 8장400ms `[40,40,60,60,40,40,60,60]`. |
| Attack / 아래 쳐내기 | `[17,30]` | 원본 공통 +1px와 피벗 동반 이동.14장/contact7. 전진·베기·회수/복귀 시간은 기존 값. |

Run의 발 최하단은 y28/28/26/28/28/28/26/28이다. 02/06의2px 높은 발은 체공이며, 매 프레임을 최하단에 다시 정렬하면 발 구름을 훼손한다. 위 회피의 공중 offset이나 공격 후 검을 내리는 회복도 기존 동작 그대로 둔다. 모든 클립의 fps/loop/contact/effectOrigin/pivot/sourceIndices/frameDurations/referenceHeight는 원본 manifest와 대조했다.

기존 Unity 스크린샷은 캐릭터가22px×7=154px 정도로 표시된다. 부츠 열 x470/480/510/520을 읽으면 마지막 남색 행은y468이고 y469부터 배경, 흙 면은y470부터 나타난다. 이것은 해당 스크린샷에서 확인한 사실이며 새 런타임의 모든 자세가 이미 접지 검증됐다는 뜻은 아니다. Sprite importer는 top-left pivot을 Unity 좌하단 좌표로 변환하고 ActorView는 referenceHeight로 스케일한다. 새 아트는 이 기준·원본 alpha를 유지하므로 지면 기준을 바꾸지 않는다. 총괄이 관리하는 전역 GroundPoint를 이 묶음에서 수정하거나 프레임별 위치 보정으로 대신하지 않았다.

## 최종 인계 상태

총괄이 NPC 원본·원형 비교·6개 최종 시트를 직접 확인하고 A안 및52프레임을 **게임 연결용으로 채택**했다. 새 실루엣 변형·손/검 분리·장비 소실이 없고, 이전 전경/발 교대/베기/위·뒤 회피 의미가 유지된다. `manifest.json`은 `ready`, actor ID는 `hero_on`, 화면 이름은 `루카`다.

이 폴더만 제작/수정했다. 기존 Player-v2, SimpleGame 원본, Unity 코드 및 실행 상태는 변경하지 않았다. 원본6종 시각 검토와 정밀 보존 검사를 완료한 상태이며, 게임 실시간 입력·접지 속도·타격 판정·UI 합성 QA는 총괄의 별도 검증이다. Player-v3 소스는 인계 후 동결한다.
