# Forest-v1 · 솔바람숲 11–20

현재 상태: `ready` — 제작 담당·총괄·독립 담당의 최종 원본 검토를 마쳐 통합용으로 동결했다. 기획 `story.json`의 11~20 목록을 새 게임용 원본으로 제작했다. 1~10층 원본이나 기존 어두운 분위기의 적을 이름만 바꾸어 재사용하지 않았다. Unity 실행 검증은 총괄의 통합 QA에서 별도로 진행한다.

대상은 숲길 고블린, 돌팔매 고블린, 숲송이, 방패 고블린, 숲송이 대장, 창 고블린, 포자 숲송이, 이끼 숲송이, 기블의 문지기, 기블이다. 같은 계열의 기본 해부학은 공유하되 장비·갓·몸폭·실루엣이 구분되는 10개 원형을 별도 생성한다.

모든 원형은 PixelLab ProFlash로 생성했다. 기본 모션은 원형을 입력한 PixMiniMax, 숲길 고블린·문지기·기블의 공격은 실제 손/무기 위치를 확인해 지정한 Skeleton v3다. 고블린 6종·버섯 4종에 각 Idle/Attack/Stun이 있다. PixMiniMax의 0번은 입력 원형이고 Skeleton v3의 0번은 첫 출력 포즈다. 이 차이를 manifest의 inputFrameReturned와 sourceIndices에 구분했다.

최종 모션은 30클립/235샘플이다. 돌팔매 공격은 6장/6고유, 이끼 공격은 7장/7고유, 기블 공격은 6샘플/4고유이며 나머지 27클립은 8샘플이다. 8샘플 안에도 의도적인 유지 자세가 있어 uniquePixelFrames를 별도로 기록한다. 기블은 생성된 깨진 타격/회수 프레임을 제외하고 온전한 source0을 접촉·경계 유지에 재사용했다. source[0,1,2,3,0,0]은 창을 당기는 3단계와 빠른 신전, 유지로 재생한다. 8개의 다른 동작이라고 주장하지 않는다.

공통 규격은 좌향 전투 측면, 투명 배경, 남색 외곽과 거친 평면색이다. 캔버스는32×32/48×32/48×48, 실제 불투명 색은5~8개, alpha는0/255다. 권장 720p 표시 높이는 일반168~210px, 중간보스310px, 보스378px이며 원형의 실제 불투명 높이에 정수배율을 곱한다. 모두 actor 공통 pivot을 사용하고 발바닥 최하단은 pivotY-1이다. 프레임마다 bbox를 정렬하지 않았다. 각 클립의 groundedFrameIndices/airborneFrameIndices와 기록의 opaqueBottomOffsetFromSole를 확인할 수 있다.

최종 게임용 파일은 각 actor의 `canonical-final.png`, `production/idle`, `production/attack`, `production/stun`이다. `production-contact.png`는 최종10원형을 같은5배 확대 및 발 기준으로 보여 준다. 각 actor의 같은 이름 파일은 최종 모션 전체 시트다. 이 시트에서 게임 스프라이트를 잘라 만들지 않는다. 원본/거절 후보는 raw·attackretry·attackskeleton 폴더에 보존했고 최종 선택은 manifest만 따른다.

접촉 프레임은 0부터 센다. 문지기와 기블은 500ms 참고 노출 시간을 기록했으며 접촉4가 200ms에 시작한다. 나머지 클립의 fps는 시각 재생 기본값이다. 실제 공격 판정·예고 게이지·반응 시간은 런타임 데이터가 관리하므로 애니메이션 길이로 임의 변경하지 않는다. 얼굴 기준은 actor.faceAnchorTopLeft와 보스 clip.faceAnchorsTopLeft에 있고, 공격의 effectOriginTopLeft와 함께 PNG 좌측 위 기준 픽셀 좌표다.

숲송이·대장·이끼는 몸 압축/내리찍기로 뿌리·포자를 방출하는 동작이며 별도 효과가 플레이어 쪽에 생긴다. 기존 방향별 패턴과 판정을 유지한다. 원본에 덧붙은 먼지·돌·마법 궤적은 제거하여 런타임 효과와 중복하지 않는다. Unity 및 기존 아트 manifest는 이 폴더 제작에서 수정하지 않았다.

`jobs.json`은 원형 요청·결과 및 최초 모션 요청의 입력길이 검증 실패를 보존한다. 해당 실패는 생성 전 검증에서 끝났으며, 실제 생성된 모션의 job ID는 `animation-jobs*.json`을 기준으로 한다.
