# 거친24px 대화 초상화 시안

기획 전용 새 시안이다. Unity, GameData, 임포터, 기존 Portraits-v1은 수정하지 않았다. 최종확정/게임적용 상태로 표시하지 않는다.

기존9개 화자 ID를 유지한다. 실제 캐릭터8명은 PixelLab Pro Flash에서 네이티브24×24로 새로 그렸고, unknown은 새 토리 그림의 실루엣만 남기는 PixelLab workbench 수정으로 만들었다. 기존48×48 초상이나 NPC원화는 머리·귀·수염·의상색을 확인하는 정체성 참고로 사용했다. 기존 초상의 단순 축소본이 아니다.

- `tori.png`: 먼저 검토할 대표 토리 시안.
- `review.png`: 전체9종을6배 확대해 비교하는 시트. 시트의 베이지 바탕은 검토용이며 개별 PNG에는 없다.
- `comparison.png`: 위 기존48px(3배), 아래 새24px(6배)를 같은 표시 크기로 비교한다.
- `manifest.json`, `validation.json`: 실제 크기·색 수·알파·해시.
- `requests/`: 최종 프롬프트와 생성 job, 처리 결과. 기본 tool 생성 PNG를 원본 크기로 보관했다.

표시 제안은 대사 패널 우측 상단에144×144(6배) cutout으로 올리는 것이다. 초상 자체에 사각 배경·프레임·별도 테두리를 붙이지 않는다. 대사 글자는 초상 발자국을 피하도록 폭을 제한한다. 패널과의 정확한 겹침량은 전체 UI 시안에서 결정한다.

실제 PNG는 모두24×24, 알파0/255. 보이는 색은5~8개(미공개 실루엣1개)다. 목표6~8색보다 적게 필요한 그림은 불필요한 색을 추가하지 않았다. 토리의 큰 귀·주황색·크림 주둥이·청록/파랑 스카프, 리나의 자주색 큰 모자, 도토의 금빛 큰 수염, 바룬의 검은 머리·빨간 목도리를 유지했다.

생성 제약: PixelLab edit_image는24px 요청을 최소32px 제한으로 거절했다. 해당 요청은 산출 없이 끝났으며, 네이티브24px를 지원하는 Pro Flash 신규생성으로 진행했다. 별도32px 확대/다운샘플 결과를24px 원본이라고 부르지 않는다.

신규5번째 NPC는 인물기획 미정이므로 이 묶음에 포함하지 않았다.
