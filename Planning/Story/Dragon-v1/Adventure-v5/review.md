# Adventure v5 기획 교차 검토

2026-10-24 · 기획 전용. Unity v0.9.3 소스·게임 데이터·저장 프리팹·빌드는 변경하지 않았다.

## 담당과 근거

- 총괄: 기존 UI 와이어프레임·짧은 문구 및 Unity 프로젝트 기반 스킬 적용. 화면·전투·튜토리얼 계약, 기존 기획 진입점 연결.
- 전투·대화 담당 `dragon_dialogue_v4`: 현재 HP 대입 경로와 첫 콤보 예약 시각을 읽기 전용 조사. 통합 화면과 상태 계약을 독립 검토.
- 성장 담당 `character_skill_plan`: NPC 배치, 서비스, 동료 성장·슬롯·자동 공격·회복력 수식과 기존 데이터 비용 검산.
- 아트 담당 `dragon_playable_art_v4`: PixelLab로 기존 인물의24px 초상8종 재제작 + 토리 기반 미상 실루엣1종. 각 원본·프롬프트·팔레트·알파 검토. 기존48px 파일 해시 보존.

## 논의 후 반영한 결정

1. NPC 첫 만남은 지역 중반5층 대신 지역 초반2·12·22·32·42로 변경했다. 각 지역에서 동행 효용을 먼저 느끼고 보스 연출과 대화가 겹치지 않는다.
2. 동료 자동 공격의 숨은 '최근6초 수동 입력' 조건을 없앴다. 주기·피해 상한·기절 미기여로 수동 전투의 비중을 지킨다.
3. 첫 콤보는 실제 데이터상5스테이지다. 일반 판정1800/2550ms는 유지하고, 순서 소개 종료900ms와 현재 타격 진행 표시를 분리했다.
4. 일반 피격으로 적 공격 큐를 취소하는 것으로 읽히던 문구를 고쳤다. 피격은 시각 반응이며 Core가 기절·사망으로 취소했을 때만 공격을 끊는다.
5. 대화창과 여관 시안은 실제24px 초상으로 다시 렌더했다. 강화 가격80G 초안을20G로 맞추고 지원 공격은 토리의 활 정체성을 유지했다. 픽셀 글꼴에서 깨진 화살표 기호도 교체했다.
6. 여관 목록 행을96px로 맞췄다. 640×360 기준48px 터치 크기를 명세·시안에 함께 반영했다.
7. 기존에 만난 리나·도토를 다시 잠그지 않는다. 완료된 seenStoryIds를 캐릭터 간 합집합으로 이전하며, 토리는 옛10보스 대사 기록도 포함한다. 진행 중인 옛 장면의 ID·페이지를 보존해 정상 종료시킨다.
8. 새 계정의1~20 첫 만남은2명, 이전 계정은 최대4명이다. 첫 구현 묶음에 기존4NPC의 서비스·지원 공격 데이터 지원을 포함했다. 도토1단계는 NPC 해금으로 접근하고 후속 단계의30/40보스 조건은 유지한다.
9. 첫 토리는 빈 슬롯에 즉시 동행해 다음 전투부터 지원한다. 이후 새 만남은 빈 슬롯에 한해 합류 선택을 제공한다. 상시 편성 변경·강화는 여관에서 한다.
10. 튜토리얼의 completed 또는 skipped는 자동 재진입을 막는다. 도움말 연습은 실제 원정의HP·쿨타임·진행과 분리해 보상 없이 재생한다.

11. 마지막 리듬 검토에서 첫 후퇴를 CueAt 기준 대신 Impact−500ms 시작으로 고쳤다. 후속 후퇴는−370ms부터 짧게 진행하며 두 경우 모두 후퇴 종료 뒤90ms 준비·160ms 전진으로 통일한다. 전투 담당이 실제750ms 연타 간격과 이전 복귀에 겹치지 않음을 검토했다.
12. 최종 변경분 재검토에서 기존 지적의 반영을 확인했고, 마지막으로 동료 데이터에 남아 있던 여관 배치 설명을 확정 시안에 맞췄다.

## 확인 범위와 남은 작업

흑백 배치와 색 시안을 별도 PNG/SVG로 만들고 대화·여관·성장·리듬 이미지, 새 초상 비교 시트를 직접 확인했다. 초상·본문·다음 버튼이 분리되고 이름표가 패널 왼쪽 위에 배치된다. 정적 링크·JSON 계약·초상24px/8색 이하/이진알파는 `validation.json`으로 검사한다.

HTML은 로컬 파일 탐색 제한으로 브라우저에서 직접 렌더·조작하지 않았다. PNG 확인을 브라우저나 실기기 QA로 대신 주장하지 않는다. 동료 자동 공격 모션, 몬스터 후퇴 포즈, 신규 모모 초상은 다음 구현·아트 제작 범위다. 수치와 DPS 비율은 계산상 초안이며 실제 전투 밸런스 실측이 아니다.

구현 완료 후 전용 QA를 한 번 진행한다. 이후에는 발견한 결함에 필요한 확인만 추가한다. 이번에는 Unity 실행·테스트·빌드·커밋·푸시를 하지 않았다.
