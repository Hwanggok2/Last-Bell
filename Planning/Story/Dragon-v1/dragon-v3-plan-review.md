# Dragon v3 독립 기획·시각 검토

2026-10-24 · 검토 담당: `character_skill_plan`

**루카 A안과 현재 지면 기획은 같은 게임의 방향으로 연결된다.** 신규 스킬·차별성 기획과 충돌하는 전투 규칙 변경은 발견하지 않았다. 전체 50스테이지 명세, 현재 실행 20스테이지, 아직 제작하지 않은 바닥 장식의 범위도 구분되어 있다. 아래 두 문구를 보완하면 미래 공중형 몬스터와 보스 카메라에서 생길 오해를 줄일 수 있다.

## 실제로 확인한 자료와 범위

- [NPC·루카 원형 비교 PNG](Production/Player-v3/reviews/canonical-comparison.png)를 이미지로 직접 확인했다.
- [A/B 변경 기록](Production/Player-v3/requests/canonical-comparison.json), [클립별 스타일 작업 목록](Production/Player-v3/requests/style-plan-index.json)을 읽었다.
- [지면 데이터](stage-ground-v1.json), [지면 HTML 섹션](stage-ground-section.html), `Tools/build-dragon-ground-plan.py`를 읽었다.
- [전용 스킬](character-skills-v1.md), [게임 정체성](dragon-identity-v1.md)과 문구·적용 범위를 대조했다.
- 계획 좌표와 기본 카메라 값은 `ParallaxWorld.cs`와 `BattlePresentation.cs`를 읽어 대조했다. Unity 실행·씬 조작·코드 변경은 하지 않았다.

이 검토는 원형 이미지와 기획 자료에 대한 검토다. 모든 v3 모션의 실제 재생, Unity 접지 렌더, 모바일 입력, HTML 브라우저 렌더를 검사했다는 뜻은 아니다. A안의 전 프레임 alpha·피벗 보존도 이 한 장의 비교 이미지로 보증하지 않는다. 해당 결과는 아트 담당의 전 프레임 기록과 최종 실행 QA에서 확인해야 한다.

## 루카 A안 검토

| 항목 | 직접 본 결과 | 판정 |
|---|---|---|
| NPC와 색·윤곽 연결 | A의 머리·등짐 가장자리에 진한 남색 윤곽이 생겨 토리·리나·바룬·도토의 두꺼운 외곽선과 가까워진다. 청록 튜닉은 토리, 따뜻한 붉은 스카프는 바룬의 색과 연결된다. | 적합 |
| 모험가 정체성 | 작은 배낭, 크림색 말이 짐, 짧은 스카프, 한손검, 장화가 구분된다. 중갑 기사나 긴 로브의 마법사와 겹치지 않는다. | 적합 |
| 얼굴·손·검 | 비교 이미지에서 눈과 얼굴, 검을 쥔 손, 짧은 검의 방향이 기존 원형과 같은 위치에 보인다. 장비를 다른 것으로 바꾸는 수정이 아니다. | 원형 기준 적합 |
| 발과 전체 크기 | 원형 비교의 A는 기존 루카와 같은 지지선에 서 있다. 머리 크기를 바꾸는 B보다 기존 동작의 비율을 이어가기 쉽다. | A 채택 동의 |
| 도트 표현 | 명암을 더 잘게 늘리지 않고 기존 색 덩어리와 계단형 실루엣을 유지한다. | 적합 |

**A를 채택하는 이유는 현재 동작의 비율을 유지하면서 NPC와 외곽선의 강도를 맞추기 때문이다.** B의 머리 축소가 반드시 나쁜 형태라는 뜻은 아니지만, 지금은 얼굴·장비·전신 비율까지 다시 검증해야 할 이유가 없다.

상단 NPC는 기존 콘셉트 이미지이고 하단 루카는 게임용 작은 원형이다. 상단에는 미세한 농담도 남아 있으므로, 이 비교를 근거로 NPC의 게임용 스프라이트·애니메이션이나 픽셀 규격까지 완성됐다고 표시하면 안 된다. 현재 비교 이미지의 `기존 NPC 컨셉` 표기는 이 차이를 알려 준다.

## 지면 계획과 실행 범위

문서에서 확인한 분량은 다음과 같다.

| 구간 | 지역 | 데이터의 실행 범위 표시 | 전용 장식 완료 |
|---|---|---|---|
| 1–10 | 바람들판 | 현재 실행 구간 | 별도 10장 제작 아님 |
| 11–20 | 솔바람숲 | 현재 실행 구간. 기존 바닥 숲 색조 적용, 전용 숲 배경은 후속 | 별도 10장 제작 아님 |
| 21–30 | 햇돌광산 | 후속 계획 | 미구현 |
| 31–40 | 구름고개 | 후속 계획 | 미구현 |
| 41–50 | 붉은바위둥지 | 후속 계획 | 미구현 |

JSON에는 50행이 있으며 `implemented=true`는 1–20의 20행, `detailArtImplemented=true`는 0행이다. HTML의 구역 표와 전체 펼침 표도 이를 `실행 구간 / 후속 계획`, `바닥 장식 계획`으로 구분한다. 사용자에게 50개의 새로운 배경이나 50스테이지 실행이 모두 완성됐다고 오해하게 만드는 내용은 확인하지 못했다.

`implemented`는 명세가 설명하는 현재 실행 구간이라는 의미로 읽어야 한다. 이 값만으로 20스테이지의 모든 발·공중·공격 프레임에 대한 시각 QA가 통과했다는 뜻은 아니다.

## 접지·공중 프레임·카메라

계획 좌표는 1280×720의 위쪽 원점 기준 **Y=590**이다. 현재 일반 전투 카메라의 크기와 높이를 반영하면 명목상 화면 위치는 **720p의 Y≈469.23**이며, JSON은 이 둘을 다른 필드로 보관한다. HTML 그림 역시 `설계도 · 실제 게임 캡처 아님`을 표시하고 그림 자체의 위치를 실제 렌더 좌표라고 주장하지 않는다.

다음 원칙은 자연스러운 모션과 양립한다.

- 잔디 끝·검끝·망토가 아니라 단단한 바닥 윗경계와 지지발을 맞춘다.
- Idle·준비·회복의 지지와 달리기·점프의 의도적 공중 자세를 구분한다.
- 프레임마다 이미지의 맨 아래 픽셀을 끌어내려 점프 높이와 무기 궤적을 뭉개지 않는다.
- 같은 지면을 기준으로 보스 크기를 위쪽으로 키우고, 바닥 공격 효과도 같은 기준에서 출발한다.
- 전환 달리기에서 플레이어의 기본 X를 고정하고 지면·배경을 움직인다.

### 보완 권고 1 · 공중형의 Idle 예외

50스테이지에는 광산 박쥐·산바람 박쥐·와이번 등이 포함되어 있다. `Idle·준비·회복은 지지발이 기준선에 닿는다`를 모든 종에 그대로 적용하면 날고 있는 생물까지 강제로 착지시키는 해석이 가능하다.

권장 문구: **“지상형 Idle·준비·회복은 지지발이 접지한다. 공중형은 같은 지면 기준에 개체별 부유 높이를 더하며, 착지하는 동작에만 지지발 접지를 적용한다.”**

현재 실행 1–20의 지상형 적용을 막는 문제는 아니다. 다만 21–50의 제작 명세로 쓰기 전에 예외를 명시하는 편이 좋다. 새 부유 움직임을 이번에 구현하라는 의미도 아니다.

### 보완 권고 2 · 469.23의 적용 상태

현재 숫자는 기본 카메라의 명목상 위치다. 보스 등장 중 줌·카메라 이동이나 흔들림에서는 실제 화면 Y가 달라질 수 있으며 픽셀 경계도 실행 렌더에서 확인해야 한다.

권장 표기: **“기본 전투 카메라의 720p 명목상 화면 Y≈469.23 · 보스 줌/흔들림 제외.”**

현재 `nominalScreenY720`라는 JSON 이름과 주석은 이미 이 취지에 가깝다. HTML에도 짧게 붙이면 일반 독자가 `모든 장면에서 화면 469.23 고정`으로 읽을 가능성이 줄어든다. 생성 도구의 카메라 상수는 현재 값과 맞지만 카메라 구성 변경 시 함께 갱신해야 한다.

## 차별성·스킬안과의 일관성

| 대조 항목 | 결과 |
|---|---|
| 외형 변경이 전투 규칙을 바꾸는가? | A안은 원형 스타일 정리이며 스킬 발동·피해·회피 판정을 새로 적용한다고 쓰지 않는다. 충돌 없음. |
| 지형이 신규 위험이나 조작을 만드는가? | 경사·발판·낭떠러지·지형 피해를 추가하지 않는다고 명시한다. 기존 버튼 안에서 판단을 늘리는 정체성 기획과 일치. |
| 달리기와 공격의 이동을 구분하는가? | 전환 달리기는 기본 X 고정. 기존 공격의 접근·접촉·복귀는 별도 동작이다. 기본 X 고정 문구를 공격까지 고정한다는 뜻으로 확장하면 안 된다. |
| 시각 효과가 판정을 가리는가? | 같은 접지 기준과 무기 연결을 우선하며 장식이 판정을 바꾸지 않는다. 스킬은 작은 효과로 다음 예고를 보존한다는 기획과 일치. |
| 새 캐릭터·스킬이 구현된 것으로 보이는가? | 스킬 자료는 루카만 현재 선택 가능, 다렌·미엘은 준비 중, 전용 스킬은 기획임을 명시한다. 지면 자료는 이 상태를 변경하지 않는다. |
| 50스테이지가 당장 플레이 가능한 것으로 보이는가? | 지면 자료와 정체성 문서 모두 전체 목표 50과 현재 실행 구간을 구분한다. 충돌 없음. |

사용자에게 보이는 기획서의 순서는 **현재 적용 화면 → 루카 비교 → 지면과 모션 원칙 → 캐릭터 스킬 → 30초 전투 예시**이면 자연스럽다. 기술적인 Y값은 접지 설명과 접힌 상세 명세에 두고, 실제 게임 HUD에는 노출할 필요가 없다.

## 최종 판정

**기획 반영에 적합. A안 채택에 동의.** 공중형 예외와 기본 카메라 상태를 위 두 문구로 보완하는 것을 권장한다. 실제 모션 자연스러움과 20스테이지 접지는 아트 담당의 전 프레임 확인 및 마지막 실행 QA 결과에 따라 별도로 판단해야 한다.

검토 중 원형·HTML·생성 도구·Unity 파일을 수정하지 않았다. 이 리뷰 파일만 작성했다.
